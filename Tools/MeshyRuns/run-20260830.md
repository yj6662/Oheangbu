## 파이프라인 실측 지식 (재시도 시 참조)

- **경로**: 알파 추출·이진화→24bpp BMP→`potrace -i -s --flat -t <N> -a 1.0 -O 0.8~1.2`→SVG→
  Blender(SVG 임포트→fill 'BOTH'·resolution_u 2→evaluated 메시 월드 굽기[ops.join 회피]→
  dissolve_limit 1.5°→bmesh solidify→중심 피벗·최장축 1.0 정규화→180°X 선회전 보상[SPELL-FX
  §4.2-6 ②]→FBX_SCALE_ALL 익스포트)
- **`--flat` 필수**: 다중 path SVG는 Blender 임포트에서 도형-구멍(even-odd) 관계가 끊겨 꽉 찬
  판이 된다(실측) — 단일 path로만
- **bmesh solidify는 양면 확장**: 최종 두께=인자×2(실측 — 인자 절반 보정). 단 지오메트리에 따라
  단면 확장인 경우도 관찰(P149·P79는 z=0.02) — bounds 실측이 판정
- **turdsize는 해상도 비례**: 3307² 원본의 잔무늬 하나가 수천 px — t 8은 노이즈 제거만.
  내부 무늬가 과밀한 문양(P27 화염 광배: t 2500에도 8.5k tris)은 t로 못 살린다 — 문양 교체가 답
- 폴리 통제 실측: resolution_u 5→2 + O 0.4→0.8~1.2 + dissolve_limit로 −74%(12.2k→2.9k)

## MCP 운용 실측 수칙 (트랙 무관 — 상시 유효)

- **`tests-run` 금지**: EditMode 테스트 러너 호출이 브리지 행→릴레이 세션 만료→서버 사망 유발
  (Editor.log에 실행 흔적 0). 인식 회귀 등은 코드 계층 증명으로 대체
- **에디터 완전 유휴 함정**: 백그라운드 Unity는 CPU 0%·auto-refresh 무발동 — 브리지가 죽으면
  자력 재연결 불가. 복구=임시 .cs 추가+포커스 킥(SendKeys Alt+AppActivate)→리컴파일→도메인
  리로드→플러그인 재초기화. 플레이 진입 도메인 리로드로도 브리지 순단(재연결 대기 후 재시도)
- **`editor-application-set-state`에 `isPaused:false`만 주면 플레이도 꺼진다**(isPlaying 기본값
  함정) — pause 해제는 두 플래그를 함께 명시
- 리플렉션 null 인자(Transform 등) 전달 불가 — 실존 더미 GO로 우회. `Instantiate`/`LoadAssetAtPath`
  반환이 메시 통짜 직렬화(2MB+)일 수 있음 — 파일로 받아 instanceID만 추출
- 구조체 배열 SO 쓰기는 jsonPatch 불가 — pathPatches+SerializedMember 봉투 형식만
- `Time.timeScale`·`Application.runInBackground` 등 UnityEngine extern 프로퍼티는 리플렉션 파인더
  미노출 — `PlayerSettings.runInBackground`(UnityEditor)로 대체. 캡처 파일 저장=
  `ScreenCapture.CaptureScreenshot` 리플렉션 호출(pause 중엔 프레임 대기로 미저장 주의)
- **`script-execute`(Roslyn) 불능**: "CSharpCompilationOptions invalid vtable slot" — 복합 편집 작업은
  `Scripts/Editor/`에 정적 메서드를 둔 에디터 스크립트로 쓰고 `reflection-method-call`로 호출한다
  (예: `SpellRangeSceneBuilder.Build/FireLetterFromPose`). 결과는 string 반환이 가장 안전
- **플레이 중 원격 검증은 자세 리셋 동반**: 게임 뷰가 마우스 delta를 받아 시작 후 수십 초면 yaw·pitch가
  드리프트한다(첫 cone 시전 0체 명중의 원인). 시전 헬퍼가 같은 프레임에 위치·yaw·pitch를 되돌린 뒤 발화
- 톱뷰 전경 컷=`screenshot-isolated`(gameObjectRef=Ground·isolated:false·cameraView:Top) — 배치 검증에 유용
- **에디터 빌더에서 `NewScene`/`OpenScene` 전에 얻은 에셋 참조는 쓰지 않는다**: 씬 전환이 미참조 에셋을 언로드해 관리
  참조가 죽은 객체(fake null)가 되고 씬에 `fileID: 0`으로 박힌다(패링장 설정 사례). 씬 생성 뒤 `LoadAssetAtPath`로 다시 얻는다
- `EditorBuildSettings.scenes` 대입은 메모리만 — `AssetDatabase.SaveAssets()`로 즉시 플러시해야 디스크/git에 반영
- 릴레이 세션 만료 시 「No game engine connected」— 유휴 에디터는 포커스 킥(AppActivate)만으로도 auto-refresh→리컴파일→재접속
- 플레이 중 씬 로드(`LoadSceneInPlayMode`)는 도메인 리로드 없이 브리지 유지 — 여러 씬을 한 세션에서 순회 검증 가능.
  원격 상호작용/이동 헬퍼(`InteractWith`·`MovePlayer`)로 키 입력 없이 포탈·선택대·근접 표시를 검증한다
