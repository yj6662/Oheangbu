   `SerializedObject`로 넣으면 fileID 0으로 저장된다(`DevSceneKit.EnsureParryConfig` 함정 재현: `_palette: {fileID: 0}`).
3. **룩 캡처는 리그 카메라가 아니라 고정 포즈 임시 카메라**(`WorldLookAudit.Capture`: sRGB RT → ReadPixels → PNG) — 플레이 중
   `screenshot-game-view`는 플레이어 위치·회전에 흔들리고(누군가 걷고 있으면 다른 곳이 찍힌다), 리그의 숄더 카메라는 캡슐 머리가 화면을 가린다.
   `screenshot-game-view`·`screenshot-camera`의 색은 sRGB로 정상(회색은 도구 탓이 아니었다).
4. 플레이 진입/이탈은 도메인 리로드로 MCP 세션이 ~8초 끊긴다 — `Start-Sleep 8` 뒤 재호출. 인스턴스 ID는 리로드마다 바뀐다(이름으로 다시 찾는다).
