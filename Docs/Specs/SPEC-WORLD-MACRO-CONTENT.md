# SPEC-WORLD-MACRO-CONTENT — 5강토 콘텐츠 위치 초안

Lifecycle: ACTIVE · State: TEST · 결정 #212 · 2026-09-12

## 목적과 소유 범위

현재 자연 지형에 적 오브젝트, NPC, 이벤트, 던전의 대략적인 자리를 만든다. 위치를 지도에 표시하는 것과 함께 매크로 씬에 실제 검토용 형상을 둔다. 완성 전투나 퀘스트 서비스는 이 초안의 완료 기준이 아니다.

근거는 LDB-REALMS, NARR-CHARACTERS, NARR-STORYLINE, NARR-LENSES, NARR-FINALE, COMBAT-ENEMY, COMBAT-BOSS다. 각 항목의 직접 근거는 `WorldMacroContentSheetSO.Entry.Source`에 기록한다. 전체 지리는 SPEC-WORLD-MACRO가 소유하며 이 문서는 새 지형·도로 생성이나 기존 C2 변경을 요구하지 않는다.

## 배치 원칙

- 기존 실제 건축물 위치를 지도 예약 POI보다 우선한다. 자연 지형, 현재 수면 삼각형, 도로 통행 폭과 기존 구조물 충돌을 확인한 후 건조한 지면에 배치한다.
- 원본 바이블 수량·좌표는 지침이다. 정확한 후반 위치가 정해지지 않은 곳은 TEST로 저작하고 세계관 정본을 수정하지 않는다.
- 청림은 폐광 조사→금표 주막→벌목장→심부→청룡의 흐름이다. 정담은 역참, 왕소는 객주 분소에 둔다. 신목의 경계 경고와 금속 덩굴 예습을 별도 위치로 분리한다.
- 적로의 전쟁 흔적과 양측 증언, 철옹의 군수·망명·백호, 현강의 폐도읍·현무·사찰, 황경의 성저·남문·기록·왕궁을 연결한다. 장영실 관련 작업 흔적을 철옹에 둔 것은 위치 검토 해석이며 원전 지역 확정이 아니다.
- 일반 적은 무속성 또는 단일 속성이다. 캡슐 색·역할·후보 활동 반경을 기록하며 이번에는 전투 AI를 추가하지 않는다.
- 국·눈·숫·웅·뭄은 재방문 후보 지점으로 표시한다. 청림 본선에 국을 강제하지 않는다.

## 데이터·런타임 계약

`WorldMacroContentSheetSO`가 ID·종류·지역·기준 장소·실제 좌표·회전·서사 단계·대화/설명·선행 항목·근거를 가진다. `Preserve`가 켜진 항목은 설치 명령 재실행 시 수동 위치를 유지한다. 모든 위치를 해결한 뒤 기존 배치 루트를 교체한다.

`WorldMacroContentPoint`는 씬의 위치 및 캡슐/모듈 형상과 데이터 ID를 연결한다. 적·보스는 `CombatConnected=false`이고, 본편 EnemyController·SpellBook·저장 상태를 변경하지 않는다.

`WorldMacroContentPreview` 하나가 0.2초 간격으로 가까운 형상만 표시한다. 보행 중 4m 이내의 가려지지 않은 지점에 F 확인을 제공한다. 차량 입력 E/V나 작도 입력은 변경하지 않는다. 왕소→화물 계약→성저 인도는 세션 내 검토용 선행 관계만 가진다. 종료하면 본편에 진행값이나 보상을 남기지 않는다.

던전은 지상에 놓은 3개 방 모듈이며 지하 굴착이 아니다. 방 12×12m, 통로 폭4m, 진입 경사로12m로 공간을 검토한다. 창고·굴·묘역의 최종 외형과 레벨 디자인은 이후에 세분화한다. 검수용 적 캡슐과 마지막 조사대는 본편 전투·드롭을 실행하지 않는다.

콘텐츠 자리만 식생의 절차 배치 제외 영역으로 연결한다. 기존 지형·도로·수면·랜드마크·차량은 재생성하지 않는다. 기존 PlayerRig와 프롤로그 서비스도 보존한다.

## 검증·검토

- 고유 ID·실제 씬 오브젝트·유효 좌표·선행 참조·Bible 출처를 검사한다.
- 기존 구조물과 위치 겹침, 실제 플레이어 크기의 통로 캡슐 표본을 검사한다. 이는 자동 보행 완주가 아니다.
- Play Mode에서 선행 조건, 반복 확인, 누락 ID, 원거리 표시 해제와 비활성화 정리를 검사한다. 실제 F키·사용자 완주·전투·보상·저장·120fps는 실행 여부를 별도로 표시한다.
- 전체 위치 지도·CSV·검증 보고서와 1920×1080 정지 이미지만 제공한다. 영상과 자동 보행 완주는 제작하지 않는다. 촬영은 순차 처리하며 커밋85% 이상에서 중단한다.
