# SPEC-PLAYTEST-MENUS — 외부 플레이테스트 메뉴 · 탐험 지도 · 석경 수집

Lifecycle: ACTIVE · State: TEST · 2026-09-15

## 1. 목적과 범위

`W_Playtest_Title`과 `W_WorldMacro_Playtest`에 외부 플레이어가 설명 없이 시작하고, 설정을 조절하고, 현재 소지품·발견한 술식과 탐험한 지도를 확인할 수 있는 UI를 제공한다. 이 범위는 플레이테스트 전용 프레젠테이션과 저장 확장이다. 본편 장비 강화, 상점, 퀘스트 원장, 오행 마석 강화 경제, 차패 성장 기능을 완성하지 않는다.

근거는 Constitution `CONST-RULES`, Art & Audio `ART-UI`, LDB `LDB-CHARTER`, Narrative `NARR-OHAENGBU`의 석경 정의, Combat `COMBAT-ECONOMY`다. 전투 HUD와 효과음 자산 규칙은 [SPEC-PLAYTEST-UI-AUDIO](SPEC-PLAYTEST-UI-AUDIO.md), 매크로 플레이 구간은 [SPEC-WORLD-MACRO-PLAYTEST](SPEC-WORLD-MACRO-PLAYTEST.md)를 따른다.

## 2. 화면 목록

- **타이틀 로비:** 이어하기, 새 게임, 옵션, 조작 안내, 종료. 유효한 주 저장 또는 백업이 있을 때만 이어하기를 허용한다. 손상 파일은 자동 초기화하지 않는다.
- **플레이 HUD:** 먹 획 HP 바, 수평 먹 바, 일획 레티클, 상호작용 프롬프트. 먹병은 이번 연결에서 사용하지 않는다.
- **일시정지:** 계속하기, 소지품, 술식 도감, 차패, 지도, 옵션, 조작 안내, 타이틀로 돌아가기.
- **소지품:** 현재 실제 저장에 들어 있는 소지품과 석경 파편을 보여준다. 파편은 글자와 발견 묶음을 식별할 수 있어야 한다. 장비 슬롯·강화 버튼·가격은 두지 않는다.
- **조사·대화 내용:** 상호작용에서 제목·본문을 보여주고 확인으로 닫는다. 2026-09-15 사용자 결정으로 기록/기록첩 메뉴와 재열람 버튼을 제거했다. 빈 탭이나 비활성 버튼을 남기지 않는다.
- **술식 도감:** 석경에서 발견한 글자, 오행, 분류, 현재 설명, 자모 조합 예를 보여준다. 발견 기록은 전투 `SpellBook`의 사용 가능 여부나 먹 비용을 바꾸지 않는다.
- **차패:** 본편 성장 방향은 유지하되 플레이테스트에서는 미취득/준비 중 상태만 읽을 수 있게 표시한다. 가짜 오상 획득이나 강화 조작을 만들지 않는다.
- **옵션:** 화면 해상도·창 모드·품질·수직동기화·프레임 제한, 전체/게임/UI 음량, 시점 감도·Y축 반전, UI/본문 크기, 미니맵 표시, 지도 펼침 동작 줄이기. 화면 변경은 확인 전 미리보기이며 제한 시간이 지나거나 포커스를 잃으면 되돌린다.

모든 문자는 런타임 한국어 텍스트로 렌더한다. 공급자 이미지에 박힌 글자를 UI 문안으로 사용하지 않는다.

## 3. 모달과 입력 소유권

Esc 메뉴, 소지품, 도감, 전체 지도, 옵션, 조작 안내, 조사·대화 내용창은 모두 게임 시간을 멈추는 전체 모달이다. 열기 전에 진행을 저장하고 작도 중이면 조용히 취소한다. 메뉴가 열린 동안 보행·시점·작도·승하차·차량·F 상호작용·전투 갱신용 거리 컬링 입력을 막는다. UI 애니메이션과 확인 제한 시간은 비스케일 시간을 사용하고, 자동 저장은 계속 허용한다. 제거된 기록 메뉴나 알 수 없는 페이지의 요청은 저장·정지·현재 페이지 상태를 바꾸기 전에 거절한다.

닫을 때는 중첩 모달 깊이가 0일 때만 이전 시간 배율과 커서 상태를 복원한다. 눌린 키가 중립으로 돌아오기 전에는 게임 입력을 다시 받지 않는다. 지도 접힘이 끝나는 동안 같은 입력으로 즉시 재개하지 않는다.

## 4. 탐험 지도

미니맵은 **이미 탐험해 드러난 지형만** 표시한다. 미탐험 셀, 목표 화살표, 추천 경로, 다음 진행 위치는 표시하지 않는다. 현재 위치, 발견된 장소, 체크포인트, 회수할 통보, 사용자가 발견 영역에 놓은 핀은 허용한다. 지도는 이동 명령이나 패스트 트래블을 제공하지 않는다.

M 전체 지도는 접힌 한지를 펼치는 화면이며 전체 메뉴와 같이 플레이를 멈춘다. 확대·이동·현재 위치 복귀·발견 영역 핀을 지원한다. 미니맵 숨기기 옵션은 발견 데이터 자체를 지우지 않는다. 탐험 셀과 마커는 월드 좌표에서 결정적으로 계산해 저장하며, 지도 그림의 장식과 실제 발견 판정을 분리한다.

### 4.1. 2026-09-14 한지 재설계 — 직각으로 두 번 접은 한 장

전체 지도는 **가로와 세로로 한 번씩 접어 네 구획이 생긴 한 장의 낡은 한지**다. 작은 접힌 묶음이 들어온 뒤 세로 중심선, 가로 중심선 순으로 펴지고 마지막에 가볍게 가라앉는다. 열기 **1.1초**, 닫기 **0.65초**를 비스케일 시간으로 진행한다. 닫는 동안에는 지도 모달·일시정지·입력 차단을 유지하고, 접힘이 끝난 뒤 기존 중립 입력 복귀 절차를 따른다. 동작 줄이기는 중간 동작 없이 열린 상태와 닫힌 상태를 적용한다.

종이에는 마모된 가장자리, 섬유, 구김과 두 중심선의 접힌 흔적을 둔다. `WorldMapPaperGeometry`는 중심선을 공유하는 연속 3차원 표면을 계산하고 `WorldMapPaperGraphic`이 이를 원근 투영해 uGUI 안에 표시한다. 현재 격자는 40×32칸, **1,353정점·2,560삼각형**이며 종이의 가로:세로 비율은 1.38:1이다. 두 중심선의 좁은 곡면과 약한 표면 굴곡을 포함하고, 같은 기하를 UV·법선이 있는 OBJ로 내보낼 수 있다. 별도 지도 촬영 카메라나 실시간 천 물리 시뮬레이션을 사용하지 않는다.

지형 그림·탐험 공개·동굴 선은 앞면의 같은 종이 UV를 따라 접힌다. 뒤집힌 면에는 인쇄 지도가 없는 한지 뒷면을 보여준다. 현재 위치와 발견 마커·설명·조작부는 종이가 충분히 펼쳐졌을 때 읽을 수 있게 표시한다. 전체/현재 위치, 범례, 확대·이동, 발견한 야외 영역에 핀 놓기·지우기와 지도 닫기는 기존 기능을 유지한다. 그림 표현의 교체는 발견 판정이나 저장 데이터를 바꾸지 않는다.

이미지 출처와 제작 범위는 [PaperMapReview/SOURCE.md](../../Art/UIAudio/PaperMapReview/SOURCE.md)에 기록한다. 재설계 전 프레젠터·접힘 코드와 두 정지 이미지는 `Art/UIAudio/PaperMapReview/Before/`에 보존한다. 이전 메뉴 검증 결과는 당시 구현의 기준선으로 남긴다.

## 5. 진행 저장과 복구

파일 슬롯 이름 `world-macro-playtest-v2`는 기존 빌드와의 경로 호환을 위해 유지한다. 내부 `WorldMacroProgress` 스키마는 v3이며 v2의 지형 revision, 진행 ledger, 처치 목록을 보존한 채 `ui`를 추가한다. `ui`는 소지품, 발견한 술식 글자, 기록, Base64 탐험 셀, 발견 마커, 지도 핀, 알려진 오상을 가진다.

주 저장이 유효하면 이어가고, 주 저장이 손상됐지만 유효한 `.bak`이 있으면 백업에서 복구한다. 둘 다 유효하지 않으면 이어하기를 막고 원인을 표시한다. 새 게임은 `.json`, `.bak`, `.tmp`를 삭제하지 않고 시간표가 붙은 별도 폴더로 모두 옮긴 뒤 시작한다. 보관 실패 시 새 게임을 시작하지 않는다. 플레이 장면이 손상 저장에서 직접 시작된 경우 자동 저장과 수동 저장으로 원본을 덮어쓰지 않는다.

## 6. 석경 파편과 도감

20개 글자를 다섯 묶음으로 수집한다.

| 묶음 | 글자 | 씬 배치 기준 |
|---|---|---|

씬 authoring이 현재 지형과 경로에서 계산해 저장한 위치가 정본이다. 런타임 카탈로그의 기본 좌표는 에디터/씬 배치가 없을 때의 참고 fallback일 뿐이며 시작·출구·주막 배치를 결정하지 않는다. 기존 석경/유물 프리팹을 사용하고 바닥 관통, 공중 부유, 통로 차단, 상호작용 시선 차폐가 없어야 한다.

F 수집은 보행 중이고 작도·탑승·모달이 아닐 때만 가능하다. 한 묶음은 한 번만 지급한다. 묶음의 각 글자는 소지품 파편 1개와 발견 글자 1개로 기록하고 즉시 저장한다. 저장에 실패하면 해당 수집 변경을 되돌리고 파편을 남긴다. 일부 데이터만 남은 저장은 빠진 항목만 보완한다. 수집은 기존 술식 사용 가능 여부, 인식, 필세, 먹 소비, 피해, 보상 경제를 바꾸지 않는다.

현재 플레이 구간의 `mine_inquiry`, `logger`, `herbalist`, `worker_satchel` 완료 ID와 기존 `ui.records`는 저장 호환성을 위해 유지한다. 기록 메뉴 제거 때문에 완료 상태를 삭제하거나 재지급하지 않는다. 설명 모달은 승인된 조사·대화가 해결된 프레임의 제목과 본문을 사용한다. 검토용 메뉴 생성은 기록 열람을 위한 상호작용을 자동 완료하지 않는다.

## 7. 구현 경계

- App UI가 메뉴 화면, 프레젠터, 저장 확장, 카탈로그와 수집 서비스를 소유한다. Core 공유 상태는 입력 차단과 접근성 설정 값만 제공하며 진행 데이터를 갖지 않는다.
- 기존 `SpellBook_Proto`, `SpellBook_WorldMacroSummon_TEST`, 작도 인식 좌표, 전투 수치, 통보/먹 경제, PlayerRig는 수정하지 않는다.
- 지도 탐색 데이터는 시각 프레젠터가 아니라 월드 진행에 저장한다. 지도 텍스처와 발견 비트 판정은 별도 데이터로 유지한다.
- 강화 경제는 Combat `COMBAT-ECONOMY`의 후속 작업이다. 이번 소지품 화면에 임시 가격·등급·강화 효과를 만들지 않는다.
- 설치는 플레이테스트/타이틀 씬에만 적용한다. 다른 씬은 기존 HUD와 입력을 유지한다.

## 8. 검증 상태와 증거

2026-09-14 메뉴 확장 구현과 검증 결과는 [검토 보고서](../../Art/UIAudio/PlaytestMenus/REPORT.md)와 같은 폴더의 `Validation/`에 기록한다. 기존 사용자 저장과 분리된 진단 슬롯을 사용했다. **아래 통과 목록은 §4.1 한지 재설계 이전 메뉴의 검증 기준선**이며, 새 종이 기하와 새 개폐 시간의 실행 통과를 뜻하지 않는다.

- **통과:** v2→v3의 기존 필드 보존, 5묶음·20파편과 중복 방지, 탐험 비트 저장, 변경 없는 저장 생략, 임시 파일·백업 복구 및 손상 파일 보관 검사.
- **통과:** Unity Input System 시험 입력으로 작도 중 Esc의 무시전 취소, 메뉴 중 이동·F·작도 차단, 입력 중립 후 복귀, 지도 접힘 동안 일시정지 유지, 실제 파편 위치 5곳의 F 획득·중복 방지.
- **통과:** 탑승 상태를 유지한 메뉴 입력 차단, 15초 설정 미리보기 복원, 지도 20회 개폐에서 텍스처 수 증가 0. 운영체제의 실제 화면 모드 전환 확인을 대신하지 않는다.
- **통과:** 기본 배율과 UI 1.20·본문 1.25의 활성 텍스트 잘림 검사. 720p·1080p·1440p·울트라와이드는 레이아웃 계산 검사이며 실제 스크린샷은 1080p로만 확보했다.
- **미검증:** 사람의 마우스·키보드와 손글씨 완주, 실제 디스플레이 모드 변경, 효과음 청취, 모든 기기의 화면 가독성과 GPU 성능. 자동 진단을 이러한 검사의 대체로 보고하지 않는다.

독립 실행 후보의 실제 새 게임·저장·로비·이어하기 결과는 후보 폴더의 `ui_smoke.json`, 컴파일·포장 결과는 `release_build_report.json`과 `package_report.json`을 정본으로 사용한다. 빌드 성공만으로 플레이테스트 전체를 완료 처리하지 않는다.
5. 다섯 석경 묶음의 접지·가시성·통행, 정확한 20글자, 중복 수집 0, 저장 실패 rollback.
6. 소지품·도감이 실제 저장만 표시하고 미발견 글자·차패·강화를 획득한 것처럼 보이지 않는지. 기록 메뉴 제거 뒤에도 기존 조사·대화 완료와 저장 이행이 유지되는지.
7. 옵션 적용/15초 복귀, 한국어 폰트, UI 효과음, 장면 왕복, 종료 저장의 독립 실행 동작.
8. 메뉴와 지도 포함 120fps 목표는 렌더 가능한 실제 실행에서 별도 계측한다. 숨김 또는 렌더 무효 실행 수치는 성능 근거로 사용하지 않는다.

정적 코드 검사, 상태 주입 정지 이미지, 에디터 Game View 캡처는 각각 구조·표현 증거로만 기록한다. 실제 키 입력, 파일 복구, 사용자 가독성, 수동 경로 완주를 대신하지 않는다.
