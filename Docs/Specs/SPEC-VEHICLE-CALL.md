# 오행부 자동차 호출과 거리 회수

2026-09-15 사용자 요청: 자동차 호출을 단축키로 바꾸고, 임시 오행부를 꺼내 조작한 뒤 집어넣는 동작과 하차 후 거리 회수를 추가한다.

## 조작

- 보행 중 **G**: 오행부 조작 1.8초. 왼손으로 꺼내 들고 오른손으로 조작하며, 약 0.94초의 조작 순간에 기존 자동차 한 대를 안전한 큰길로 부른다. 마지막에 손과 오행부를 되돌린다.
- 기존 오행부 메뉴의 즉시 호출 버튼은 G 안내로 교체한다. 조작 안내와 관청 아전의 대사·현재 목적도 G를 가리킨다.
- 신설 관청 여정은 의뢰를 확인한 뒤 호출한다. 기존 저장에 의뢰를 강제로 부과하지 않는 이전 정책을 유지한다.
- 탑승·웅크림·착석·공중·회피·작도·갈무리 중에는 시작하지 않는다. 이 시안은 땅에 선 자세에서 사용한다.
- 손동작 동안 이동·전투·상호작용 입력을 기존 입력 게이트로 막지만 세상은 정지하지 않는다. 메뉴를 열거나 창의 포커스를 잃거나 실제 피해·사망이 발생하면 취소한다. 조작 순간 전 취소는 자동차를 부르지 않는다. 호출 완료 후 취소는 이미 호출한 차량을 되돌리지 않는다.
- 종료 후 눌려 있는 G 및 전투·이동 키가 중립으로 돌아올 때까지 입력을 재개하지 않는다. 일시정지 메뉴가 게이트를 인계받았다면 동작 종료가 메뉴의 차단을 해제하지 않는다.

## 회수

- 실제 승하차 경로의 **성공한 하차**에서만 거리 회수를 준비한다. 처음 배치된 차나 아직 타지 않은 새 호출 차량이 멀다는 이유로 바로 사라지지 않는다.
- 하차 후 유예 2초, 자동차 중심과 플레이어 발 위치의 수평 거리 **30m 이상을 0.75초 유지**하면 회수한다. 가까워지면 거리 유지 시간을 초기화한다. 재탑승하면 회수 준비를 해제한다.
- 회수는 기존 차량 오브젝트를 비활성화해 물리·시각·좌석·구동 VFX를 함께 정리한다. 인스턴스를 삭제하거나 복제하지 않는다. 다음 유효 호출에서 같은 인스턴스를 다시 활성화한다.
- 자동차에 탄 상태, 메뉴 정지, 플레이어 사망 중에는 거리 회수를 하지 않는다.
- 회수 여부는 이 플레이 세션의 상태다. 앱 재실행 후 차량 위치·회수 상태의 영속화는 이번에 추가하지 않았다.

## 외형과 판정

- 임시 오행부는 금빛 판, 다섯 개의 빈 소켓, 고리와 짧은 끈을 가진 2,200삼각형·3재질 소품이다. 사용자 참고 이미지의 최종 제작을 대체하지 않는다.
- C02의 기존 골격에 두 팔 IK와 손가락 조작을 표시한다. 루트 이동, 본 길이, 신체 메시·UV·승인된 붓 파지를 변경하지 않는다. 작도용 근접 팔은 조작 중 숨기고 종료 후 기존 파지로 복귀한다.
- 자동차는 기존 도로/지지면/차체/바퀴/출입 공간 검사 경로를 사용한다. 동작 시작 전과 실제 조작 시점에 모두 빈자리를 확인한다. 실패하면 원래 위치 또는 회수 상태를 유지한다.
- 큰길은 호출 위치 조건이며 큰길 밖 운전 강제 제한은 아니다. 소환·회수 전용 대형 VFX, 연료, 자동운송은 추가하지 않는다.

## 검사 원칙

가상 G 입력은 Unity InputSystem의 실제 Dynamic 갱신에서 전달하며, API·정지 화면 검사는 사람의 실제 입력 완주와 구분한다. 거리는 안전 위치 사이의 제한된 진단 이동으로 확인한다. 결과와 미검증 항목은 `Art/PlaytestRecovery/VehicleCall/`에 남긴다. 원래 씬·기존 자료를 보존하고 새 빌드나 영상은 만들지 않는다.
