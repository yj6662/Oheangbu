## 1. 목적

CSV 정본의 기본 공격 10자 중 **기존 에셋(전통 문양 이펙트)만으로는 「효과의 실체」가 읽히지 않는
어휘**에 한해, Meshy AI → Blender MCP → Unity 경로로 최소한의 모델·VFX를 생성해 기존 문양과
결합한다. 목표는 화려함이 아니라 **가독** — "무엇이 날아오고 무엇이 솟는가"가 형태로 읽히게
하는 것(색+형태 이중 채널). 구현 범위가 작은 것부터, 대상마다 예준 게이트를 거쳐 전진한다.

## 2. 정의

- **문양 투사체**: 기존 구현 — KoreanTraditionalPattern_Effect Fly 프리팹(비행부 `Projectile` +
  개화부 `Explosion`, 비행축 로컬 +X)이 글자 자리에서 목표로 날아가 착탄 개화. 단일 5자
  (가·나·마·사·아)는 이미 이 경로로 구현됨 → **본 Spec의 생성 범위 제외**(감사 표에는 기구현 행으로 등재).
- **생성 대상**: 커버리지 감사(§4.5)가 「기존 에셋으로 불가」로 판정한 어휘의 실체 모델
  (1차 소견 후보: 송곳·가시 클러스터·파도 — §4.5).
- **결합**: 생성 모델을 단독으로 쓰지 않고 기존 문양 프리팹과 한 프리팹 안에서 겹친다 —
  문양=속성·의례의 언어, 생성 모델=효과의 실체. 둘 다 팔레트 틴트를 받는다.
- **커버리지 감사**: 어휘별로 기존 에셋(Fly ~90·Bottom ~160 + 틴트·스케일·재조합)만으로
  충분한지 판정하는 런 1 절차. **감사 전 생성 착수 금지.**

## 4. 아키텍처 / 파이프라인

### 4.1 생성 경로 (정본)

```
[감사 통과 대상만] Meshy Text-to-3D preview (무텍스처 — refine 0회)
  → 썸네일 선검수(다운로드 전 게이트)
  → FBX+GLB 다운로드(스크래치)
  → Blender MCP 후처리: 정리·데시메이트(§8)·피벗/축 정렬(비행·전진축=+X)·스케일 실측·FBX 익스포트
     (Blender 미연결 폴백: Meshy FBX 직수령 + Unity 임포터 Scale Factor·부모 오프셋 보정)
  → Unity Assets/_Project/Art/Generated/<글자>/ (gitignore — §4.7)
  → 결합 프리팹(§4.3) → SpellVisualSetSO 등재(§4.4)
```

Meshy API v2: `POST /openapi/v2/text-to-3d`(mode=preview, ai_model=**meshy-5 고정** — 재현성·비용,
topology=triangle, target_polycount=§8, should_remesh=true, target_formats=[glb,fbx]) → task id 즉시 기록 →
`GET /openapi/v2/text-to-3d/{id}` 폴링(10~20s 간격·10분 타임아웃) → SUCCEEDED 시 `thumbnail_url` 선검수.
잔액 확인=`GET /openapi/v1/balance`(무소모). 키=리포 밖 `.env`의 `MESHY_API_KEY` — 스크립트 내
변수로만 보관, 출력·로그 금지. 프롬프트 관례: `[주체]+[재질]+[아트 스타일]+[기술 제약]` 순서,
"one single object, centered, stylized, clean silhouette, simple bold shapes" 류.

### 4.2 에셋 수용 기준 (Acceptance — 전 대상 공통, 게이트 판정 기준)

1. **무텍스처 [확정 — 예준 2026-08-29]**: Meshy 텍스처 폐기, 지오메트리만 취한다. 머티리얼은
   프로젝트 소유 URP 셰이더(먹 그라디언트 계열) — 수묵 정합의 단일 통제점. 필요 시 512² 이하
   단채널 마스크만 개별 예외(§9).
2. **팔레트 틴트 호환**: 머티리얼 `_Color`(또는 `_BaseColor`) 노출 필수. 색의 정본은
   ElementPaletteSO 하나 — 에셋에 속성색 베이크 금지. 메시 렌더러 틴트 경로는
   `PatternEffectLifetime`에 분기 추가(§4.4 — 현행 Tint는 파티클 startColor 전용).
3. **발광 상한**: 생성 모델 머티리얼 Emission 0 고정. 순간 발광은 기존 규약(플래시·개화 파티클·
   수명 내 소멸하는 Light)만. 생성 모델이 스스로 빛나면 반려.
4. **무PBR**: Metallic/Smoothness 미사용. 예외: 금(金)은 ART-COLOR 「광택질로 구분」 — 금 한정
   림·그라디언트 셰이더 트릭으로 근사, 실PBR 금지 [TEST · §9 예외 3].
5. **무리깅**: 본·스키닝·블렌드셰이프 금지(PROD-RIG 기운 조항 준용). 움직임은 트랜스폼·셰이더
   (UV 스크롤·버텍스 오프셋)·파티클만.
6. **축·피벗 규격**: 투사체형=비행축 로컬 +X·피벗 후단 중심(`PatternEffectLifetime`이
   transform.right로 조준 — 기존 Fly 실측 관례). 지면 개화형(가시·파도)=업축 +Y·피벗 바닥 중심,
   전진형=전진축 +X. Unity 반입 후 실물 축 확인이 수용 조건(래퍼 회전 보정 허용).
   **임포터·축 수칙(파일럿 실측 확정)**: ① Meshy FBX는 fileScale 0.01로 들어와 메시가 1/100 —
   반입 직후 `useFileScale=false` ② Blender 경유 FBX의 메시 정점은 Z-업 그대로다
   (`bakeAxisConversion`도 무효 — 12차 실측). **메시 기준축(첨단·비행축) = +Z**가 정본이며
   런타임 코드(SpikeVolleyEffect 등)도 +Z 기준. 반입 직후 mesh bounds 실측으로 장축 검증이 수용 조건.
7. **폴리 예산**: §8 표. 초과분은 Blender 데시메이트 수렴 후 재검.
8. **수묵 정합 최종 판정 = 예준 육안**: 「담채인가, 네온인가 / 실체가 읽히는가」(§9 예외 2 —
   아트 디렉션은 사람 영역, PROD-CHARTER).

### 4.3 결합 프리팹 구조 (어휘당 1개)

```
SpellFx_<글자> (루트 — PatternEffectLifetime 대상, 루트 ParticleSystem)
 ├─ Projectile   ← 기존 Fly 비행부 재사용(문양 비행 — 현행 유지)
 └─ Explosion    ← 개화부 확장 지점
     ├─ Pattern  ← 기존 문양 개화(Fly Explosion 또는 Bottom 계열) — 의례의 언어
     └─ Body     ← 생성 모델(파도·가시 등) — 효과의 실체 [생성 대상만]
```

`Projectile`/`Explosion` 자식 이름 규약을 지키면 `PatternEffectLifetime` 수정 최소.
유료 에셋은 gitignore 그대로 — 결합 프리팹의 GUID 참조는 기존 규약(COMBAT-CORE-LOOP §9-4) 승계.

### 4.4 글자별 시각 매핑 — 신규 `SpellVisualSetSO` (표현 전용)

  보존해야 하는 결합이 생긴다. 규칙/표현 분리는 기존 문법(ElementPaletteSO가 선례).
- 어댑터 변경(소규모): `BrushStrokeFeedAdapter`에 `_visualSet` 슬롯 추가 → `OnLetterDrawn`에서
  글자별 프리팹 스태시 → `SpawnPattern`에서 스태시 우선·폴백. `PatternEffectLifetime`에
  메시 틴트 분기(수용 기준 2)·연출 궤적 훅(§3.1)·지면 전개 모드(필요 시 P4에서 판단).
  Combat·Spellcraft·Drawing 무접촉.

### 4.5 커버리지 감사 절차 (런 1 — 산출물=감사 표, 게이트 G1)

10자 전수(단일 5자=기구현 확인 행). 판정 3문:
① **실체 요구** — CSV 효과문의 실체(파도·가시·모래폭풍…)가 2D 문양 판+파티클만으로 읽히는가?
② **형태 채널** — 그레이스케일에서도 어휘·속성이 실루엣·거동으로 구분되는가?
③ **부족분의 종류** — 모델 부족인가, 파티클 재조합 부족인가, 연출 궤적(코드) 부족인가?

판정치 4종: `기존만으로 충분` / `기존+재조합(생성 불요)` / `기존+생성 결합` / `보류`.
방법: Fly·Bottom 후보 어휘별 3~5종 스폰·틴트·스크린샷(플레이모드) → 표+컷 묶음으로 게이트.

**감사 판정 [확정 — 2026-08-29 G1 예준 승인, 실측=런 로그 P1]**: 에셋 전체가 평면 문양 판+파티클,
3D 실체 메시 전무. 노=기존+재조합(생성 불요) / 소=기존 골격+**송곳 메시 1개**(최소·**파일럿**) /
고=**가시 클러스터 메시** / 오=**파도 crest 메시**(필요성 최고) / 모=재조합 먼저 시도 후 보류.
생성 순서=작은 것부터: 송곳 → 가시 → 파도 → (모=재조합 실패 시만).
