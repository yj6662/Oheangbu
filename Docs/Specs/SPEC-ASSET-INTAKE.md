## 2. 이번 작업 범위

- 현재 Unity 프로젝트에 들어온 모델 팩을 탐색하고 검수 대상 경로를 원장에 명시한다. 신규 수령 시 같은 절차를 반복한다.
- 대상 팩의 모든 프리팹을 실제 계층·렌더러·메시·재질로 검사한다. 이름만으로 분류를 완료하지 않는다. 프리팹 없이 모델 파일만 있는 경우도 별도 모델 항목으로 수록한다.
- 프리팹별 실제 기하를 렌더한 썸네일과 모델 의미를 확인하여 분류한다. 같은 모델의 색상·LOD·조립 변형은 관계를 기록하며 임의로 누락하지 않는다.
- 현재 렌더 파이프라인에서 깨진 재질을 복구하고 재검사한다. 에셋의 원래 표현을 복원하는 작업과 월드 수묵 룩 적용을 구분한다.
- 이번 산출물은 사용 가능한 자산 목록·시각 카탈로그·복구 기록이다. 모든 자산을 즉시 월드에 배치하는 것으로 해석하지 않는다. 장면별 의미·크기·공간 역할에 맞는 자산을 후속 구현에 선택한다.

## 4. 셰이더 복구와 보존

1. 원본 경로·GUID·재질 연결과 에러를 먼저 기록한다. 셰이더 누락, 현재 URP 미지원, 컴파일 오류, 누락 재질을 구분한다.
2. 복구 시 albedo/base map, tint, normal map, metallic/smoothness, AO, emission, opacity/cutout, culling, UV tiling/offset 등 실제 사용된 속성을 조사한다. 원본 의미를 재현하는 URP 셰이더와 속성으로 옮긴다. 의미가 불명확한 커스텀 셰이더는 획일 변환하지 않고 별도 보류·검토한다.
3. 잎·풀·창호 같은 얇은 면의 알파/양면과 노멀맵을 유지한다. 전체 팩을 Ink 셰이더로 덮어써 텍스처나 재질 차이를 지우지 않는다. 소스 복구 상태의 발광·색은 원본 검수용이며 실제 월드에 배치할 때 ART-COLOR/ART-INK를 다시 적용한다.
4. GUID와 프리팹 연결을 유지한다. 외부 패키지의 원본을 보존해야 하는 경우 프로젝트 소유 복구 재질/프리팹 변형을 만들고 매핑을 기록한다. GUID 재생성·일괄 삭제·원본 폴더 재배치는 하지 않는다.
5. 씬용 수묵 변형은 복구 원본과 별도로 관리한다. 원본 텍스처의 존재는 원본 검수의 속성이지 모든 텍스처를 월드에서 사용한다는 결정이 아니다. 세계의 저채도·의미색·발광 상한은 계속 적용한다.

## 5. 후속 모델 확보·배치 절차

카탈로그에서 장면의 역할과 실루엣에 맞는 모델을 먼저 찾는다. 피벗·스케일·접지·콜라이더·LOD·수묵 재질을 장면 맥락에서 조정하고 같은 고정 화각과 보행 시점에서 검수한다. 목록을 채우기 위해 자산을 무작위 산포하거나 시대·공간 역할이 다른 건물을 대체물로 넣지 않는다.

보유 자산에 실제 공백이 있을 때만 `요구 형상·규모·역할 기록 → Meshy 생성 → Blender MCP 정리 → Unity 임포트 → 본 Spec 검수`를 수행한다. Blender 단계는 축/단위/피벗, 노멀·실루엣, 불필요 면, UV·재질 슬롯, LOD·충돌·리깅 필요성을 모델별로 점검한다. 폴리 수는 장면 용도와 가시 거리로 정하며 일괄 감축이나 일괄 증가를 품질 판단 대신 사용하지 않는다. 생성 작업 ID와 원본/수정본 경로를 연결해 기록한다.

이번 검수에서 Meshy 생성이나 Blender MCP 사용을 선행 완료로 기재하지 않는다. 각 도구의 실제 연결과 결과를 확인한 실행만 기록한다. 도구가 미연결이면 연결 문제와 미실행 단계를 별도로 명시한다.

## 6. Validation

- 검수 대상 경로의 프리팹·모델 수와 원장 항목 수를 대조하고 누락/중복/제외 사유를 기록한다.
- 각 항목의 실제 썸네일 생성 여부 및 육안 분류 근거를 확인한다. 자동 분류와 육안 확인을 구분한다.
- 재질 복구 후 대상 셰이더 지원·컴파일 오류·missing 참조를 재검사한다. 썸네일에서 분홍색, 투명면 소실, 불합리한 광택/정렬/스케일을 점검한다.
- 수정 재질의 주요 텍스처·알파·노멀 연결 보존을 전후 데이터로 확인한다. 폴더/자산 이름만으로 복구 성공을 판정하지 않는다.
- Unity C# 컴파일 및 검수 도구 실행 중 예외를 확인한다. 원장 수치는 에디터 자산 통계이며 실제 빌드 성능 수치가 아니다.
- 파일 변경 목록과 기존 작업 보존을 확인한다. 잔여 미확인·미복구 자산은 보고서에서 숨기지 않는다.
