## 1. 목적

프로젝트 잔여 최고 리스크(HIGH) 2건 — **작도 손맛**과 **Core Combat 재미** — 를 실기로 검증한다.
튜토리얼 전투가 압축 교육하는 정체성 루프(COMBAT-CHARTER):

> **상극 패링 → 그로기 → 강타**

이 한 문장이 실제로 성립하고 재미의 판단 재료가 나오는 최소 전투를 만든다.
스파이크가 아니라 **프로토타입**이다 — 코드는 버리지 않고 정식 모듈(Combat·Spellcraft)의 첫 층이 된다.

## 2. 코어 루프 정의 (LOCKED 문법의 최소 절단면)

```
[탐색-접근] 락온(결투 계약) 
→ [읽기] 적 공격 텔레그래프(색=속성 / 무색=무속성)
→ [대응] 속성 공격 = 상극+ㅓ 패링(판정 3단) / 무속성 = 회피(즉발 무적·무보상)
→ [축적] 정답 패링 = 피해 무효 + 그로기 + 먹 순증
→ [처벌/자원] 갈무리(클릭·락온·근거리) = 약피해 + 먹 수급
→ [공격] Q 작도 술식(감속 중) — 필세(형×세) 위력, 먹 소모
→ [만개] 그로기 만개 = 급소창(스턴+피해 증폭) — 큰 글자의 시간
→ 적 처치 or 피격(작도 중단·글자 소멸)
```

## 6. Validation (사전 선언)

| # | 기준 |
|---|---|
| 1 | 정체성 루프 성립: 상극 패링 → 그로기 만개 → 큰 글자 강타가 **설명 없이 몸으로 학습되는가**(예준 플레이) |
| 2 | 패링 판정 3단이 정본표대로 동작(성공/반성공/상생 완전실패) — 5속성 전부 표본 확인 |
| 3 | 색=대응 프롬프트가 읽히는가: 속성색 텔레그래프→패링 / 무색→회피가 손에 붙는가 |
| 4 | 감속·체류 감쇠·피격 중단이 "전투 중 작도"를 성립시키는가 — 작도가 안전지대가 되지 않는가 |
| 5 | 먹 경제 체감: 몸을 써야(갈무리·패링) 먹이 차는 리듬이 성립하는가 |
| 6 | HUD 4종 외 추가 UI 없이 전투가 읽히는가(화이트리스트 준수 증명) |
| 7 | **재미 판단 재료** — PASS 기준이 아니라 산출물: 예준의 손맛 메모(무엇이 재밌고 무엇이 답답한가) |

## 12. 카메라 실증 실험 (2026-08-27 착수 · [실험] — 결정 3의 검증이지 전이가 아님)

**동기(예준 지시)**: 숄더뷰(플레이어 우측 상단)로 상대 패턴·주변 상황 파악을 높이고 회피 시
카메라 어지러움을 줄인다. 숄더뷰에서 사라지는 마우스↔작도 일관성은, 작도 시작 시 같은 축
(우측 상단)을 유지한 채 카메라가 작도 지점으로 다가붙는 클로즈업으로 보정한다.

**전제**: 게임 정의(1인칭)는 불변 조항 — 이 실험은 코드로 정의를 바꾸지 않는다. V키 토글로
1인칭이 항상 대조군으로 남는다. **채택하려면 DECISIONS 문답이 먼저다.**

**설계 — 2층 상태 모델** (수치 전부 `CombatConfigSO` [실험] 헤더):
베이스 모드(1인칭↔숄더뷰 · V 토글, 작도 중 V 무시 — 복귀처가 항상 결정적) + 작도 오버레이(클로즈업).

- 포즈 3종(CameraPivot 기준 로컬): 1인칭 `(0,0,0)` / 숄더뷰 `(0, 0.55, -2.8)` — 정중앙 상단·뒤 /
  클로즈업 `(0.45, 0.35, -1.1)` — 살짝 우측·상단. 지수 수렴(unscaled — 감속 무관), 진입
  빠르게(20)·복귀 부드럽게(8) — 패링처럼 짧은 작도의 커밋이 블렌드 도중에 걸리지 않게 한다.
- **클로즈업 체감 = FOV 스냅(60→52)**: 작도면이 카메라 자식이라 포즈 이동만으로는 글자 화면
  크기가 변하지 않는다(마우스 1:1은 구조적으로 보존 — 코드 검증 완료). FOV는 작도 점이 찍히기
  전에 스냅으로 확정해 1:1을 깨지 않는다. 1인칭은 대조군으로 무변경.
- 안전장치(사전 설계 리뷰 반영): 피벗 SphereCast 붐(지면·벽 관통 방지 — 축소 즉시·복원 점진) /

  모드 신호가 아니라 카메라 오프셋 거리 문턱(0.8m)으로 판정, 숨김=ShadowsOnly(니어클립 단면 방지).

- **클로즈업 전진** — `(0.45, 0.35, -1.1)` → `(0.35, 0.25, -0.2)`: 시선 근처까지 전진, 플레이어가
  거의 보이지 않는다(오프셋 0.48m < 몸 문턱 0.8m → 몸 렌더러 자동 숨김). 작도면은 눈 기준식이
  자동 대응(카메라 앞 최소 1m 유지)
- **유리판 차폐 + 투시** — 2차의 ZTest Always(무조건 위) 폐기. 그리는 동안 글자가 몸·벽에
  가려지되, 가려진 부분은 반투명(투시 농도 `BrushStyleSO.XrayOpacity` 0.35 [TEST])으로 비친다.
  구현 = 2패스: `InkStroke`(LEqual, 비차폐) + `InkStrokeXray`(Greater·SRPDefaultUnlit, 차폐부만) —
  ZTest 상보성으로 픽셀당 한 패스만 그려져 스텐실 자기겹침 1회 규약 유지. 커밋 순간 투시 패스를
  꺼서(세상 물체) 커밋 글자는 자연 차폐. 전제: 포워드 계열 렌더러 + 렌더러 스텐실 오버라이드 금지.
  주의: 현 클로즈업은 카메라가 몸 앞 + 몸 숨김이라 몸 차폐는 사실상 벽·적 등에서 발생 —
  추후 팔·붓/몸 노출 시 자동 적용
- **진입 컷 → 블렌드 복원** — 컷이 어색(예준). 진입 빠른 블렌드(20)·복귀 부드럽게(8)로 환원.
  트레이드오프 재수용: 블렌드 창(~0.2s) 안에 시작한 획은 커밋 후 미세한 평면 뒤틀림 가능 —
  새 클로즈업은 이동량이 작아 이전 설계보다 완화됨

**판정 기준(예준 플레이)**: ① 상황 파악 — 텔레그래프·주변이 1인칭보다 잘 읽히는가 ② 회피 멀미 감소
③ 작도 일관성 — 클로즈업이 「내 앞에서 쓴다」 체감을 복원하는가(FOV 값 튜닝 포함) ④ 패링 성공률 —
카메라 전환이 패링 창 체감을 깎지 않는가 ⑤ 정체성 — 1인칭 한글 작도 소울라이크의 정체성 유지 여부.
결과 = 채택(DECISIONS 문답行) / 철회(실험 코드 제거) / 부분 채택(예: 교전 중만 숄더).
