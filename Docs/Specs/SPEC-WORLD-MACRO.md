# SPEC-WORLD-MACRO — 자연 지형 우선의 5강토 전체 지도

State: TEST · 2026-09-12 · 사용자 실행 승인. Decisions #205–#211.

## 목적과 우선순위
산계·수계·분지 → 정착 가능한 땅 → 도시·고개·도하점 → 가도·도보 길 → 콘텐츠 순서로 구성한다. 자연스러운 지형, 공간감과 탐험 경험, 강토 정체성과 큰 서사, 기존 배치 지침 순으로 판단한다. 바이블의 공간 방위·거리·배치 수량·시간은 이 작업의 지침이며 개별 형상을 강제하지 않는다. 게임 입력·재화·전투 규칙 변경은 이번 범위가 아니다.

동서 약8km·남북 약12km는 저작 범위의 참고값이다. 실제 지도 외곽은 불규칙하며 사각 청크를 산벽으로 둘러싸지 않는다. 산지·수역·배경을 포함하므로 범위 전체를 콘텐츠로 채우지 않는다. 지역마다 넓은 평야를 확보하던 기준은 정착·이동·조우에 필요한 적당한 평지를 유지하는 방향으로 바꾼다. 길 양옆에서 산이나 언덕이 대부분 읽히되, 기존 큰 산계를 따르는 가지능선·산자락과 높낮이가 다른 구릉으로 구성한다. 균일한 양쪽 산벽이나 규칙적인 좁은 통로를 반복하지 않는다. 긴 지역 간 산맥 우회는 유지한다. 이전 첫 주막120–180초·540–810m·이를 맞추기 위한 knots 수정은 강제 기준에서 해제한다. 기존 프롤로그 위치와 구간 형상을 새 지형의 입력으로 삼지 않는다.

## 지리 참고와 각색
한양의 내사산을 따른 도시 입지([국가유산포털](https://www.heritage.go.kr/heri/html/HtmlPage.do?pageNo=5_1_1_0&pg=%2Funesco%2FHeritage%2FHeritage_99_12.jsp))와 산지 분지에 위치한 개성([UNESCO](https://whc.unesco.org/en/list/1278))의 관계를 참고한다. 실제 지형 측량 복제나 DEM 다운로드 결과가 아니다. 황경의 분지, 동쪽 청림 산림, 남쪽 적로 구릉·전장, 서쪽 철옹 고개, 북쪽 현강 옛 도읍·침수 저지대를 게임적으로 재배치한다. 정확한 위치·면적·방위·물길은 TEST 각색이다.

청림 탐험→청룡→국 재방문→상경 가도→황경 남문이라는 큰 흐름을 예약한다. 물리적 지리 연결과 스토리상 통행 가능 여부는 구분한다. 가마는 주요 가도, 도보는 숲·좁은 길·유적을 중심으로 한다. 가마14m/s는 검토용 가정, 도보4.5m/s는 기존 기본 이동 값이다. 매크로 초안의 가마 속도 환산과 후속 가마 시제품의 실제 움직임은 구분한다. 진행 게이트는 이번에도 구현하지 않는다.

## 구현 계약
- `WorldMacroSheetSO`: 좌표계·외곽·산계·분지·수계·강토·거점·이동망의 단일 저작 자료. 기존 RealmId 직렬화 순서 유지.
- `WorldMacroTerrain`: 경로와 무관한 전역 높이. 렌더 청크 이음도 같은 표면을 사용. 도로를 먼저 정하고 그 둘레를 산으로 채우는 방식 금지.
- `W_WorldMacro_Blockout`: 독립 저밀도 검토 씬. 도시·숲·랜드마크는 대체 형상을 출발점으로 삼고, 승인된 주요 건축물부터 외형과 접근 공간을 구체화한다. 원경은 같은 지형에서 파생하며 C2와 Prologue는 보존한다. 저장·전투·공용 PlayerRig·공급자 원본 변경 없음.
- 지도는 Unity에서 내보낸 동일 시트·지형 표본을 소비. 지상 이동과 가마 속도 카메라는 검토 도구이며 실제 플레이·가마 물리 검증으로 보고하지 않는다.
- 도시 전체 상세화·NPC·전투·보상·자동가마·월드 스트리밍은 후속. 주요 건축물 외형·접근 배치와 가마 시제품은 아래 후속 제작 범위에서 진행하되, 콘텐츠 완성이나 자동 운송망 연결로 간주하지 않는다.

## 후속 조정 — 산지 보강과 황경 귀환
사용자 검토에 따라 기존 큰 산계를 유지하면서 가지능선과 지역 사이 산지를 보강한다. 산 수를 채우거나 길을 강제로 굽히는 대신 기존 분지·하천의 관계를 유지하고, 산줄기의 높낮이와 갈라짐을 늘린다. 기존 외곽·분지·수계 보존 여부와 실제 높이 표본의 변화를 비교해 기록한다. 능선 저작선 개수는 실제 산봉우리 개수가 아니다.

각 강토의 중심에서 황경까지 기존 가도와 도보 연결을 함께 사용할 수 있도록 지리 연결을 보완한다. `Return_` 구간은 새 귀환길을 구분하는 저작 표식이며 실제 귀환 기능·스토리 통행 해제·남문 진행 규칙을 추가하거나 변경하지 않는다. 좁은 고개에 가마를 억지로 통과시키지 않으며 도보 구간을 허용한다.

귀환 비교는 경로 그래프에서 3D 거리 합계가 가장 짧은 연결을 먼저 선택한다. 같은 경로의 전체 도보4.5m/s 시간과 가도14m/s·도보길4.5m/s 혼합 시간을 따로 환산한다. 최단시간 경로, 실제 완주 시간이나 가마 주행 검증으로 보고하지 않는다. 이전 청림 비교값은 연결이 있던 금표 주막 출발임을 명시하고 새 청림 중심 출발값과 직접적인 단축량으로 비교하지 않는다. 변경 전 자료는 `Art/World/WorldMacro/Versions/v1_before_mountain_returns`에 보존한다.

## 후속 조정 — 길 양옆의 산지와 지면 농도
V3에서는 V2의 산계·귀환 연결을 바탕으로 길 양옆의 산과 언덕이 더 자주 읽히도록 산자락을 보완한다. 넓은 평야의 최소 면적을 맞추지 않으며, 도시와 마을 입지·길·필요한 활동 공간에는 적당한 평지를 남긴다. 수계와 도하점의 연속성, 길과 지형의 실제 높이 관계를 다시 검사한다. 지형의 좌우 상대 고도 표본은 산지의 근접성을 확인하는 자료이며 플레이 화면에서의 가시성 검증을 대신하지 않는다. 실제 눈높이 스크린샷과 함께 판단한다.

땅과 산은 매크로 씬 소유 재질에서 조금 더 어둡게 조정한다. 지형의 먹 농도와 능선 구분을 유지하며 C2·프롤로그 룩 및 전역 노출을 함께 어둡게 만들지 않는다. 색조 비교는 동일한 V3 지형·카메라에서 재질 값만 복원해 기록한다. 지형 전후 자료는 경로와 거점 이동으로 카메라 위치가 달라질 수 있다. V2 자료는 `Art/World/WorldMacro/Versions/v2_before_route_relief`에 보존하고 V1 이력도 유지한다. 이전 버전의 검사 통과를 새 지형에 자동 승계하지 않는다.

## 후속 조정 — 더 짙은 지면·강토색과 이동 흐름
V4는 V3보다 땅과 산을 더 어둡게 하고, 강토에 대응하는 오행색을 지면에 옅게 더한다. 매크로 씬 소유 셰이더·재질과 지역 마스크에서 조정하고 C2·프롤로그·공용 자산과 전역 노출은 보존한다. 낮은 채도와 부드러운 지역 전이를 사용하며 밝은 안내선이나 선명한 색 경계로 지형을 표시하지 않는다. 최종 농도와 색의 적절함은 실제 스크린샷으로 사용자에게 확인받는다.

기존 산지 높이를 기본적으로 유지하면서 실제 지면·교량 콜라이더를 사용해 경사, 급격한 단차, 지지 누락과 경로 폭의 흐름을 확인한다. 문제가 생긴 구간은 경로 선형과 교량 접근을 우선 보완한다. 표본의 실제 충돌 지지 검사와 플레이어 입력·가마의 전 구간 완주는 구분하며, 검사하지 않은 항목은 미검증으로 남긴다.

V3 자료는 `Art/World/WorldMacro/Versions/v3_before_realm_tint`에 보존한다. 이번 주 비교는 V3→V4 색조·강토색 및 이동 흐름이다. 기존 V2→V3 산지 비율은 V3 기록으로 분리하며 새 경로의 시야·통행 판정으로 재사용하지 않는다. 정지 이미지와 검사 보고서만 갱신하고 영상은 제작하지 않는다.

## 후속 조정 — 이동에 따른 강토별 하늘
매크로 씬에만 `RegionalInkSkyProfile`을 연결한다. 지역 폴리곤과 카메라 위치의 거리를 사용해 여러 강토의 하늘색·구름 농도를 연속 혼합하며, 경계를 넘는 순간 하늘 재질을 교체하지 않는다. 초기 BlendDistance는1200m, 시간 응답은2초로 둔다 [TEST]. 시간 응답은 지수 보간의 기준값이며2초 만에 전환이 끝난다는 의미가 아니다.

지평선과 기존 수묵 하늘의 공통 구름 형태·이동 기준을 유지하고 상공의 색과 농도 차이를 절제한다. 실행 중 임시 재질 사본 하나를 갱신하며 C2·프롤로그의 저장된 설정과 원본 하늘 재질은 보존한다. 지형과 경로를 다시 생성하지 않는다. 별도 `RegionalSky` 정지 이미지 검토를 만들고, 기존 V4 지면색 비교17장은 당시 기록으로 유지한다. 위치별 정지 이미지와 실제 이동 중 전환 검사는 구분한다. 영상은 제작하지 않는다.

## 수면 시안 — 현 상태 보존·보류
#209에서 수면을 먼저 제작했으나, 사용자가 자연스럽지 않다는 시각 판단과 함께 추가 수정을 중단했다. 현재 수면 파일·설정·검토 자료를 보존하고, 수면 개선을 건축물·가마 제작의 선행 조건으로 두지 않는다. 수면 외형 승인이나 완성으로 기록하지 않으며 이번 후속 작업에서 셰이더·물가·합류 형태를 다시 조정하지 않는다.

보존하는 수면 시안의 제작 기준은 원천 중심선·지형과 공급자·술식 물 그래프를 보존한 매크로 전용 사본, 실제 지형 콜라이더에 맞는 폭, 중심선 기준 미터 UV, 물가·끝단의 감쇠, 부모 수면 영역에 따른 합류 절단이었다. 정점에 구운 지형 깊이는 정적 지면용이며 이동 물체 깊이와 구분한다. 공유 런타임 재질의 게임 시간·감속·일시정지와 WaterSurface 정지 이미지의 기존 검사 기록은 당시 실행 범위로만 남긴다. 이번 보류에 따라 추가 검사나 수정을 수행하지 않는다. 물 위 보행·수영·기존 전투 규칙을 추가하지 않으며 프레임 성능과 실제 크기 캡슐 완주를 수면 검증 통과로 대신하지 않는다.

## 후속 제작 — 실제 크기 캡슐·주요 건축물·마법가마
#210에 따라 **사용자 보행용 캡슐 설정 → 주요 건축물의 외형·접근 배치 → 마법가마 시제품** 순서로 진행한다. 기존 매크로 룩·지형 높이·큰 산계·수계·경로를 유지하며, 전체 지도 재생성이나 수면 재작업을 함께 수행하지 않는다. 각 제작 결과는 TEST이며 실제 완료한 부분과 후속 콘텐츠를 구분한다.

### 사용자 보행용 캡슐
- 매크로 씬 전용 플레이어를 높이 **1.75m**, 지름 **0.56m**의 실제 크기 캡슐로 설정한다. 발바닥을 로컬 원점으로 두어 캡슐 중심은 높이0.875m, 눈높이는 발 기준 **1.62m**로 맞춘다. 월드 스케일은1을 기준으로 확인하며 표시 메시와 충돌 캡슐의 크기를 일치시킨다.
- C2·Prologue·공용 `PlayerRig`를 수정하거나 이 크기를 공용 게임 규칙으로 승격하지 않는다. 이전 높이2m·지름1m 공용 캡슐로 얻은 매크로 충돌 검사 결과를 새 캡슐의 보행 검증으로 승계하지 않는다.
- 이번에는 에이전트가 전 구간 보행이나 자동 `CharacterController.Move` 주행 검사를 수행하지 않는다. 크기·발 기준·눈높이·연결된 카메라와 기본 조작을 설정하고, 실제 통행과 체감은 사용자가 직접 검사한다. 사용자 검사가 끝나기 전 완주·경사 통과·가마 통행을 통과로 기록하지 않는다.

### 주요 건축물
- 조선식 궁궐·성곽·동굴·사찰의 주요 외형과 접근 가능한 배치를 순차 제작한다. 기존 승인된 낮은 채도·수묵 농도와 지역 분위기를 유지하며, 건축물이 현재 지형에 맞도록 배치한다.
- 이미 보유한 에셋을 먼저 확인하고 재사용한다. 공급자 원본은 보존하며 과도하게 무거운 모델은 원본 그대로 다량 배치하지 않는다. 필요한 사본의 메시·재질·LOD와 단순 충돌체를 정리하고 실제 삼각형 수·재질 수·배치 수를 기록한다. 기존 자산으로 해결되지 않는 주요 파츠만 이미지 → Meshy → Blender 제작으로 보완한다.
- 출입구·통로·계단·마당과 동굴 입구·내부의 연결은 새 캡슐 치수에 맞춰 구성한다. 시각적 입구만 만들고 콜라이더로 막는 배치를 피한다. 지형을 다시 높이거나 길을 재설계하는 대신 현 지형에 맞는 기단·접근부·실내 배치를 사용한다. 치수·배치 확인과 사용자의 실제 보행 결과는 따로 기록한다.
