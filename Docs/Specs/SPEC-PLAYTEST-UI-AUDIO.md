# SPEC-PLAYTEST-UI-AUDIO — Recraft HUD · ElevenLabs 효과음

Lifecycle: ACTIVE · State: TEST · 2026-09-14

사용자의 Recraft/ElevenLabs 제작 요청을 `W_WorldMacro_Playtest`에 적용한다. 근거는 ART-UI, ART-COLOR, ART-AUDIO와 SPEC-WORLD-MACRO-PLAYTEST다. 기존 빌드 후보와 공급자 원본, C2, 공용 PlayerRig를 보존한다.

Recraft에서 먹 획 HP, 투명 먹물병 테두리, 일획 먹 원 레티클, 상호작용 배경을 제작한다. 원본 SVG와 Unity용 투명 PNG를 함께 남긴다. 생성 이미지에 문자를 넣지 않고 실제 한국어 텍스트를 사용한다. HUD 화이트리스트 네 항목 안에서만 표현하며 HP 감소, 먹의 액면, 락온/그로기/패링 상태를 기존 서비스 값으로 표시한다. 기존 씬은 스킨 미지정 시 이전 HUD를 유지한다. 위기 먹 번짐은 시야 중앙을 침범하지 않게 제한한다.

2026-09-14 외부 플레이테스트 적용 범위에서는 **먹병 대신 수평 먹 바를 사용한다.** 먹 잔량을 즉시 비교할 수 있는 가는 먹 획이며 기존 `InkPool` 값을 읽기만 한다. 먹병 생성 원본과 Art 방향은 보존하지만 이번 플레이테스트 연결 대상은 아니다. HP·먹 바·레티클·프롬프트 외의 소지품·기록·술식 도감·지도·옵션은 상시 전투 HUD가 아니라 플레이를 멈추고 여는 모달 화면이다. 탐험으로 드러난 지형만 보이는 미니맵과 펼친 한지 전체 지도는 [SPEC-PLAYTEST-MENUS](SPEC-PLAYTEST-MENUS.md)를 따른다.

ElevenLabs로 짧고 건조한 붓/한지 마찰, 시전, 피격, 받아치기, 먹 회수, 상호작용/휴식, 소환 효과음을 제작한다. 거문고의 짧은 현 울림과 나무·돌·쇠·불·물의 물성을 중심으로 하며 음악·대사·과장된 영화 예고편 충격음은 추가하지 않는다. 오행별 실제 시전과 실제 피해/패링 이벤트를 따라 재생한다. 소환은 승인된 정적 외형의 등장·소멸에만 연결하고 공격/AI를 추가하지 않는다.

시청각은 읽기 전용 결과 구독자다. 인식 좌표·필세·시전 판정·먹 소비·데미지·시간을 변경하지 않는다. 효과음 재생 풀은 최대 12개, 프레임별 할당/AudioSource 생성 없이 운용하며 연속 접촉은 짧은 쿨다운으로 제한한다. 사운드 미지정은 무음 폴백이고 일시정지·비활성·장면 종료에 정리한다. 위치가 있는 타격/소환은 공간음, HUD/플레이어 피드백은 2D로 분리한다.

초기 제작은 Recraft 최대 5회(예상 400 API units = $0.40), ElevenLabs 총 30초 이내(보수적 예상 1,200 credits 이내)로 제한한다. 자동 결제/충전·무제한 재시도는 하지 않는다. 성공 원본을 재사용하고 요청 ID·모델·프롬프트·파일 해시·예상/응답 소비량을 기록한다. 계정 사용량 조회 권한이 없으면 실제 사용량 미검증을 명시한다.

순서: 연결/원장 → UI와 효과음 생성 → 플레이테스트 전용 연결 → 실제 서비스 이벤트와 중복/정리 검사 → 1080p 정지 이미지와 HTML 청음 페이지. 청음의 한국적 인상과 최종 음량은 사용자 검토로 남긴다. 캡처는 순차, 시스템 커밋 85% 이상에서는 새 촬영 중단. 영상/자동 보행 완주는 하지 않는다. 새 메뉴·지도·저장 마이그레이션·파편 수집은 이 문서의 기존 HUD/오디오 검사 통과를 뜻하지 않으며 각각의 실제 입력·독립 실행 검사는 아직 수행 전이다.
