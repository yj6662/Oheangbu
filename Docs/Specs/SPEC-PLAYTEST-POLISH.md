# 플레이테스트 동작·먹·음향·식생·지도 개선

상태: TEST / 사용자 승인 계획(2026-09-14). 이 문서는 현재 플레이테스트 씬에 선택적으로 연결하는 변경을 정의한다. 공용 C2와 공급자 원본의 규약을 일괄 변경하지 않는다.

## 이동과 손

WASD 2.2m/s, Ctrl 달리기 5.5m/s, Shift 기존 회피, Space 약 0.75m 지상 점프다. 2026-09-14 후속 결정에 따라 C는 웅크리기 전환(1.2m/s, 캡슐1.25m), X는 정지 상태의 바닥 착석·기립으로 분리한다. 착석은 회복·저장을 수행하지 않는다. 웅크린 이동·작도·갈무리는 허용하며 점프·달리기·회피 시작은 서 있을 때만 허용한다. 낮은 천장은 일어서기와 탑승을 막고, 작도·갈무리 중 C 입력은 무시한다. 기존 점프 금지는 이번 저상 점프에 한해 완화한다. 등반·수영·자동 이동은 추가하지 않는다. 국을 요구하던 접근 구간을 점프로 우회할 수 있는지는 별도 통행 검사 대상이다.

애니메이션은 실제 이동·접지·수직 속도를 읽으며 Root Motion을 끈다. 공중·착석 중 작도·갈무리·회피 시작을 차단하고 착지 후 새 입력을 요구한다. 탑승 좌석 상태와 바닥 착석은 분리한다. 차량 Space 제동과 모달 입력 차단을 유지한다.

사용자가 선택한 A 파지를 기준으로 손·손목 메시와 웨이트를 국부 수정한다. 첨부 Mixamo FBX9개는 C02 고정54본에 리타깃하며 평소 팔은 이동 클립을 따르고 손목 보정만 제한적으로 더한다. 근접 어깨 보정은5cm 이내이며 길이와 원시 획을 변경해 도달 실패를 숨기지 않는다. 수치 검사와 실제 외형 승인은 구분한다.

## 먹과 음향

먹 획득은 실제 양수 증가량만 알림으로 보낸다. 복원·초기화·만충 상태는 획득 강조에서 제외한다. 표현은 주 먹줄기 하나와 가는 결, 실제 변형된 붓끝의 수렴으로 구성하며 경제·피해·인식 시점은 유지한다.

음원 원본을 보존하고 편집 WAV를 분리한다. 짧은 효과의 손실 재압축, 역할별 중첩과 갑작스러운 재생 교체를 줄인다. 전체·게임·UI·갈무리 믹싱과 기존 옵션을 연결한다. 소스·오프라인 합산·실제 Unity 출력 검증을 구분한다. 디지털 클리핑이 없는 소스를 클리핑된 원본이라고 기록하지 않는다.

## 식생과 지도

식생은 보유 에셋, 256m 셀, 인스턴싱을 사용한다. 통행면·입구·탑승 공간은 보호하고 낮은 풀의 제외 폭을 줄인다. 동일한 확정 수목 위치·크기로 메시와 카드 LOD를 연결한다. 청림 기준을 먼저 적용한 후 5강토로 확장한다. 전역 지형 재생성과 수동 확정 배치 덮어쓰기는 금지한다.

지도는 생성한 먹 삽화와 실제 지리 벡터를 조합한다. 월드 외곽·좌표 변환·물길·경로·시설 좌표는 기존 데이터가 정본이다. 큰 산맥·강·지역명은 기본 공개하고 작은 길과 시설은 기존 탐험·발견 상태로 제한한다. 미니맵과 전체 지도는 같은 자료를 공유하며 가로·세로 접힌 한지 연출, 실내 지도, 저장과 표식 기능을 유지한다. 예전 미니맵 금지는 결정214·215 및 이번 결정으로 플레이테스트에서 이미 해제되었다.

발 미끄러짐10cm·관통2cm, 실제 붓끝1080p2px와 30/60/120fps는 검증 목표다. 실행하지 않은 실제 입력·천·성능 검사를 통과로 표시하지 않는다. 8.33ms는 목표이며 실제 측정 자료와 구분한다. 영상·자동 전체 보행은 만들지 않는다. 캡처는 순차1920×1080이며 시스템 커밋85% 이상에서는 새 캡처를 시작하지 않는다. 빌드는 손 선택 후 통합 검증까지 완료한 마지막에 한 번만 만든다.
