메뉴의 오행부는 첨부 이미지처럼 끈으로 매단 금빛 금속 3D 패찰로 표현한다. 세로로 긴 판의 모서리는 깎이고, 상단 고리에는 여러 색의 굵은 꼬임끈이 연결된다. 앞면에는 원형 소켓 다섯 개를 위 1개·가운데 3개·아래 1개로 배치한다. 판의 두께, 돌출된 소켓 테두리와 얕은 음영이 정면에서도 읽혀야 한다. 금속 표면의 닳음·긁힘·두드린 자국은 참고하되 글자 형태와 내용은 이미지 속 문자를 그대로 확정하지 않는다.

소켓과 삽입물은 분리된 파츠로 만들고 실제 보유 상태와 연결한다. 미획득 오상이나 성장 효과를 이미 얻은 것으로 보이지 않게 한다. 끈을 기준으로 매달리는 중심과 모델 피벗을 정리하고, 메뉴에서 가벼운 움직임과 재질을 검토할 수 있는 별도 프리팹으로 납품한다. 원래 차패·저장 상태의 의미를 바꾸지 않는다. 기존 평면 메뉴는 새 모델과 연결이 검증될 때까지 기준선으로 유지한다.

이번 변경에는 이미지 생성·Meshy 유료 생성·Blender 모델 제작·기존 차패 모델 교체가 포함되지 않았다. 제작 시 사용 도구·비용·메시 예산과 내보내기 형식은 해당 작업에서 명시한다. 금속 표면을 차체처럼 강하게 발광시키거나 소켓마다 효과를 상시 재생하는 해석을 추가하지 않는다.

기록첩 메뉴는 별도로 제거한다. 조사·NPC 완료 ID와 구버전 저장의 `ui.records`는 호환성을 위해 보존하며 패찰 아트 제작의 입력 데이터로 임의 전환하지 않는다.
