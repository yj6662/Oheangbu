# SPEC-SPELL-VFX120 — 한국적 술식 표현 전면 제작

상태: **TEST** · 실행: 제작·검수 진행 중 · 2026-09-09 · 결정 #189

사용자 요청: 기존 술식 VFX를 새 표현으로 제작하고 120개를 모두 확인할 수 있도록 한다. Art Bible의 수묵·담채 정체성을 유지하면서 어울리는 보조 색을 허용한다. KoreanTraditionalPattern_Effect의 실제 한국적 형태를 활용한다. 필요한 자산이 없을 때만 Meshy/Blender를 사용한다.

## 범위와 데이터

- CSV 원장은 120행이며 100개 배정, 20개 의도적 공백이다. 공백의 신규 규칙 배정 여부는 질문 중이다. 공백을 임의 공격으로 바꾸지 않는다. 카탈로그에는 120칸을 모두 만들고 공백의 상태를 명시한다.
- 실제 SpellBook_Proto는 현재 15개만 실행 가능하다. VFX 카탈로그 완성과 게임 기능 120개 구현을 혼동하지 않는다. 신규 VFX는 모든 배정 어휘를 위한 표현 자산을 갖추고, 기존 게임 시전 경로의 표현을 교체한다.
- 원시 작도, 인식, 필세, SpellResolver, SpellBook, 피해/가드/회복 시계는 변경하지 않는다. 이미 확정된 AreaImpactPlan과 비행시간을 읽는다.
- 기존 VFX 원본과 캐릭터 실험을 보존한다. 새 출력은 Art/SpellVFX120, 신규 Unity 자산은 Assets/_Project/Art/SpellVFX120이다.

## 표현 계약

- 글자마다 동사를 읽을 수 있는 실체·운동·실루엣·개시/진행/착탄/소멸을 저작한다. 같은 링의 색을 바꾼 것으로 120개를 계산하지 않는다.
- 목: 생장과 굽힘, 화: 상승과 소진, 토: 쌓임과 무게, 금: 벼림과 절단, 수: 낮게 흐르고 스밈. 한국 회화·공예의 구름/연화/회문/매듭/민화 형태를 사용한다.
- 구 팔레트 하나·무텍스처 규약은 이번 새 VFX에 한하여 대체한다. 절제된 단청 안료·비색·구리·옻칠 등 보조 색과 실제 무늬 텍스처를 허용한다. 종교/문자 도상을 무작위 마법 로고로 쓰지 않는다. 네온과 화면 전체 백색 포화는 피한다.
- 새 VFX 컴포넌트가 수명과 색을 소유한다. 기존 PatternEffectLifetime의 일괄 백색화/틴트를 적용하지 않는다. 생성/소멸 자원 누수, 원본 재질 변경을 금지한다.
- 문양 완제품의 수십~백여 개 ParticleSystem을 복사하지 않고 텍스처/메시를 작은 구성으로 재사용한다. 표현은 충돌체·게임 판정 객체를 만들지 않는다.

## 검수

1. 전체120 유일 ID·출처·recipe·프리팹·재질 참조, 컴파일/셰이더 확인.
2. 동일 검수 씬에서 모든 효과의 개시·진행·착탄·소멸 프레임/영상. 재생 선택기와 목록 제공.
3. 게임에 연결된 15개 실제 시전의 기존 목표점/비행/가드 시계 전달 확인. 나머지 자산은 카탈로그 상태로 구분.
4. 전투 배경과 밝은/어두운 배경에서 실루엣, 프레임당 비용·동시 수명 종료/잔존객체를 확인.
5. PASS/FAIL/UNVERIFIED를 항목별 기록. 자동 렌더 생성과 실제 육안 검수는 구분한다.
