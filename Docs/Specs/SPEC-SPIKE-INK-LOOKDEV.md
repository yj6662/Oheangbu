# SPEC-SPIKE-INK-LOOKDEV — 먹 셰이더·한지 룩 스파이크

| 항목 | 값 |
|---|---|

| 작성 | 2026-08-27 |
| 선행 | SPEC-SPIKE-BRUSH-RENDERER(형태 언어·UV 계약) — 관성 폐기 확정으로 형태 층 동결 |
| 근거 | ART-INK LOCKED · ART-COLOR LOCKED · ART-UI LOCKED(먹 미터 보조 언어) · PROD(Ribbon+Noise Cutout 규격) |

## 1. 목적

스파이크 ③(먹 셰이더·한지 머티리얼)의 정본. 붓 획을 "폴리곤 띠"가 아니라 **한지에 먹으로 그은
획**으로 보이게 하는 셰이더·머티리얼 층을 확정한다. 기하(형태 언어 4축)는 선행 Spec에서 동결됐고,
이 Spec은 그 위 **질감 층**만 다룬다 — 예준 지시(2026-08-27): "붓글씨의 비주얼 부분은 아트에서 해결."

## 2. 소비하는 계약 (선행 Spec §4 — 변경 금지)

셰이더는 아래 세 채널만 읽는다. **기하를 재요구하지 않는다** — 여기서 Ribbon 수정이 필요해지면
계약 위반이므로 선행 Spec으로 되돌아간다.

| 채널 | 의미 | 이 Spec에서의 용도 |
|---|---|---|
| UV0.U | 획 진행률(기필 0 → 수필 1) | 붓결 텍스처 흐름·기필/수필 질감 차이 |
| UV0.V | 폭 방향(가장자리 0/1, 중앙 0.5) | **갈필이 가장자리부터 갈라지는** 좌표 |
| 정점 알파 | 먹 농도(속도·먹 잔량 반영) | Noise Cutout 임계·번짐 강도 |
| **UV1.x** | **점 탄생 시각**(이 Spec에서 계약 확장 — 2026-08-27) | 점 나이 기반 번짐(`age = 지금 - 탄생`) |

> 계약 확장 사유: 번짐은 "획 완료 후"가 아니라 **붓이 지나간 자리 뒤를 따라** 진행한다
> (예준 지시 — 그리는 순간 얇고, 빠르게 번지다 느려짐). 점마다 나이가 달라야 하므로
> 탄생 시각을 정점 채널로 싣는다. UV0·정점알파의 기존 의미는 불변.

## 3. Goals

1. **먹 획 전용 셰이더(URP Unlit·정점색 소비)** — 현행 폴백 `Sprites/Default` 대체.
   근흑색 임시 완화의 원인이던 "정점색이 제대로 안 먹는 문제"를 여기서 근본 해소.
2. **Noise Cutout 갈필** — 노이즈로 획을 갉아낸다. V 가장자리(0/1)부터 갈라지고,
   정점 알파(농도)가 낮을수록 심해진다 → ART-UI "먹 부족 시 획이 갈필로 그어짐" 실현.
3. **번짐(bleed)** — 그린 후 먹이 가장자리로 스미는 시간 연출(예준 요청 2026-08-27).
4. **겹침 블렌딩 근본 해결** — 획 겹침 과도 진해짐(선행 Spec에서 근흑색으로 임시 완화·이관분).
5. **한지 머티리얼** — 작도면 배경(#F7F1E4 · ART-COLOR). 종이 소지(素地) 질감.
6. **[TEST 승격 트랙]** ART-INK의 [TEST] 항목 실측: HDR intensity 상한·Bloom threshold·역번짐 셰이더
   중 **이 스파이크 범위는 획 자체뿐** — 역번짐·광원은 §7 참조.

## 4. 불가침 (위반=버그)

- **인식 무접촉**: BrushRender asmdef는 Drawing을 참조하지 않는다(컴파일 타임 강제 유지).
  셰이더·머티리얼 교체 전후 동일 입력의 인식 결과 불변.
- **필세 불개입**: 갈필·번짐·농도는 순수 비주얼 — 위력은 형×세뿐(ART-INK LOCKED).
- **발광 상한**: 획은 발광하지 않는다. 술식 순간 Emission(중등 광원)은 §7에서 범위 결정.
- **데이터 주도**: 셰이더 수치는 머티리얼 에셋 소유(Unity 표준 — 머티리얼 자체가 데이터).
  런타임에서 시간에 따라 구동되는 값(번짐 진행 등)만 코드가 만지되, 그 속도·범위 상수는
  `BrushStyleSO`의 룩 섹션(신설)에 둔다. 코드에 미감 상수 금지.

## 5. 설계 방향 (제안)

### 5.1 셰이더 — 손 HLSL (URP Unlit 변형)

Shader Graph가 아니라 **텍스트 HLSL**을 제안한다: 1인+AI 파이프라인에서 텍스트=리뷰·버전관리·AI
협업이 전부 유리하고, 필요한 기능(정점색 × 노이즈 cutout × 시간 번짐)은 수십 줄 규모다.

```
알파 = 정점알파
     × EdgeMask(V)                  // 가장자리 감쇠 곡선
     × step(cutout임계(농도,V), noise(UV·획시드))   // 갈필 — 농도가 낮을수록 임계 상승
번짐 = 획 완료 후 t: 알파 스미어 반경·가장자리 소프트닝이 t로 완만히 증가(메시 불변)
```

### 5.2 번짐 — 점 나이 기반, 붓 뒤를 따라 진행 (RT 시뮬레이션 아님)

각 점의 탄생 시각(UV1.x)과 전역 현재 시각(`_InkNow`, `Shader.SetGlobalFloat` 1개)으로
셰이더가 점마다 `bleed = 1 - exp(-age/τ)`를 계산한다 — **그리는 순간은 얇고(시작 폭 비율),
빠르게 번지다 점점 느려지며** 여유 폭(margin)까지 퍼진다. 번짐 진행이 가장자리 소프트닝과
갈필 틈 메움도 함께 구동한다. 메시·인식 데이터 불변, 획별 프레임 갱신 없음(전역 float 1개).
RenderTexture 유체 시뮬레이션은 스파이크 과잉으로 배제(§8).

- 여유 폭은 기존 `_widthMultiplier` 훅으로 확보: 메시를 (1+margin)배 폭으로 만들고
  셰이더가 V를 재매핑해 명목 가장자리를 안쪽에 둔다(빌더 무수정).

### 5.3 겹침 — 스텐실로 「한 획 안」 자기 겹침 1회 제한

실제 먹은 **획이 겹치면 진해지는 게 맞다**(붓을 두 번 지나간 자리). 문제는 한 획 안에서
모서리·캡이 스스로 겹쳐 얼룩지는 쪽이다. 따라서:
- 획 내부(같은 메시): 스텐실로 픽셀당 1회만 찍는다 — 캡·꺾임 얼룩 소멸
- 획 사이: 알파 블렌딩 자연 누적 유지 — 겹친 획이 진해지는 먹의 성질 보존

### 5.4 한지 — 정적 머티리얼 1장 [검증 소품 — 월드 요소 아님]

한지색(#F7F1E4) + 저주파 섬유 노이즈. 스파이크에서는 텍스처 1장(AI 생성 가능 — Recraft)
또는 프로시저럴 노이즈 중 저렴한 쪽. 월드 배치 규격은 LOOKDEV 밖(레벨 아트 몫).

> [2026-08-27 검수 명확화] **술식은 한지 위가 아니라 허공에 그려진다**(예준 확인).
> S3의 HanjiBackdrop은 기본 회색 배경에서 먹색·갈필·번짐을 판독하기 어려워 깔아 둔
> **검증용 대비판**일 뿐, 게임 화면 요소가 아니다. 실제 작도는 3D 월드 위에 겹쳐 그려지며,
> 한지 머티리얼의 정식 용처(UI·서사 소품 등)는 ART 소유로 별도 결정.

## 7. 술식 순간 Emission — 이 스파이크에 포함 (§11 결정 4 · 예준 개정)

ART-INK 광원 3등급의 중등(술식): "획이 그어지는 순간 빛나고 먹으로 가라앉는다."
제안(이연)과 달리 **포함으로 결정** — 커밋 시 글자가 **해당 오행 속성색**으로 순간 발광한 뒤
먹으로 가라앉으며 소멸한다. 추가 지시(계획 검토 시):

- **플래시 강도는 필세(형×세) 위력에 비례한다** — 잘 그린 글자일수록 강하게 빛난다.
  위력 공식의 정본은 Spellcraft 소유(미구현)이므로 스파이크는 DrawnLetter의
  정확도(AverageDistance)·속도(strokeDuration)로 근사치 p(0..1)를 만든다 — **TEST, §10 예외 2**.
- 속성색은 초성→오행 매핑(작도어휘 CSV 3열)으로 결정. 5색 실수치는 ART-COLOR가 [TEST]이므로
  placeholder를 SO에 두고 TEST 표기(§10 예외 1).
- 피격·불발은 빛나지 않는다(발광은 성공한 술식만) — 대신 **먹이 증발하듯 소거**(디졸브).

### 11.1 구현 확정 기술 사항 (설계 검증에서 확정)

- **스텐실 Ref는 MaterialPropertyBlock으로 세팅 불가**(렌더 스테이트는 Material 값만 읽음)
  → 획별 머티리얼 인스턴스 + 획 파괴 시 머티리얼 동반 파괴. SRP Batcher는 셰이더 단위라 배칭 유지.
- 노이즈 도메인은 UV.U 금지(그리는 동안 U 재정규화로 결이 흘러내림 + 캡 U 상수)
  → **오브젝트 공간 위치** × 스케일 + 획 시드.
- **프리멀티 알파**(`Blend One OneMinusSrcAlpha`) — 플래시를 알파 독립 가산 성분으로.
- Linear 색공간에서 Color32 정점색 무변환 → 프래그먼트 `SRGBToLinear`.
- 투명 소팅: `sortingOrder = 획 인덱스`. 스텐실 Ref는 1..255 순환·전체 소거 시 리셋.
- `clip(alpha - 0.004)` — 투명 프래그먼트의 스텐실 스탬프 방지.
