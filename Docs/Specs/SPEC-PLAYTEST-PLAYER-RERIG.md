## 진단과 리그 선행 검사

1. 기준 파일에서 부모·오브젝트·본 행렬, 단위·정지 자세, Armature 대상, 모디파이어 순서, 텍스처 연결, 실제 손가락/엄지 형태를 기록한다. 이미 스킨된 모델에 전역 변환을 무작정 적용하거나 골격을 겹쳐 넣지 않는다.
2. 양손의 손목·손바닥·엄지 대립·각 손가락 관절 위치를 실제 메시 위에서 정한다. 손등과 손바닥 방향을 구분하고, 손가락 개폐 때 이웃 손가락·소매가 따라오지 않게 웨이트를 제한한다. Humanoid 손가락 매핑과 기존 몸 본의 연결을 유지한다.
3. 새 손 웨이트는 정점당 최대 4개를 기본으로 하되, 기존 A2 몸 웨이트 전체를 4개로 잘라내지 않는다. 기존 722개 정점의 다섯 번째 영향은 이전 개선의 일부다. 몸 영향을 변경하면 같은 자세의 변형 대조가 필요하다.
4. 모든 변형 정점의 유한·비음수·유효 본 할당과 합계 오차 0.0001 이하를 검사한다. 사용하지 않는 제어 그룹은 변형 웨이트 합계에서 제외한다. 손가락 본 길이·좌우 부모 연결·중복 이름을 검사한다.
5. 제작 모션에 앞서 정적 진단 포즈를 확인한다. 손 개방→반쥠→파지→개방, 엄지 대립, 팔 내리기, 전방 뻗기, 머리 위 올리기, 팔꿈치 깊은 굽힘, 몸통 비틀기, 스쿼트의 정지 표본을 사용한다. 기존 움직임을 숨기기 위해 포즈 범위를 줄이지 않는다.
6. 동일 버전의 수치·다각도 이미지와 FBX/Unity 스킨 검사를 통과한 범위만 `RIG_PASS`로 기록한다. 몸/의복/손 중 미해결 범위가 있으면 각각 표시하고 전체 리그 통과로 합치지 않는다. 구조를 바꾸면 관련 검사를 다시 수행한다.

## 파지와 동작

- 오른손 붓 파지를 기본으로 하며 평소에는 붓 든 팔을 자연스럽게 내린다. 자루는 고정 길이를 유지한다. 손가락을 닫는 것만으로 파지를 완료 처리하지 않고 엄지·검지·중지의 피부와 실제 붓대 표면을 검사한다.
- 초기 정적 접촉 목표는 주 접촉부 간격 1.5mm 이하·관통 0.5mm 이하다. 손·붓의 실제 월드 크기로 측정한다. 본/소켓 거리나 부호 없는 최근접 거리만으로 이 값을 대신하지 않는다. 메시의 닫힘·법선 신뢰성이 부족하면 관통은 미검증으로 기록한다.
- 손바닥과 손가락 전체의 삼각형 표면도 확인해 정점은 밖에 있지만 면이 자루를 가로지르는 오류를 찾는다. 얇은 자루 부근은 0.5mm 간격 표본 또는 실제 교차 검사와 근접 이미지를 함께 사용한다.
- 정적 리그 검사 이후 기존 B2 Idle, B1 Walk/Run/Attack 사본을 사용해 붓 휴대·작도 준비/유지/복귀·갈무리 표현을 보완한다. 기존 무기 없는 Attack 재생을 붓 동작 완성으로 표시하지 않는다.
- 움직임은 기존 실제 이동 속도에 맞춘다. 현재 Walk 기준 1.554m/s, Run 기준 4.5m/s와 Run 재생 배율 0.839는 기존 런타임 값이며 게임 이동 속도를 애니메이션에 맞춰 바꾸지 않는다. Root Motion은 OFF다.
- 기존 달리기의 발바닥 관통은 파생 모델 전용 발 접지 컴포넌트로 보완한다. 실제 발바닥 스킨 표본과 발별 두 지면 광선을 사용해 관통한 발만 최대 7.5cm 들어 올린다. 무릎·발목의 회전으로 처리하며 뼈 길이·골반·플레이어 루트·카메라는 변경하지 않는다. 공중의 발, 탑승·비접지 상태에는 적용하지 않는다. 평면 진단은 경사·계단·실제 보행의 통과 근거와 구분한다.
- 새 본을 추가했더라도 기존 클립이 손가락을 자동으로 움직인다고 가정하지 않는다. 손가락 곡선 또는 Animator 이후 손 포즈 제어 경로를 명시하고 동일 본을 여러 경로가 덮어쓰지 않게 한다.
- 작도 입력은 기존 단일 입력 경로에서 읽는다. 인식 좌표·샘플링·필세·피해·시전 시점을 변경하지 않는다. 입력이나 시전이 연출 완료를 기다리지 않는다. 보행 숄더뷰와 기존 작도 시점·차량 전환 계약을 유지한다.
- 근접 표현을 추가한다면 월드 전신과 팔·붓 중복을 막고 메뉴/피격/모드 종료 시 복귀를 검증한다. 완성 전 범위 밖 기능을 활성 상태인 것처럼 보고하지 않는다.
