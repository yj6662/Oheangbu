# KTP 받아치기·플레이어 피격 VFX

상태: TEST · 2026-09-10

사용자 후속 지시: KTP Preview 씬의 에셋을 원래 미감 그대로 받아치기와 상대 공격에 피격될 때 사용한다. 이 작업은 기존 ㄱ·ㄴ 술식 제작 결과에서 이어지는 접촉 표현 작업이다.

- 받아치기 Success/Half는 확정 접점에, 플레이어 피격은 PlayerVitals.Damaged의 실제 양수 피해에만 재생한다. 무적 회피·실패 판정에는 성공 문양을 만들지 않는다.
- 원본 Fly 프리팹의 Explosion 계층을 직접 참조한다. 메시·공유 재질·색·방출 수·크기/속도/회전/시간 곡선과 활성 계층을 보존한다. 위치 재중심화·방향·전체 배율 및 그 배율을 위한 복제본 Hierarchy scaling만 허용한다.
- 피격 이벤트에는 접점/공격 방향이 없으므로 1인칭 카메라 전방에 월드 효과를 배치한다. 실제 충돌점으로 표시하지 않는다. 성공은 속성별 원본 선택, Half는 동일 원본의 절반 배율이다.
- 원본 루트의 한 주기(선택 원본은 5초)가 끝나면 반복 광채의 방출을 멈추고, 남은 입자가 원래 수명을 마치면 생성 계층을 제거한다. 씬 전환/배선 비활성에서도 제거한다. 방어막의 휘어짐·맥동은 유지하고 중복 native 타격만 억제한다.
- 피해·보상·가드·회피·인식 규칙은 유지한다. 신규 술식/다른 초성 제작과 적에게 가하는 모든 공격의 타격 교체는 이번 범위에 포함하지 않는다.
- 검증: Preview 출처, 원본 자산 해시 보존, 성공/반성공/실패 및 양수 피해/무적/치명타, 방어막 중복 억제, 실제 재생/렌더와 자연 종료, 컴파일 오류. 비주얼 최종 선택은 사용자 검토 대상이다.
