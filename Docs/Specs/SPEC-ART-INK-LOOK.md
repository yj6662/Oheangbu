## 1. 목적

작도 획과 술식 발광의 **수묵담채 톤 실수치**를 화면 실측으로 확정할 준비를 한다.
ART-COLOR·ART-INK의 [TEST] 실수치 트랙 중 **작도·술식 몫**을 이 Spec이 실측하고,
INK-LOOKDEV §13 백로그(거침·플래시·기필)를 같은 기준 아래 해소한다.
TEST→LOCKED 승격은 예준의 DECISIONS 기록으로만 이루어진다 — 이 Spec은 후보 수치와 판정 절차까지만 소유한다.

## 2. 상위 원칙 (참조 — 복제 아님, 전부 LOCKED)

- **저채도 세계, 의미 있는 색만 채도를 가진다**(ART-CHARTER). 고채도 "허용" 대상에 술법이
  있으나(ART-COLOR) 이는 허용이지 의무가 아니다 — 담채(淡彩)는 "옅게 물들이는" 채색이다.
- **빛은 전구가 아니라 먹이다**(ART-INK) — 술식은 중등 광원: 순간만 빛나고 먹으로 가라앉는다.
- **아트는 인식을 방해하지 않는다**(ART-CHARTER) — 가독·판독이 연출에 우선. 예준 검수 지적
  ("강한 채도는 이질감 + 가시성 저하")은 이 조항의 직접 적용이다.
- 오행 색 이름(ART-COLOR): 목=청록(생죽색) / 화=주홍 / 토=황토 / 금=은백(광택질) / 수=현색(깊은 청묵).

## 4. 설계 (후보 — 실측으로 확정)

### 4.1 오행 담채 팔레트 — 기본 5색 [승인: 2026-08-27 예준] + 상태 바리에이션 [TEST]

채도를 HSV 기준 40~55%로 눕힌 담채 톤. 금은 색이 아니라 광택질이 정본이므로 단색 근사는
명도·저채도 회백으로 두고 광택 표현은 후일 트랙.

**정본은 「기본색 × 상태 변환 규칙」이다** — 상태별 색을 낱개로 찍지 않는다. 새 상태가
생기면 변환 규칙 하나를 추가하면 팔레트 전체가 일관되게 파생된다(드리프트 방지 + 데이터 주도).
변환 규칙은 전부 ART-COLOR LOCKED 조항의 수치 번역이다:

| 상태 | 변환 규칙 [TEST] | 근거(LOCKED) |
|---|---|---|
| **술식**(플래시) | 명도 +10~15%, 채도·색상 불변 | 중등 광원 — 순간만 빛나고 먹으로 가라앉는다 |
| **오염** | 검보라 먹 `#332B36`과 **55% 혼합** — 번진 먹이 색을 삼킨다 | "속성 오염 = 해당 오행색의 **탁화**" · 오염은 빛나지 않는다 |
| **정화** | 한지 소지 `#F7F1E4`와 **35% 혼합** — 어둠이 물러나 소지가 드러난다 | 역번짐 — "빛 퍼짐 = 먹의 물러남, 소지(素地)가 드러난다" |

파생 후보표(규칙 적용 결과 — 실측 출발점):

| 속성 | 기본 [승인] | 술식(플래시) | 오염(탁화) | 정화 |
|---|---|---|---|---|
| 목 | `#4E8069` | `#5A9379` | `#3F514D` | `#89A894` |
| 화 | `#B85C38` | `#CE673F` | `#6F4137` | `#CE9074` |
| 토 | `#B08D4A` | `#C59E53` | `#6B573F` | `#C9B080` |
| 금 | `#AEB4BA` | `#BFC6CD` | `#6A6971` | `#C8C9C9` |
| 수 | `#33475C` | `#3D556E` | `#333847` | `#77838C` |

- 데이터 구조: `ElementPaletteSO`에 상태 변환 2종(혼합 대상색·비율)을 필드로 추가하고
  파생색은 **계산으로** 얻는다(`GetColor(속성, 상태)`) — 25개 베이크는 규칙과 어긋날 위험이 있어 피한다.
- 판독 기준: 같은 속성의 기본/오염/정화가 한 화면에서 구분되되, **오염이 항상 가장 어둡고 탁해야**
  한다(빛=안전 / 번짐=위험의 읽기 보존 — §5 기준 1b).
- 스코프 주의: 오염·정화가 **어디에 쓰이는가**(적·지형·이펙트)는 Combat/LDB 소유 — 이 Spec은 색 어휘만 정한다.

### 4.2 플래시 합성 — 가산 중심에서 틴트 중심으로

현행(가산 `+ 색×강도`)은 LDR에서 백색 포화 → 무슨 속성이든 노랗게 뜨고 담채가 깨진다(검수 지적).
개정안: **먹색→속성색 보간(틴트)이 주역, 가산은 미량.**

```
rgb = lerp(먹색, 속성색, tintK · flash01) × alpha + 속성색 × (addK · flash01)
tintK ≈ 0.85 (피크에서 획이 속성색으로 "물든다")
addK  ≈ 0.25 이하 (빛의 기운만 — 백색 포화 절대 금지)
```

판정 문장: **"피크에서도 무슨 속성인지 색으로 읽혀야 한다."** 강도·시간 곡선은 SO 유지.

### 4.3 거침 — 다림질을 덜고, 가장자리를 흔든다

두 겹으로 접근한다(전부 기존 파라미터·셰이더 확장 — 기하 계약 불변):
- **보정 완화**: `_positionSmoothing` 2→1, `_widthSmoothing` 2→1, `_widthNoise` 0.08→0.12.
  꺾임(折)이 살고 폭의 유기적 떨림이 커진다.
- **가장자리 지터(셰이더)**: 가장자리 판정 `s`에 저강도 오브젝트 공간 노이즈를 더해
  윤곽이 미세하게 흔들리게 한다(신규 `_EdgeJitter` ≈ 0.05~0.1). 갈필(농도 연동)과 별개로
  **항상 존재하는** 종이 위 먹의 요철이다.

### 4.4 기필 — 반원의 기하가 드러나지 않게

원인: 장봉 캡의 매끈한 반원 외곽이 그대로 노출. 후보 2단:
- (a) **가장자리 지터가 캡에도 적용**(4.3과 같은 메커니즘 — 캡 V 규약이 동일해 공짜) → 1차 실측
- (b) 부족하면 **비대칭 캡**: 진행 방향으로 살짝 눌린 부채꼴(기필의 "댄 붓" 형태) — 빌더 수정 필요
(a)로 충분한지 먼저 보고 (b)는 그때 결정한다.

### 4.5 발광 상한 실측 [ART-INK TEST 승격 트랙] — Bloom 채택 (결정 1 · 2026-08-27)

예준 결정: **"낮은 채도로 다소 화려한 Bloom" 채택 — 속성에 맞는 효과가 같이 나오게.**

- 합성 구조: 틴트(주역 — 획이 속성색으로 물듦, LDR 안전) + **가산 성분을 HDR로**(`_FlashAdd` ≈ 1.5)
  올려 Bloom이 **속성색 그대로** 번지게 한다. 채도는 팔레트가 이미 담채이므로 글로우도 담채.
- Volume: S3에 Global Volume + Bloom(threshold ≈ 1.0 — 플래시 가산만 넘도록, intensity는 실측).
  카메라 포스트프로세싱 활성. 지속 Emission은 여전히 0 — 획 평상시는 threshold 아래(발광 상한 준수).
- ~~해석 주의: "속성에 맞는 효과" = 발광이 속성색을 띠는 것까지~~ → **정정(예준 2차 검수):**
  "다소 화려"의 뜻 = **속성별 한국화풍 모티프가 글자 주변에 피어나며 Bloom** —
  목=매난국죽, 화=불꽃 등. 생성 AI 사용 허가.

### 4.6 속성 모티프 (예준 2차 검수 지시 · 3차 정정 — 2026-08-27)

**목적은 Art가 아니라 가독이다** — "어떤 속성을 썼는가"를 즉시 읽히게 한다(3차 정정).
배경에 큰 그림을 까는 방식(2차 구현)은 폐기 — **획 위 몇 곳에 붙는 작은 스프라이트**로 한다:
"가"(목)를 그리면 글자에 잎사귀 몇 장이 붙고, "나"(화)를 그리면 불꽃이 약하게 피어오른다.

- **소재 = 낱개 요소 [TEST — 목·화만 예준 예시, 나머지 3종은 후보]:** 목=대나무 잎가지 /
  화=불꽃 한 줄기 / 토=바위 하나 / 금=반짝임(성망) / 수=물방울·물보라.
- **파이프라인:** Recraft(흰 바탕 수묵담채, 낱개 소재 프롬프트) → WebP→PNG 변환 →
  `Assets/_Project/Art/Motifs/T_Motif_*.png`. 재생성 = `Tools/Generate-Motifs.ps1`(PROD-AIASSET 상업권 정합).
- **합성(InkMotif 셰이더):** luma 키잉(밝을수록 투명) + 담채 원색 유지 + 속성색 틴트 + HDR 부스트(Bloom).
- **스폰(어댑터):** 부착점 = **획의 표현 점들에서 무작위 표집** + 산포. 개수·크기·산포·상승 속도·회전
  지터 전부 `BrushStyleSO`(MotifCount 4 · MotifSize 0.22 · MotifScatter 0.08 · MotifRise 0.12 · AngleJitter 30).
  획 **앞**(sortingOrder 100) — 붙어 있는 것이 보여야 한다.
- **타임라인:** 붙은 자리에서 **움직이지 않는다** — 크기만 0에서 제 크기로 은은히 자라고(grow),
  글자와 함께 사라진다. 상승(rise)은 4차 검수에서 폐기. 플래시 strength·fade 공유.
- **가독 우선(4차 검수):** 스프라이트는 글자의 보조 언어다 — 저채도(`_Desaturate` 0.5)·
  반투명(`_Opacity` 0.55)으로 눌러 글자 자체의 가독을 지킨다. 크기 기본 0.18.
- **플래시 시퀀스 정정(2차):** 어택 후 강도 **피크 유지** — 글자가 먹으로 돌아오지 않고
  속성색인 채로 페이드아웃한다.
- 매핑·텍스처는 `ElementPaletteSO.Entry.Motif`(데이터) — 소재 교체는 에셋 교체로 끝난다.

### 9.1 자동 검증 (플레이모드 스크린샷)

- 컴파일·런타임 에러 0. 거침: 가장자리 요철·갈필이 육안으로 뚜렷(§4.3 작동).
