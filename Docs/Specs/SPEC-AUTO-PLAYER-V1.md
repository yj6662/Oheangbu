## 실제 검사

고정 시험은 Idle·Walk·Run·실제 창/봉 계열 공격 1개, 팔 내리기·깊은 팔꿈치 굽힘·머리 위 팔 올리기·**양발 접지 스쿼트**다. 유효한 기존 클립을 우선하고 원본 FPS·재생시간을 유지한다. 절차 진단 자세는 원본 클립과 구분하며 한쪽 다리 들기나 이름만 같은 과거 진단을 대체 검사로 취급하지 않는다.

1. 데이터: 유한 좌표, 정상 웨이트·최대 4본, 재질 연결, 실제 메시 통계 확인.
2. 변형: 모든 정수 프레임 검사. 최악 에지의 양 끝 정점·본 영향·위치·프레임을 기록한다. 정지 길이 5mm 이상 에지의 2배 초과는 검토 경고, 4배 초과는 구조 실패 의심이다. 경고를 해결하거나 실제 해당 프레임에서 무해함을 확인해야 한다.
3. 시각: 사면도, 어깨·겨드랑이·손 근접, 달리기·공격 연속 재생 확인. 통합 메시에서 정의할 수 없는 피부 관통 수치는 0으로 쓰지 않는다. 계산 영역·한계를 명시하고 부호 없는 최근접 거리로 관통 통과를 선언하지 않는다.
4. 장비: 후보 통과 후 모자·약 0.95m 긴 붓·수납 장비를 강체 부착한다. 실제 붓을 단 공격에서 손 접촉·양손 위치·붓 궤적·몸 관통과 본 추종을 확인한다. 제한적 부착/IK 보정으로 해결하지 못하면 `WEAPON_GRIP_FAIL`.
5. FBX: 선정 후보만 빈 Blender 장면에 왕복한다. 클립별 시작·중간·끝·최악 프레임을 비교하고 0.5mm 기준·정점 대응 한계·삼각형 차이를 기록한다. `SERIALIZATION_PASS`는 변형 품질 통과가 아니다.
6. Unity: 별도 검수 씬·프리팹과 맞는 Humanoid Avatar/재질을 구성한다. 지면 위 이동·정지·회전·Idle/Walk/Run·공격/복귀·발 미끄러짐·지면 관통·파지·바운딩 소실을 플레이 카메라와 전신 카메라에서 확인한다. 삼각형·본·렌더러·재질 수를 기록하며 미측정 성능은 미검증이다. C2·공용 리그는 교체하지 않는다.
