# 5강토 콘텐츠 — 첫 실제 플레이 구간 연결 계획

계획 상태: PROPOSED · 2026-09-12

근거: SPEC-WORLD-MACRO, SPEC-WORLD-MACRO-CONTENT, SPEC-EA-PROLOGUE, LDB-REALMS/EA/CHECKPOINT, NARR-STORYLINE, COMBAT-ENEMY/ECONOMY. 이번 문서는 실행 전 계획이며 완료 기록이나 바이블 결정 전이가 아니다.

## 목표와 범위

전체 매크로 맵의 외형과 83개 콘텐츠 위치 초안을 유지하면서 **폐광 조사 → 첫 교전 → 출구 → 지선 탐험 → 금표 주막 대화·휴식·저장**을 실제 플레이 가능한 한 구간으로 완성한다. 이 구간에서 검증한 연결 구조를 이후 벌목장·심부·황경 가도로 확대한다.

기존 매크로 검토 씬, C2, 프롤로그와 저장 파일을 보존한다. 별도 `W_WorldMacro_Playtest` 씬은 같은 지형 메시·재질·환경 데이터를 참조하고 첫 구간만 실플레이 대상으로 활성화한다. 나머지 지점은 검토 배치 상태를 유지한다. 일반 적과 NPC의 임시 외형, 실제 크기 캡슐을 사용하며 새 모델·술식 VFX·수면 미술은 만들지 않는다.

## 확인한 현재 구현과 연결상 주의점

- `PrologueEncounter`: NavMesh 기반 순찰·추격·복귀와 근접/원거리 공격 연결이 있다. 전 지역 NavMesh를 한 번에 굽는 대신 첫 구간의 실제 지면과 출입 통로만 저작한다.
- `PrologueSession` / `PrologueProgressStore`: 조사 완료·일회 보상·체크포인트·사망 드롭·회수·원자적 파일 교체가 있다. 세션이 프롤로그 좌표와 전투 스코프에 연결돼 있으므로 통째로 붙이지 않고 필요한 공통 기능과 씬 어댑터를 나눈다.
- `WorldMacroReviewController`: 현재는 검토용 이동·카메라이고 실제 전투 플레이어가 아니다. 검토 컨트롤러와 전투용 PlayerMotor를 동시에 실행하지 않는다.
- 현재 콘텐츠의 거리별 Visual 비활성화는 전투 상태를 보존하지 않는다. 적 사망·일회 이벤트 완료와 단순 비표시/재표시를 분리해야 한다.
- 동굴 실제 입구와 지도상 폐광 예약 POI가 다르며 가도까지의 접근로는 미완료다. 코드 연결에 앞서 실제 입구 기준으로 접근 동선을 해결한다.

## 순서와 단계별 완료 조건

### 1. 첫 구간 동선 고정

실제 동굴 입구·조사점·안전 시작점·적 배치·주막 출입구를 현 지면에 맞춘다. 막힌 길과 연결되지 않은 지선을 먼저 정리한다. 필요한 짧은 지선·경사로 또는 콘텐츠 위치만 조정하며 전체 지형을 재생성하거나 넓게 평탄화하지 않는다. 이동 시간이나 갈림길 개수를 맞추는 굴곡은 넣지 않는다.

완료 조건: 시작점에서 동굴 밖 본선·지선·주막 출입구가 연결되고, 실제 크기 캡슐의 폭·경사·지지·머리 공간 검사에서 치명적인 단절이 없어야 한다. 자동 완주는 하지 않는다.

### 2. 실제 플레이어와 입력 연결

매크로 전용 플레이어 구성에서 기존 HP·먹·작도·락온·회피·패링 서비스를 재사용한다. 캡슐은 높이1.75m·지름0.56m, 비작도 시 숄더뷰를 유지하고 작도 시점은 기존 규칙을 따른다. 발 기준 위치와 카메라 피벗을 명시적으로 분리한다.

보행·작도·탑승 상태에서 입력과 카메라 소유자는 각각 하나만 활성화한다. 기존 차량 E 승하차·V 시점 전환은 보존하고, 차량 연동 검사에서는 하차 후 발 위치와 전투 조작 복원까지 확인한다. 차량 전투·적의 차량 공격 규칙은 이번에 임의로 추가하지 않는다. 첫 교전 검수는 보행 상태로 한정한다.

완료 조건: 실제 키/포인터 입력의 작도·명중·회피·가드, 시점 복귀, 상호작용 F와 차량 E/V의 충돌이 없는지 한정된 시험 장소에서 확인한다.

### 3. 첫 교전 연결

폐광 주변의 무속성 근접 적과 화 속성 원거리 적부터 실제 EnemyController·체력·단일 속성 설정을 붙인다. 기존 공격 예고·판정·술식 위력과 시간 규칙을 유지한다. 순찰→발견→추격→공격→귀환→사망을 연결하고 지형 차폐를 검사한다.

적의 영속 ID와 조우 상태를 관리해 거리별 비활성화만으로 부활하거나 처치 통보가 중복되지 않게 한다. 휴식·사망 시 일반 적을 재설정하고 이벤트/보스의 재등장 여부와 구분한다. 모든 79개 캡슐의 AI를 동시에 켜지 않는다.

완료 조건: 벽 너머 공격·NavMesh 이탈·중복 처치 보상·범위 이탈 후 순간 부활이 없어야 한다. 처치 보상은 기존 TEST 값을 데이터로 재사용하며 경제를 새로 확정하지 않는다.

### 4. 조사·대화·지선 보상 연결

폭파 흔적 조사, 벌목꾼·약초꾼 대화, 선택 지선의 일회 통보 보상을 실제 진행 데이터에 연결한다. 이미 확인한 기록과 받은 보상을 저장하고 재진입해도 유지한다. F 입력은 가까운 가시 지점에만 허용하고 작도 중에는 차단한다.

사건의 정답을 조기에 설명하거나 특정 글자 성공을 진행 조건으로 추가하지 않는다. 정담은 역참, 왕소는 객주 분소에 남긴다. 국 장소는 재방문 예고이며 첫 구간 통과 요건으로 쓰지 않는다. 상시 퀘스트 목록 HUD·상점·강화 경제는 추가하지 않는다.

완료 조건: 반복 상호작용·저장 재로드에서 설명/보상 상태가 일치하고, 벽 너머 또는 작도 중 상호작용이 발생하지 않아야 한다.

### 5. 휴식·사망·저장 연결

금표 주막에서 HP·먹 회복, 체크포인트 등록, 일반 적 재설정을 실행한다. 사망 시 마지막 안전 접지점에 통보를 남기고 체크포인트에서 자원을 회복해 재시작한다. 회수 전 재사망 시 이전 드롭을 교체하며 완료 조사·일회 보상은 보존한다.

새 테스트 저장 슬롯과 버전을 사용하고 기존 프롤로그 저장을 덮어쓰지 않는다. 파일 교체·백업 복구뿐 아니라 누락 ID·유효하지 않은 위치·변경된 지형·차량 탑승 중 종료의 복원 경로를 검토한다. 이번에는 차량 이동 상태 자체를 저장하지 않고 검증된 안전한 보행 위치로 복원하는 테스트 정책을 명시한다. 저장 실패는 조용히 완료 처리하지 않는다.

완료 조건: 사망→회수, 재사망, 휴식, 씬 재진입, 새 세션의 디스크 재로드에서 통보·드롭·체크포인트·일회 획득 상태가 일치해야 한다. 실제 앱 종료·재실행을 수행하지 못하면 별도 미검증으로 남긴다.

### 6. 첫 구간 검토본 전달

첫 구간에 한정해 재사용 전투 규칙 회귀, 입력 소유권, 조우 비활성화와 재활성화, 저장/재진입 검사를 수행한다. 동일 1080p 구도에서 전투 비활성/활성의 CPU·GPU 프레임타임과 메모리를 비교한다. 8.33ms는 목표이며 실측 없이120fps를 완료로 쓰지 않는다.

스크린샷은 주요 동선·교전·대화·주막의 조감과 플레이 구도만 순차 촬영한다. 영상과 자동 보행 완주는 제작하지 않고 시스템 커밋85% 이상에서 새 촬영을 중단한다.

전달물: 플레이테스트 씬, 연결한 콘텐츠/조우 데이터, 저장 테스트 결과, 정지 이미지, 검사별 통과·실패·미검증 보고서와 사용자 보행 검토 경로. 사용자 완주·비주얼 판단 전에는 해당 항목을 통과로 올리지 않는다.

## 이후 확장

첫 구간의 기술 검증과 사용자 보행 피드백을 반영한 뒤 **금표길·역참·객주 분소 → 벌목장 던전 → 심부·뿌리굴 → 청룡 → 상경 가도·성저 → 황경 남문** 순서로 연결한다. 청룡과 관문전은 전용 보스 설계 단계가 필요하며 일반 적 연결 완료에 포함하지 않는다. 다른 강토의 캡슐과 후반 NPC는 그 전까지 검토용 위치를 유지한다.
