# 걷기·달리기·점프 Mixamo 교체

2026-09-14 사용자 요청. 기존 파지의 잠정 승인과 손 후속 작업 기록을 유지한다.

- Adobe Mixamo에 로그인된 브라우저에서 Locomotion Pack과 후진 걷기·달리기를 내려받았다. 사용자 모델을 업로드하지 않았으며 X Bot / FBX Binary / Without Skin / 60fps / Keyframe Reduction none을 사용했다.
- 전후좌우 걷기·달리기, 중단 가능한 전진 시작, 점프 도약·낙하·착지를 `PlaytestNaturalLocomotion` 파생본으로 연결한다. 정지 발 재배치가 재발하지 않도록 새 Idle은 첫 프레임을 유지한다.
- C02 바인드의 벌어진 다리 각도가 소스 회전 델타에 남는 문제를 확인했다. 원본의 움직이는 허벅지–무릎–발목–발끝 방향을 재현한다. 기준 뼈 길이·계층·신체 메시를 바꾸지 않는다.
- 방향별 주기는 왼발이 이동 방향으로 가장 앞에 놓인 구간을 기준으로 정렬한다. 실제 C02 발바닥의 지지 구간 이동량으로 재생률을 구한다. 첫 후진 후보는 보폭이 짧아 제외하고 다른 일반 후진 소스를 채택했다.
- 걷기 2.2m/s, 달리기 5.5m/s, 점프 높이 0.75m와 입력을 유지한다. 점프는 실제 수직 속도로 Rise/Fall 클립의 시간을 제어하고 실제 접지로 착지한다. 소스의 공중 루트 상승은 제거하여 Motor의 상승과 중복하지 않는다.
- 발목 고정 목표가 다리 길이를 벗어날 때 높이까지 밀어 올리는 문제를 수정했다. 높이를 유지한 채 수평 도달 범위를 제한한다. 새 프로필의 선 상태 이동은 교정된 원본의 뒤꿈치→발끝 구름과 보폭을 유지하며, 발목 고정 대신 발바닥 간격·지면 법선 차이만 보정한다. 웅크림의 기존 접지 방식은 유지한다.
- 기존 DodgeTurn 파생본·회피·웅크린 구르기·90도 고개/몸 회전·C 웅크림·X 착석·현재 손 파지를 유지한다.
- 짧은 실제 Play 입력 검사는 별도 저장 슬롯에서 수행한다. 최종 동작 검사는 적 GameObject를 일시 비활성화하고 복원한다. 전투 검증을 의미하지 않는다.
- 이번 작업에는 빌드·영상·자동 보행 완주를 포함하지 않는다.

결과와 검증: `Art/PlaytestRecovery/NaturalLocomotion/REVIEW.html`, `REPORT.md`, `source_ledger.json`. 실제 실행하지 않은 지형·전투·네이티브 키보드 검사는 미검증으로 남긴다.
