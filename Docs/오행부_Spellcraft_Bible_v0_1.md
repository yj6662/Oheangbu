## 1장 — 헌장 [SPELL-CHARTER] [LOCKED]

- **작도는 직접 획을 긋는 입력으로만 한다**(헌법 3조 1항). 한 글자 = 하나의 진(陣).
- 모든 시스템은 음양오행에서 파생된다(기둥 1) — 자모 배정은 훈민정음 제자해, 속성의 성질은 홍범 오행.
- **술식에 고유명은 없다 — 글자 자체가 이름이다.** 글자가 아닌 행위·개념만 이름을 갖는다(갈무리·상합·필세 등).
- **몸은 초성, 짓은 종성.** 술식의 물질·형상은 초성이 독점하고, 종성은 기능만 바꾼다. 모든 글자 창작의 이중 시험: "이 몸이 초성인가, 이 짓이 종성인가."
  - 세칙: 짓이 새 몸(투사체·구조물)을 낳으면 그 재질도 초성을 따른다(안의 물방울, 낫의 초승달). 짓의 기운·효과 표현은 종성의 색을 띨 수 있다(간의 옮는 불씨, 녹의 회복존).

## 2장 — 어휘 공간 [SPELL-VOCAB] [LOCKED]

- 총 **120자(칸) 고정**: 초성 5(ㄱㄴㅁㅅㅇ) × 중성 4(ㅏㅓㅗㅜ) × 종성(없음 + ㄱㄴㅁㅅㅇ). 이 중 배정 100자 — ㅜ+받침 비동기 20칸은 의도적 공백(13장).
- 확장 전면 기각(LEGACY): 자음군 확장(ㅋㄷㅌㄹㅂㅍㅈㅊㅎ) · 강도축(ㅑㅕㅛㅠ) · 특수 중성(ㅣㅡ). 예외: 원획 ㆍ·ㅡ는 엔딩 마지막 작도 전용 후보(헌법 슬롯 6 파킹, [TBD]).
- 인식기 제스처 클래스 = **9종(자음 5 + 모음 4) 영구 고정** — 최고 위험 가정(자모 인식)의 스코프 최소화.
- 전 초성은 시작부터 개방(보스 필수 기믹의 전제 — Combat 9장 상호 참조). 종성은 강토 보상 — **획득 순서 ㄱ→ㄴ→ㅅ→ㅇ→ㅁ(최후, 상합)**. 종성 하나 = 새 술식 10종이 한꺼번에 열리는 "책 한 권". 습득 간격 약 3~4시간 = 열당 학습 창.

## 3장 — 3층 문법 [SPELL-GRAMMAR] [LOCKED]

| 자리 | 맡는 것 | 내용 |
|---|---|---|
| 초성 | 속성 + 몸(형상) | 아음 ㄱ=목 · 설음 ㄴ=화 · 순음 ㅁ=토 · 치음 ㅅ=금 · 후음 ㅇ=수. 술식이 무엇으로 이루어졌는가를 독점 |
| 중성 | 프레임 (음양 × 천지인) | ㅏ=양·단일 공격 / ㅓ=음·단일 수렴(패링 — 순간) / ㅗ=양·광역 즉발 타격 / ㅜ=음·광역 방벽(지속) |
| 종성 | 짓(효과) | 보편 거동 없음 — **조합마다 글자 단위로 해석한다.** 해석 원료 = 종성의 오행 성질 팔레트(6장) |

- 패링 열(무받침 ㅓ 5자)은 허공 시전도 **방어막으로 잔존**한다(#131 개정 — 앞 구간 패링 판정·뒤 구간 일반 경감, 판정·수치=Combat 3장). ㅓ=순간 철학은 여타 열(버프 등)에 유지. ㅜ는 언제든 시전 가능, 잠시 잔존, 패링 판정·보상 없음 — 단일/영역 축이 순간/지속 축을 겸한다.
- 받침이 붙은 음성렬: **ㅓ+받침 = 자기 버프**(12장) / **ㅜ+받침 = 필드 작도 — 동기 5자(국·눈·뭄·숫·웅)로 제한**(13장), 나머지 20칸은 의도적 공백. 예외: ㅁ받침 설치는 ㅏ 전용(상합, Combat 5장).
- 광역(ㅗ) 기본형은 즉발 영역 타격이며 장판이 아니다. 단, **잔존하는 장(場)은 특정 글자의 짓으로 가능**하다 — 장판은 플레이어와 적이 공유하는 공격 언어.

## 4장 — 초성 탄도 [SPELL-INITIAL] [LOCKED]

| 속성 | 형상(몸) | 궤적·속도 | 광역(ㅗ)의 방식 | 이점 / 대가 | 홍범 근거 |
|---|---|---|---|---|---|
| 목 ㄱ | 곧게 뻗는 생목 가시 | 대상을 향해 곧게 | 영역에서 가시 일제 솟음 | 즉발 도달 / 사거리 짧음(근중거리) | 曲直 |
| 화 ㄴ | 불덩이 | 곧게, 표준 탄속 | 영역 화염 방사 | 기준선(baseline) / 특이점 없음 | 炎上 |
| 토 ㅁ | 바위 덩어리 | 포물선 | 직선 모래폭풍 | 최고 단발 위력 / 조준 난도 최고 | 稼穡 |
| 금 ㅅ | 송곳 | 거의 즉발급 최속 | 다연발 송곳 속사 | 최속·명중 용이 / 단발 위력 최저 | 從革 |
| 수 ㅇ | 느린 유도탄 | 각도 한계 내 비행 추적 | 전진하는 느린 파도 | 조준 용서 / 도달 지연 | 潤下 |

- 수의 유도 = 비행 중 추적. 락온 유도(발사 시점 조준 보정, 발사 후 직진)와 구분되어 락온 중에도 수의 개성이 유지된다.
- 속도·위력 배율·사거리·유도 각도 등 수치는 전부 데이터 TEST.

## 5장 — 패링 어휘 [SPELL-PARRY] [참조 — 정본 COMBAT-PARRY]

패링의 판정·타이밍·보상·정본표(거·너·머·서·어)는 **Combat Bible 3장 소유.** 본 문서는 문법만 정의한다: 패링 글자 = 상극 초성 + ㅓ 완성형.

## 7장 — ㄱ열(목성) 10자 [SPELL-COL-G] [LOCKED]

첫 종성 책. 열 개가 전부 다른 동사이면서 전부 목성의 해석이다.

| 글자 | 조합 | 효과 |
|---|---|---|
| 각 | 목+ㅏ+ㄱ | 완전 속박 — 대상 행동 불가. 보스는 둔화(행동 가능). 시간 만료로만 해제 — 묶인 대상 타격 가능, 추가 피해 없음 (개정 2026-08-16) |
| 낙 | 화+ㅏ+ㄱ | 적중 대상에 뿌리박힌 화염 — 지속 피해 |
| 막 | 토+ㅏ+ㄱ | 낙하 지점에 바위가 뿌리내려 엄폐물로 잔존 |
| 삭 | 금+ㅏ+ㄱ | 일자 관통 — 경로상 뒤의 적까지 피해 |
| 악 | 수+ㅏ+ㄱ | 명중 후 튕겨 되돌아와 같은 대상 재타격 |
| 곡 | 목+ㅗ+ㄱ | 영역에 덩굴이 일정 시간 퍼져 잔존 — 이동 감속장 |
| 녹 | 화+ㅗ+ㄱ | 광역 화염 + 적 명중 지점에서 회복존 분출(플레이어 진입 시 HP 회복). **허공 시전 시 회복존 없음** |
| 목 | 토+ㅗ+ㄱ | 폭풍 경로에 석순이 시간차로 솟아 2차 타격 |
| 속 | 금+ㅗ+ㄱ | 명중한 송곳이 튕겨 다른 표적으로 재발사(도탄 확산) |
| 옥 | 수+ㅗ+ㄱ | 파도가 끝까지 갔다가 되돌아오며 2회 타격(조수 왕복) |

- 각의 속박 이원(일반=완전 속박 / 보스=둔화)은 그로기(완전 무력화)와의 영토 분리 — 필드의 제어 왕은 각, 보스전의 무력화 왕은 그로기. 엘리트의 소속은 리셋 경계 TBD와 묶어 데이터에서.
- 녹 = 회복 작도의 해답. 회복존이 적의 위치에서 태어나므로 회복하려면 적이 있던 자리로 들어가야 한다 — 안전지대 힐의 구조적 봉쇄. 회복량·지속·먹 비용은 TEST.
- 패턴 노트(규칙 아님): 같은 성질이 단일에선 강형(각=완전 속박), 광역에선 완화형(곡=감속장)으로 번역되는 경향.
- 하드 CC 이원(개정): 각=지속 제어(시간 만료만 해제·추가 피해 없음) / 앗=폭발 셋업(첫 피격에 깨지며 추가 피해) — 9장 참조. 구 "상합 부착=첫 피격?" TBD는 자동 해소.

## 8장 — ㄴ열(화성) 10자 [SPELL-COL-N] [LOCKED]

두 번째 종성 책 — 적로의 보상.

| 글자 | 조합 | 효과 |
|---|---|---|
| 간 | 목+ㅏ+ㄴ | 박힌 가시의 불씨 — 대상이 쓰러지거나 시간이 지나면 가장 가까운 적에게 옮아 같은 피해(번짐) |
| 난 | 화+ㅏ+ㄴ | 순수 대화력 — 부가 효과 없이 최대 위력의 한 방(타오름의 극치) |
| 만 | 토+ㅏ+ㄴ | 착탄 시 소범위 폭발(화산탄 — 포물선 조준의 보상) |
| 산 | 금+ㅏ+ㄴ | 낙인 침 — 찍힌 대상이 짧게 받는 피해 증가(최속 마킹) |
| 안 | 수+ㅏ+ㄴ | 명중 시 작은 물방울들로 갈라져 주변 적을 각자 추적(번짐 — 새 몸은 물 유지) |
| 곤 | 목+ㅗ+ㄴ | 영역의 적들을 짧게 쳐올림 — 광역 인터럽트(예열 끊기, 완화형) |
| 논 | 화+ㅗ+ㄴ | 역화 — 방사 끝점에서 크게 터지는 이단 구조 |
| 몬 | 토+ㅗ+ㄴ | 훑인 전원에 받는 피해 증가 낙인(광역 마킹) |
| 손 | 금+ㅗ+ㄴ | 총신 가열 — 연속 시전마다 다음 속사 위력 증가(자기 스택) |
| 온 | 수+ㅗ+ㄴ | 경로상 적 장판·잔존물을 지우며 전진(정화 — 씻어 태움) |

- 운율: 산·몬 = 낙인의 단일/광역 짝(악·옥의 조수 짝에 이은 두 번째 가족 운율). 난 = 동기(화+화) 자리의 극치 해석.
- 온 = 공간 부정 위협 축(적 장판·오염)에 대한 플레이어 측 최초의 대답 — 신규 동사 "정화" 첫 등재.
- [TEST] 만·논 폭발 반경 차등(만=소, 논=대) / 산·몬 낙인 배율·지속(급소창 증폭과의 중첩 규칙 포함) / 손 스택 상한·유지 / 간 옮음의 연쇄 횟수(1회 vs 연쇄).
- [TBD] 곤의 보스 처리 — 각 선례(보스=완화 적용) 준용 방향.

## 9장 — ㅅ열(금성) 10자 [SPELL-COL-S] [LOCKED]

세 번째 종성 책 — 철옹의 보상. 책의 성격: 제압과 약화.

| 글자 | 조합 | 효과 |
|---|---|---|
| 갓 | 목+ㅏ+ㅅ | 숨통 가르기 — 체력이 낮은 대상에게 큰 추가 피해(처형) |
| 낫 | 화+ㅏ+ㅅ | 명중 후 초승달 화염 두 줄기가 부채꼴로 갈라져 나감(2차 참격 — 새 몸=화) |
| 맛 | 토+ㅏ+ㅅ | 갑주 파쇄 — 명중 대상 방어력 감소(중장갑 카운터) |
| 삿 | 금+ㅏ+ㅅ | 막을 수 없는 찌르기 — 가드·방벽·반사 자세를 무시하고 꽂힘(곧음의 극치) |
| 앗 | 수+ㅏ+ㅅ | 고드름 — 단일 대상 얼림(행동 불가). 첫 피격에 깨지며 추가 피해 + 해제(폭딜 셋업). 보스 처리는 각 선례 준용 [TBD] (개정 2026-08-16) |
| 곳 | 목+ㅗ+ㅅ | 굳은 가시밭 — 솟은 가시가 잠시 남아 밟는 적에게 피해(피해 장판) |
| 놋 | 화+ㅗ+ㅅ | 갑주 녹이기 — 훑인 전원 방어력 감소(맛의 광역 짝) |

## 13장 — ㅜ열(필드) 5자 [SPELL-FIELD] [LOCKED]
