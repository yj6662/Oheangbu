# 월드·UI·캐릭터 플레이테스트 체크포인트

2026-09-15. 새 데모 콘텐츠 구현에 들어가기 전까지의 작업을 보존한다. 원래 작업 폴더와 인덱스를 유지하고, 최신 `main` (`a375362`)에서 별도 PR 작업본을 만들었다. 새 보스·상점·데모 진행 단계는 이번 체크포인트에 구현하지 않았다.

## 포함한 작업

- 5강토 지형·수계·가도, 지역 하늘·수면 설정, 건축물·식생 배치와 스트리밍, 관청 시작·자연 폐광·주막 플레이 구간.
- 보행 숄더뷰·차량 시점 전환, 마석 자동차 주행과 출발 효과, G 호출·임시 오행부 조작·하차 후 30m 회수.
- C02 캐릭터 연결, 이동·점프·웅크림·회피·구르기·제자리 회전, ThumbWrap 파지와 작도 팔꿈치 안정화.
- 먹 막대, 로비·옵션·정지·소지품·석경 도감·차패, 삽화형 미니맵과 가로·세로 접이식 종이 지도, 탐험·진행 저장. 기록첩은 제거된 상태를 보존한다.
- 먹 흡수 표현, 믹서·음량·중첩 억제·샘플 페이드, 소환수 5종의 실제 시전과 정적 등장·소멸 연결.
- 관련 제작 도구·Spec·결정 기록·기존 검사 결과. 기존 Spike 파일의 아카이브 이동도 보존한다.

최신 상태는 [PROJECT_STATUS](../../PROJECT_STATUS.md), 현재 남은 작업은 [작업 공백 점검](../../../Art/PlaytestRecovery/DrawingElbow/GAP_AUDIT.md)을 기준으로 본다. 과거 보고서의 통과 결과는 그 보고서 작성 당시 범위에 한정된다.

## 공개 범위와 로컬 복원

공개 저장소의 기존 정책을 유지한다. 유료 공급자 팩, 원본/파생 FBX·GLB·텍스처·음원·리타깃 모션 데이터·베이크 클립·생성 메시와 큰 로컬 원본은 업로드하지 않는다. 소스·설정·씬/프리팹 참조·GUID 메타데이터와 복원 목록을 보관한다. 빌드, 비공개 입력, 원시 도구 응답 및 중간 촬영물은 제외한다.

1. Unity를 열기 전에 기존 라이선스가 있는 로컬 작업본에서 [LOCAL_ASSETS.json](LOCAL_ASSETS.json)의 각 상대 경로 파일을 복원하고 SHA-256을 비교한다. 이는 다운로드 URL 목록이 아니다.
2. [기존 VFX 복원 목록](../../Art/SpellVFX120/CHECKPOINT_LOCAL_ASSETS.json)과 [에셋 목록](../../Assets/ModelCatalog.json)을 함께 참고해 KTP·PolyOne 및 건축/식생 공급자 팩을 동일 경로에 설치한다. `.meta`의 GUID를 보존한다.
3. `Oheangbu/Packages/manifest.json`의 패키지를 복원한 뒤 Unity에서 임포트·씬 참조 검사를 진행한다. 이 단계는 이번 PR에서 미검증이다.

체크포인트 선별 정보는 [SNAPSHOT.json](SNAPSHOT.json)에 남겼다. 과거 검토 HTML이 가리키는 대다수 영상·이미지는 로컬 자료이며 공개 저장소에서 열리지 않을 수 있다. 아래 두 검토 페이지의 기존 스크린샷 11장은 이번 PR에 함께 포함한다.

- [관청 시작 검토](../../../Art/World/WorldMacro/Playtest/VillageOpening/REVIEW.html)
- [작도 팔꿈치 전후 비교](../../../Art/PlaytestRecovery/DrawingElbow/REVIEW.html)

## 후속 작업과 제한

- 폐광 조사 이후 보고/다음 목적지 연결, 관청 독립 지도 표식은 미완료다.
- 사용자 장치의 SFX 깨짐과 신고된 동굴 구멍은 해결 확인이 남아 있다.
- 최신 이동·회전 성능은 재계측이 필요하다. 120fps 달성을 주장하지 않는다.
- 손·소매와 임시 오행부 외형은 후속 제작 대상이다.
- 소환수 이동·공격·AI와 데모 보스/경제/진행 콘텐츠는 다음 구현 범위다.
- 최신 시작 흐름의 사망·휴식·메뉴·재실행 조합과 최종 빌드는 통합 검증 전이다.
