## 1장 — 헌장 [ART-CHARTER] [LOCKED]

- **수묵담채 룩 = 게임 정체성의 투자처.** 비대칭 투자(헌법)의 "확실하게" 쪽 — 주변부는 자동화해도 먹의 손맛은 사람이 지킨다.

## 2장 — 색 어휘 [ART-COLOR] [LOCKED — 2026-08-17 완결 · 실수치 TEST]

- 기본 팔레트 [LOCKED]: 한지 #F7F1E4 · 먹 #2A2622 · 갈색 #8A5A33.
- 고채도 허용 대상 [LOCKED]: 마석 · 술법 · 오행 강조색.
- **오염색 [LOCKED]:** 기조 = **번진 먹** — 검보라·묵색의 침식이 윤곽을 삼킨다. "오염은 번진 먹이다" = 발광 상한 원칙의 부정형(빛=먹, 병=번진 먹). 국소 = 속성 오염은 해당 오행색의 탁화(후반 황경 황색 안개=토 기운의 탁화). 오염은 빛나지 않는다.
- **오행 강조색 번안 [LOCKED]:** 목=청록(생죽색) / 화=주홍 / 토=황토 / 금=**은백(색이 아니라 금속 광택질로 구분)** / 수=**현색(깊은 청묵 — 오방 정통에서도 수는 玄, 고증 방어)**. 백·흑 원색은 한지·먹 바탕과 충돌하므로 기피. 접근성: 색+초성 탄도 형태의 이중 채널.
- **의미 5축 색 언어 [LOCKED]:** 진행=오행색 / 경고=번진 먹·탁화 / 안식=**등불 주황**(팔레트 갈색의 난색 연장) / 보상=**비색(翡色 — 고려청자의 청록 유광**, 숨은 것·옛것의 색, 고려 서사와 은은한 공명. 수 청묵과는 명도·광택으로 구분) / 서사=**무채**(한지 백·먹 — 글자의 존재 자체가 인력).
- [TEST] 전 항의 실제 hex·머티리얼 수치 = 실측 트랙(EA 프로토타입에서 승격).

## 3장 — 먹과 붓 [ART-INK] [LOCKED]

- 갈필 = 순수 비주얼 [LOCKED] — 필세(형×세) 불변, 인식 로직 무접촉. 붓 획 = Ribbon Mesh + Noise Cutout(구현 규격=Production).
- **발광 상한 규칙 [LOCKED — 1호 안건 원칙 확정]: 빛은 전구가 아니라 먹이다.** 강조는 Emission 증폭이 아니라 **먹 농도 · 번짐 · 획 굵기**로 말한다. 수묵 세계에서 네온은 금지.
- **역번짐 발광 [LOCKED]:** 광원의 빛 퍼짐 = Emission bloom이 아니라 **먹의 물러남** — 어둠이 밀려난 자리로 종이의 소지(素地)가 드러난다. 프롤로그 광맥의 색 인도가 이 규칙의 정본.
- **광원 3등급 [LOCKED]:** 상등(인력·서사 광원 — 광맥·주막 등불·봉수·성황당 촛불): 은은한 지속 Emission 허용+역번짐. **지속 발광은 이 목록뿐 — 빛나는 것은 곧 부르는 것**(인력 시스템 구성원 한정). / 중등(술식·마석 이펙트): 순간 Emission 허용·지속 금지 — 획이 그어지는 순간 빛나고 먹으로 가라앉는다. / 하등(환경 소품): Emission 금지, 명도 대비만.
- **오염은 빛나지 않는다 [LOCKED]:** 오염 지대·물든 짐승에 형광 없음(오염=번진 먹의 발광 규칙판). 날것 마석 빛은 정제 전 원석에만, 탁하게. 빛=안전·인력 / 어둠·번짐=위험의 읽기를 배신하지 않는다.
- [TEST] HDR intensity 상한 · Bloom threshold · 역번짐 셰이더 = 실측 트랙(먹 셰이더 스파이크에서 승격).

## 6장 — 디제틱 UI [ART-UI] [LOCKED — 2026-08-17 완결 · 차패 상세 TBD]

- HUD 화이트리스트(헌법 — 4종으로 개헌): 락온 레티클 · HP · 먹 미터 · 상호작용 프롬프트. 구현은 아래.
- **락온 레티클 [LOCKED]:** 붓으로 그은 일획의 먹 원. 그로기=원 안에 먹이 차오름, 만개(급소창)=원의 진한 완성. **적 공격의 속성 힌트는 표시 금지** — 상극 읽기는 텔레그래프의 시험.
- **HP [LOCKED]:** 붓으로 그은 한 획이 줄어드는 최소 바 + **위기 침식**: HP가 낮을수록 화면 가장자리로 번진 먹이 스며든다("오염=번진 먹"의 UI 적용 — 죽음이 가까울수록 그림이 얼룩진다).
- **먹 미터 [LOCKED]:** **얇은 투명한 병에 먹이 차오르는 액체 효과 HUD** — 도사의 먹물병(디제틱 소지품 정합). 이동·피격에 출렁이는 liquid 표현. 보조 언어: 먹 부족 시 획이 갈필로 그어짐(갈필=비주얼 전용이라 합법). [TEST] liquid 셰이더 구현=실측 트랙.
- **상호작용 프롬프트 [LOCKED]:** 무채 소자(小字) — 서사=무채 원칙의 연장, 최소 존재감.
- 화물 상태: HUD 제거(개헌) — 봉인 화물은 등짐 실물로만 존재.
- **차패 UI [방향 LOCKED · 레이아웃 TBD]:** 정비·성장 화면=차패 실물을 꺼내 들여다보는 행위. 오상 5슬롯이 오행 강조색으로 채색되어가는 것이 성장 표시, 뒷면=면허 정보(전직 관속의 이력이 간접 서사로 새겨질 자리).
