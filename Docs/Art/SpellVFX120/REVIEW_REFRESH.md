# 제작 중 VFX 검수 페이지 갱신

현재 갤러리는 **제작 중 자료 탐색용이며 최종 미술 승인본이 아니다.** 기존 자료와 항목별 후속 자료를 구분해서 보여준다. 전체 120종이 최신이거나 실제 게임·미술 검수를 통과했다고 표시하지 않는다.

## 서버와 현재 선택

2026-09-09 확인: 127.0.0.1:8771의 PID 30900은 Python `http.server`이고, 문서 루트는 `C:/Users/yj666/Oheangbu/Art/SpellVFX120`이다. 기존 서버를 재설정하거나 새 서버를 만들지 않고 [REVIEW.html](http://127.0.0.1:8771/REVIEW.html)을 갱신했다.

현재 선택은 기본 구영상 `Clips` 101종, `CueMotionClipsB3` 17종, `CueWorldClipsB4` 2종이다. 후속 자료는 합계 19종이며 나머지 101종은 구자료다. 몸 `064_BAB8`과 몽 `066_BABD`는 B4 C2 영상이 기본이고, 상세 화면에서 B4 독립 검수씬·B3·구영상을 비교 선택할 수 있다. 스틸은 후속 19종의 검증된 영상 원본에서 5시점을 선택하고, 나머지 101종은 명시적으로 선택한 `FinalStills`를 유지한다.

## 선택과 검증 규칙

- 기본 명령은 기존처럼 `--stills-folder`가 지정한 스틸 폴더를 사용한다. 후속 폴더를 암묵적으로 전부 검색하지 않는다.
- `--latest-overrides`는 B3/B4의 알려진 세 폴더를 후보로 추가한다. `--clip-overrides FOLDER`를 반복해 새로운 후보를 명시할 수 있다. 존재하지 않거나 제작 중인 후보는 채택하지 않고 검증된 기존 자료를 유지한다.
- 각 MP4의 ID·글자, 인코딩 상태와 9개 검사, 실제 MP4 SHA-256, 촬영 메타 SHA-256이 맞아야 표시한다. 새로운 FFmpeg 디코드 검사를 수행하는 대신 기존 디코드 검사 기록과 현재 파일의 동일성을 검증한다.
- 후보 순서는 해시가 확인된 촬영 메타의 `capturedUtc`로 결정한다. 파일 수정 시각·인코딩 시각·폴더 이름을 최신 소스의 증거로 사용하지 않는다. 현재 소스와 일치 여부는 여전히 미검증이다.
- 후속 스틸은 원본 전체 PNG 시퀀스와 촬영 메타를 인코더와 동일한 방식으로 해시 검증한 뒤 선택한다. 시퀀스가 바뀌거나 불완전하면 스틸은 기존 기준 폴더에 남으며 영상과 같은 자료라고 표시하지 않는다.
- 항목별 폴더 버전, 촬영 장면, 시간, 런타임 MVID, 인코딩 증거 링크를 표시한다. B4 장면은 메타에 기록되어 있다. B3의 C2 후방 장면 표기는 운영·시각 검수 기록에 근거하며, 해당 JSON에 장면이 없다는 점을 따로 표시한다.
- 자료 경로는 출력 폴더 안으로 제한한다. 원본 프레임·영상·Unity 에셋은 변경하지 않는다.

## 재생성 명령

저장소 루트에서 실행한다.

```powershell
C:/Python314/python.exe Tools/SpellVFX120/build_review.py --stills-folder FinalStills --stage "전수 기준 촬영 + 항목별 후속 자료" --latest-overrides --title "오행부 · 제작 중 VFX 검수"
```

후속 폴더가 실제 생성·인코딩 검증된 뒤에는 다음처럼 명시한다. 현재 B5 완성을 이 문서가 주장하지 않는다.

```powershell
C:/Python314/python.exe Tools/SpellVFX120/build_review.py --stills-folder FinalStills --latest-overrides --clip-overrides WaterClipsB5 --title "오행부 · 제작 중 VFX 검수"
```

출력은 `Art/SpellVFX120/REVIEW.html`과 `review_file_validation.json`이다. 후자는 전체 후보의 채택/거절 사유, 선택 버전별 수, 원본 시퀀스 해시 확인 결과를 남긴다. 이미 열어 둔 브라우저에서는 새로 고침해야 새 목록이 보인다.

## 실제 확인 범위

- Python 및 생성 JavaScript 문법 검사 통과.
- 실제 갤러리 생성: 120종, 표시 영상 120개, 스틸 600개, 후속 영상·스틸 19종. B3/B4 전체 후보와 기본 구영상의 인코딩 근거 거절 0, 선택된 19개 원본 시퀀스 해시 일치.
- 임시 파일로 누락 sidecar, 잘못된 영상 해시, 잘못된 메타 해시, 출력 폴더 밖 경로를 거절하는 동작 확인. 실제 B4 촬영 시각이 B3보다 뒤이고, C2 장면 메타를 표시하는 선택 결과 확인.
- HTTP로 서버 페이지와 생성 파일 SHA가 같은지 확인. B3/B4 대표 영상과 대응 스틸의 200 응답 및 MIME 형식 확인.
- 연결 가능한 CUA 브라우저가 없어 실제 브라우저 렌더·클릭·재생 검수는 **미검증**이다. 이 갤러리 생성 작업은 새로운 영상의 미술 품질이나 게임 연결을 검증하지 않는다.
