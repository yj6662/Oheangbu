# THIRD PASS — 목·화 48개 렌더 검수

**무기·잔탄의 높이, 건의 잎 크기, 불과 수증기 재질은 2차보다 개선됐다. 아래 5개 미술 문제와 4개 재촬영 대기를 제외하면 시각 자산을 VFX TEST 단계에서 수용할 수 있다. 전투 연결·최종 모션까지 통과했다는 뜻은 아니다.**

이번 검수는 큰 결함을 마무리하는 데 한정한다. 수용한 항목에 잎맥·파편 수·문양 농도를 조금씩 추가하는 재작업은 요구하지 않는다.

## 먼저 분리해야 할 촬영 한계

- 목·화 **48개 × 5장 = 240장**을 8개 비교 시트에서 전수 직접 열람했다. 원본은 모두 1280×720, 16:9다. 각 술식의 5칸은 같은 범위로 잘라 축소했다. 서로 다른 행의 확대율은 다르며, 원본의 색·내용은 변경하지 않았다.
- 문서 작성에 사용한 명칭·의미·문양 출처·시각·원본 경로·manifest 해시는 [sources.json](../../../Art/SpellVFX120/ThirdPassReview/WoodFire/sources.json)에 보존했다. 비교 기준은 [2차 검수](SECOND_PASS_WOOD_FIRE.md)다.
- 캡처 48개는 모두 `demonstrationCues=true`, `gameplayConnectionVerified=false`다. 명중·격발·전이는 검수용 예시 이벤트이며 실제 피해·회복·감속·시전 연결의 증거가 아니다. `phase 0~4`는 수명 7%, 22%, 42%, 64%, 90%의 표본이다. **5장의 정지 화면은 모션 영상이 아니다.** 중간 프레임의 속도, 떨림, 연속성, FPS와 정확한 관통 수치는 미검증이다.
- **곡·곤·공·국의 수정 코드는 이번 촬영에 반영되지 않았다.** 확인한 `Oheangbu.App.dll` 수정 시각은 09:17:38, `Vfx120VariantMotion.cs`는 09:22:18, `Vfx120Effect.cs`는 09:29:19다. 곡 phase 2 촬영 시각은 09:41:22다. 소스보다 오래된 DLL이 로드된 상태임을 root도 확인했다. 다른 재질·프로필 변화는 렌더에 반영되어 있으므로 3차 전체가 2차 복사본이라는 뜻은 아니다.
- 따라서 네 술식의 새 지면 인자·확장·쳐올림·엄폐·발판 구현은 **재촬영 대기**다. 이번에 보인 예전 형상을 근거로 새 코드를 다시 설계하지 않는다. 명시적 Refresh 후 `FourthPassSubset`에서 판단한다.

## 3차에서 수용할 개선

- **건**: 겹친 큰 잎 두 장에서 작은 잎 무리로 바뀌어 화면을 덮는 문제가 줄었다.
- **것·넛**: 발바닥을 가로지르던 검이 시전자 허리·손 높이에 놓인다. **겅·넝**도 발치에서 상체 주변으로 올라왔다. 실제 캐릭터의 손 소켓·주탄 발사와의 일치는 별도 미검증이다.
- **나·낙·난·너·노·논·누**: 불꽃 내부에 금빛·주황빛 농담이 생겨 균일한 붉은 판의 인상이 줄었다. 특히 노는 시전자에서 앞쪽으로 퍼지는 불길이 읽힌다. 현재 TEST 단계에서 추가 재질 개편은 필요하지 않다.
- **농**: 각지고 불투명한 운문 덩어리에서 부드럽고 반투명한 회백색 연기로 개선됐다. [phase 1](../../../Art/SpellVFX120/ThirdPass/042_B18D_1.png), [phase 2](../../../Art/SpellVFX120/ThirdPass/042_B18D_2.png), [phase 3](../../../Art/SpellVFX120/ThirdPass/042_B18D_3.png)에서 수증기 표현으로 수용할 수 있다. 전투 영역의 실제 시야 차단 범위까지 검증한 것은 아니다.
- 전통 문양은 봉인과 바닥 장식에서 보이지만 모든 효과의 주형상에서 읽히지는 않는다. 기존 KTP 출처를 연결했다는 이유만으로 개별 문양의 가시성을 통과시키지 않았다. 이번 수정 범위에 전체 문양 재설계는 추가하지 않는다.
