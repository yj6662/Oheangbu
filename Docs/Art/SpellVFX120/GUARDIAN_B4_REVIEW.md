## 주먹과 표적의 관계

- **0056–0058 / 2.333–2.417초:** 두 카메라에서 장승이 표적의 옆으로 자리를 잡고 몸을 돌린 뒤 주먹을 몸 쪽에 둔 준비 자세가 보인다. C2 0058에서는 표적이 장승 왼쪽, 장승 얼굴과 준비된 주먹은 오른쪽으로 분리되어 보인다.
- **0060–0064 / 2.500–2.667초:** 주먹이 준비 위치에서 표적의 가슴 방향으로 나간다. 특히 0062에서는 검수 더미의 상체 앞을 큰 주먹이 덮고, C2에서도 캡슐 상체 앞에 주먹이 놓인다. B3에서는 해당 팔과 접점이 몸 뒤에 묻혔지만 B4는 **표적을 향해 뻗는 방향과 접촉하는 위치가 읽힌다.**
- **0066–0076 / 2.750–3.167초:** 주먹이 돌아오고 팔을 내린 유지 자세로 연결된다. 표본에서 머리 위 주먹 이탈이나 몸에서 멀리 떨어진 팔 조각은 다시 나타나지 않았다.
- **판정: 주먹 시인성·타격 방향은 한정 통과.** 화면에서 표적 앞에 주먹이 겹쳐 보이는 것과 실제 메시 표면 사이의 접촉/관통 깊이가 검증된 것은 다르다. B4에서 새로 실행한 표면 거리·삼각형 교차 감사는 없으므로 **정확한 표면 접촉은 미검증**으로 남긴다. B3의 지정 TargetPoint 접점 오차 수치를 B4에 그대로 전용하지 않는다.

장승의 얼굴은 B4 C2 0058·0062에서 측면에 가까운 각도로 실제 드러난다. 이번 방향 변경이 유효하다는 관찰이며, 모든 시점의 얼굴 품질을 통과 처리하는 의미는 아니다. 현재 결과만으로 새 모델 생성이나 얼굴 재제작이 필요하다는 근거는 없다.

## 등장·퇴장과 유지된 부분

0004–0016에서 아래쪽부터 몸이 채워지는 순차 등장, 0103–0109에서 머리·몸이 비워지는 해체 퇴장이 두 카메라에 모두 보인다. **0115는 두 촬영본 모두 각 0000과 RGB가 동일하다.** C2는 0110도 동일하지만 독립 검수의 0110은 235픽셀에 최대 채널 차이 2가 남으므로 그 프레임까지 완전 소멸했다고 판정하지 않는다. 0110은 4.583초로 수명 4.7초 전이며, 최종 0115는 4.792초다. 해당 마지막 프레임에 렌더 잔여물이 없다는 확인이며 오브젝트 풀 반환·게임플레이 종료 신호·전체 120효과의 자원 수명에 대한 새 판정은 아니다.

몸·머리·주먹·두 발의 분리형 장승 실루엣은 유지된다. 추가 접근 동선 때문에 기존 축 오류가 재발한 모습은 관찰되지 않았다. 밝은 C2 배경에서 황토색 외곽은 구분되지만 표면의 단일 명도감은 남는다. 이번 변경의 목적이었던 주먹 가림 개선은 확인됐으므로 재질과 전수 관절 검사를 확대하여 완료를 지연할 이유는 없다.
