# 각·공·검 — 실제 식물 자산을 쓰는 본체

전체 VFX120 목표는 **미완료**다. 이 기록은 목 계열 세 본체의 교체 범위이며 실제 게임15종 또는 120종 미술 완료 기록이 아니다.

## 원형과 구현

| 글자 | 재사용 원형 | 실제 본체 삼각형 |
|---|---|---:|
| 각 | Seyeonjeong `SM_TreeRoot_1_LOD2` 3,305 tris ×5 | 16,525 |
| 공 | `SM_Henonis_1_LOD1` 2,819 tris ×7, 원래 줄기/잎 두 슬롯 | 19,733 |
| 검 | `SM_MeliaAzedarach_Summer_1_LOD3`, 꽃·잎·목질 세 슬롯 | 6,826 |

세 본체를 하나씩 함께 놓을 때 기하 합계는 43,084 tris다. KTP 발동·타격 파티클까지 포함한 GPU 처리량이나 프레임 비용이 아니다. 원형의 메시·UV·텍스처를 보존해 별도 정규화 메시와 공유 재질/프리팹을 만든다. 원래 씬 배치용 콜라이더·스크립트·LODGroup은 가져오지 않는다. 메시 통계와 원본 파일/메타 SHA-256 전후는 [실제 빌드 기록](../../../Art/SpellVFX120/botanical_build.json)에 남긴다.

`Vfx120Effect.Botanical.cs`는 기존 효과의 Age/Life/목표/AreaPlan을 읽는다. 각은 표적 둘레의 뿌리, 공은 기존 Path 선두를 따르는 대나무 무리, 검은 위치에 뿌리내린 잎나무다. 새 인식·공격·가드·회복 시계나 충돌체를 만들지 않는다. 공의 적합한 Path가 없으면 기존 본체를 보존한다. 해당 게임 술식이 없는 현재 카탈로그 검수에서는 Review가 별도의 **진단용** 경로를 제공한다.

줄기를 늘이거나 납작하게 만들지 않고, 원래 크기 전체를 지면 아래에서 올려 생장처럼 보이게 한다. 대나무는 줄기 배치 X만 반경에 따라 조절한다. 넓은 잎은 명목 경로 폭을 벗어날 수 있다. 검의 Release/Break 이후 0.4초의 시각적 소멸도 입력·효과 시전을 기다리게 하지 않는다. 깊이 기록을 하는 수피/알파 컷아웃 재질을 사용하며, 원래 BaseMap/Normal 및 잎/꽃의 컷오프를 유지한다. 매 프레임 재질을 복제하지 않고 MPB로 가시성·지면 절단 높이만 전달한다.

## 실제 화면에서 발견해 고친 것

- 13: 각은 너무 작은 뿌리 뭉치였고 검은 잎 없는 겨울나무였다. 공의 Review에 Path가 없어 옛 S판 본체가 나왔다. [13 원본 비교](../../../Art/SpellVFX120/KTP_BOTANICAL_REVIEW13.md).
- 14: 각의 높이를 키우고 공의 보기용 Path를 전달했다. 검을 잎이 있는 여름나무로 바꿨다. 세 프로필의 KTP 복제 PS에 Hierarchy 배율을 적용해 밝은 정면 원판의 주목도를 줄였다. 실제 화면에서 각의 굵은 근부가 위에 있는 역방향을 발견했다. [14 원본 비교](../../../Art/SpellVFX120/KTP_BOTANICAL_REVIEW14.md).
- 15: 원본 임포트 좌표의 **+X 쪽 굵은 끝**을 기준점으로 다시 잡고 +90° Y 회전으로 잔뿌리를 위로 향하게 했다. 원본 FBX의 축/단위를 재적용한 것이 아니다. 13/14의 빌더 코드와 빌드 JSON, 촬영 자료는 보존한다.

## 확인 범위와 잔여

[지면 탐침](../../../Art/SpellVFX120/botanical_ground_probe.json)은 실제 C2 Valley의 두 시각 1.6/2.3초에서 줄기 **피벗**과 아래 지면의 높이를 비교했다. 각은 +1.33~2.59cm, 공은 −2.14~−6.67cm, 검은 약 0cm였다. 공은 이 표본에서 물리적으로 떠 있지 않지만 가는 줄기와 그림자 부재로 떠 보일 수 있다. 전체 정점·전 구간·모든 지형의 접지 또는 시각적 접촉 통과로 확대하지 않는다. 현재 식물 본체는 그림자를 투사하지 않는다.

[식물 Edit 검사](../../../Art/SpellVFX120/botanical_audit.json)는 원본 참조/해시, 위치·Path 시계·줄기 간격, 반복·역탐색·종료·재시작, 검의 Release 소멸을 검사한다. 진단용 계획과 큐를 공급한 계약 검사이며 실제 플레이 입력·전투·그림자·미술·성능 인증이 아니다. 실제 Update/Destroy와 영상은 별도 기록으로 구분한다.

각은 독립된 강체 뿌리 원형 다섯 개이며 상대 신체에 맞춰 굽는 스키닝이나 충돌 대응이 없다. 접지의 시각적 설득력, 대상별 결박 접촉, 검의 실제 그림자/영역 가독성, 동시 사용 비용은 남아 있다. 기존 소환수 정적3종과 이번 식물 자산을 혼동하지 않는다.

최종 같은 MVID `fb3d4381-ac41-49ee-aef2-ed6b874f010e`의 식물 Edit7행과 [C2 실제 Play3종](../../../Art/SpellVFX120/botanical_play_audit.json)이 통과했다. Play 검사에서 각5/공7/검1 렌더러의 출현, 공유 원본 참조, Life 종료 및 루트/자식 제거를 관측했다. 오류·셰이더 오류0, 씬/원본 불변, Edit 복귀를 확인했다. 주입한 것은 진단용 목표·Path뿐이며 인식·적 피해를 시험한 영상이 아니다.

15 Main/External 정지 화면은 30장이다. 별도 `ClipsKTPIntegrated15`와 `ClipsKTPExternal15`의 총6개 1280×720/24fps 영상은 Life+0.1초 범위를 담고 전체 디코드·시간·해시 검증을 통과했다. [영상 원본 표본 검토](../../../Art/SpellVFX120/KTP_BOTANICAL_VIDEO_REVIEW15.md)는 54개 실제 PNG 표본에 한정된다. 전 프레임 미술 통과나 실제 플레이 입력 녹화로 부르지 않는다.
