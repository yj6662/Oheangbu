# KTP 원본 연출 중심 재제작 — 2026-09-09

상태: **진행 중 / 사용자 미술 피드백 반영**. 이전 B3/B4/B5는 보존된 시제품이며 최종 미술 승인 자료가 아니다.

사용자는 기존 VFX의 인공적·상투적인 형태를 지적하고, KoreanTraditionalPattern_Effect 에셋으로 타격·발동·소환진·방어막을 만들고 소환수는 Meshy로 제작하라고 지시했다. 원래 120칸의 범위는 유지한다.

## 바뀐 제작 방식

- 이전 감사의 '완제품 프리팹을 뼈대로 사용하지 않는다'는 구현 선택을 대체한다. 원본 프리팹의 문양, 메시, 방출·크기·회전·소멸 곡선을 중심으로 구성한다.
- Fly 데모 전체의 정해진 이동/명중 Animator를 실제 게임 시간에 덧씌우지 않는다. 원본 Charge와 Explosion 하위 연출을 실제 발동/명중점에서 시작하고 내부 동작 곡선을 유지한다.
- 소환진·방어막은 Bottom 원본의 다층 문양과 입체 외곽을 활용한다. 선화를 가리는 광면만 줄이며, 단순 링·큐브·띠를 여러 개 겹친 것으로 대체하지 않는다.
- 메시·재질·텍스처 원본은 변경하지 않는다. 파생 프리팹은 기존 에셋을 참조하고, 런타임 사본에 입자 예산과 종료 처리를 적용한다.
- 기본 게임 로직의 입력·인식·피해·비행·가드 시간은 그대로 둔다. 신규 필드가 비어 있는 프로필의 동작은 유지한다.

## 실제 교정한 부분

- 발동의 큰 꽃판을 원형 대비 0.28배로 줄이고, Charge는 보조층으로 제한했다.
- 소환진이 지면 아래에 묻히지 않도록 표면에서 6cm 올렸다. Meshy 모델은 실제 바닥을 기준으로 1cm 올려 문양의 높이 보정을 중복 적용하지 않았다.
- 원본 형광색을 곱해 색이 뒤틀리는 대신, 파티클의 원래 알파·시간곡선은 유지하고 RGB 농도를 속성 안료에 맞췄다.
- 소환진·방어막은 0.75초까지 원래 전개를 재생하고 자세를 유지한다. 유지 시간을 게임 시계에 추가하지 않으며 종료 시 페이드 후 정리한다.
- 방어막은 원본 Pattern 파티클 4개를 새 곡면 캐리어에 배치했다. 캐리어는 각 256 tris이며 열린 문양 방패 네 면으로, 완전히 닫힌 물리 돔이 아니다. 게임 충돌체는 만들지 않는다.
- 원본 Charge의 방출하지 않는 제어용 PS에 누락 재질이 있었다. 파생본에서만 렌더러를 끄고 유효한 공유 재질을 연결했다. 소스 패키지는 수정하지 않았다.
- Meshy 재질은 URP 검사기에서 미리 검증해 최초 사용 시 재질이 자동 수정되는 문제를 정리했다. 약한 텍스처 발광도 실제 `_EMISSION` 활성 상태를 확인했다.
