# 최종 Stills — 목·화 48개 실제 이미지 검수

**넉·넌·넘의 위치·가려짐 문제와 곰·놈의 단순 색변주 문제는 개선됐다. 목·화의 정지 화면 자산은 대체로 VFX TEST로 수용 가능하다. 남은 큰 비교 항목은 것·넛의 같은 칼날 인상이며, 눈의 통로 개방과 모든 연속 운동은 이번 정지 캡처만으로 통과시키지 않는다.**

## 근거와 범위

- `Art/SpellVFX120/Stills`의 001~048, **240장 전수**를 8개 시트에서 실제 열람했다. 넌·넘·곰·놈의 phase 2 원본도 별도로 열었다. 모두 1280×720, 16:9이며 원본은 수정하지 않았다.
- 비교 시트는 같은 술식 안에서 동일한 범위를 잘라 축소·배치했다. 글자와 시각은 원본 바깥에만 있다. 행마다 확대율이 달라 절대 크기 비교에는 원본을 쓴다.
- [sources.json](../../../Art/SpellVFX120/StillsReview/WoodFire/sources.json)에 48개 의미·문양 출처·샘플 시각·로드된 DLL 식별자·원본 경로·240개 SHA-256을 남겼다.
- 대표 캡처 시각은 2026-09-09 10:28:43 KST, 로드된 App DLL은 10:05:20, MVID는 `3d055876-9a44-4237-8ca7-37434d3bf2ed`다. 이번에는 09:56~09:58의 Variant/Summon 수정 뒤 DLL로 촬영됐다. 실제 새 형상도 확인했다.
- 모든 캡처의 `demonstrationCues=true`, `gameplayConnectionVerified=false`다. 예시 부착·격발·전이를 실제 게임 이벤트 통과로 바꾸지 않았다. **정지 5장은 영상이 아니다.** 궤적의 중간 과정·속도·떨림·프레임당 비용·실전 밝고 어두운 배경은 이번 검수에서 미검증이다.
- 판정 기준은 [최종 미술 계약](FINAL_ART_REVIEW_CRITERIA.md)을 따른다. 아래 PASS는 해당 시각 항목의 TEST 통과이며 전체 시스템 완료가 아니다.

## 남은 항목을 좁혀 기록

1. **것·넛의 속성별 칼날 차별화: 보완 필요.** [것 p2](../../../Art/SpellVFX120/Stills/011_AC83_2.png)와 [넛 p2](../../../Art/SpellVFX120/Stills/035_B11B_2.png)의 위치는 허리·손 높이로 맞지만, 주형상은 같은 직선 칼날로 읽힌다. 작은 잎과 불씨만으로는 녹색 검·붉은 검의 인상이 강하다. 무장 위치 검수는 PASS, 속성별 큰 형상/재질 차이는 FAIL로 분리한다. 나무 날의 굽은 생장 경계와 불 날의 열린 불끝처럼 **주윤곽 한 가지 차이**만 보완하면 된다. 공통 검의 게임 규칙이나 손 동작을 새로 만들라는 요구는 아니다.
2. **눈의 통로 개방: UNVERIFIED.** [p1](../../../Art/SpellVFX120/Stills/045_B208_1.png)과 [p3](../../../Art/SpellVFX120/Stills/045_B208_3.png)은 더미 둘레 불꽃이다. 덩굴이나 길이 없어 무엇이 타서 사라지는지 볼 수 없다. 불꽃 자산은 수용하되, 덩굴의 소각 전후가 없는 자료를 통로 개방 완료로 제출하지 않는다.
3. **영상과 상황별 연결: UNVERIFIED.** 간의 전이, 감·남의 격발, 낫의 갈라짐, 녹의 회복존은 정지 표본에서 단계 차이를 확인했다. 원인 이벤트의 실제 발생·잘못 맞은 경우·연속 프레임의 궤적까지 확인한 것은 아니다. 파일 생성 완료와 육안 영상 검수 완료를 구분한다.

그 외 잎맥·파편 수·미세 문양 농도는 이번 마무리의 필수 수정으로 추가하지 않는다.
