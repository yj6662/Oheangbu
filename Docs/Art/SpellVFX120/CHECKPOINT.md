상태 **TEST**. Draft PR #14의 최신 진행 상황이다. 120개 게임 규칙 전체나 모든 외형이 완성됐다는 의미는 아니다.

## 반영한 결과

- KTP 중심 기본 공격/방어 10종. 발사구를 화면 우측 하단에서 중앙 쪽으로 조정하고, 사각 반투명 방패·중앙 문양·속성별 접촉 파편을 구성했다. 실제 적 피해/유효한 방어 접촉 정보와 전용 프로필을 연결했다.
- 고·노·소·모·오 광역 재작업. 고는17가시의 산발적 순차 피해와3초 수명, 노는 하단 화염방사, 소는 위에서 내리꽂는 산발 속사, 모는 지형을 따르는 불규칙 분기 균열, 오는 넓은 물결과 낮은 양끝/포말을 사용한다.
- 구·무·수·우·누의 지점 고정 결계5종과 우의 내부 시야 개선. 이 결계는 VFX/진단 접촉만 구현했으며 실제 방어 규칙에 연결하지 않았다.
- 곰 목질 사슴·놈 불씨 해태·솜 은철 호랑이, 몸 몽둥이 도깨비와 옴 거북 영물의 정적 외형/소환 연출. 이전 몸 바위 도깨비·석장승은 검토 이력으로 보존한다. 소환수의 리깅·보행·AI·전투는 미연결이다.
- 마지막 몸/옴은 생성 이미지를 실제 Meshy7 입력으로 사용했다. 최종16,653/16,648tris, 재질 각1개, Meshy35+35=70크레딧. 앞선 후보 생성 비용까지 이70에 포함한다는 의미는 아니다.

## 검증과 한계

- 이 PR 작업본의 9어셈블리·255개 C# 소스를 재컴파일해 오류0·경고16을 확인했다. [정적 컴파일 기록](../../../Art/SpellVFX120/checkpoint_compile_latest.json). Unity 임포트·Play·빌드와 다른 검사다.
- 작업 프로젝트에서 몸/옴 각각48개 검사 및1080p 플레이/외부 진단 영상2개씩 완료. 30/60/120fps와0.2배 시간 조건, 지면/수명/잔존/정적 형상을 검사했다. 최고 커밋 몸82.7%,옴82.8%;85% 촬영 중단 정책 유지.
- 결계5종은425개 수치 검사, 우 시야 수정85개. 각 보고서의 검사 시점과 범위를 따른다. 전체 최신120종 재검사나 실제 전투/성능 검사를 완료한 것은 아니다.
- 사용자에게 맡긴 최종 미술 판정, 소환수 리깅·실제 전투, 결계 게임 규칙, 전체 입력/적 AI/빌드 회귀가 남아 있다.

## 재현과 보존

기존 PR과 같은 VFX 범위로 구성했다. 작업 중인 C2 월드·캐릭터·카메라·Spike 이동은 이 PR에 합치지 않았다. 어댑터에서는 VFX 발사구/방어 연결 부분만 옮겼다. C2 영상은 로컬 정본 씬에서 촬영한 진단 자료이며 PR만으로 동일 C2 장면을 복원하지는 않는다.

유료 KTP/PolyOne 원본과 사본 셰이더, Meshy 생성3D 바이너리·텍스처는 기존 저장소 규약에 따라 로컬 보관한다. [경로·해시 목록](CHECKPOINT_LOCAL_ASSETS.json), Meshy 작업 원장과 Blender/Unity 빌더, GUID 메타데이터 및 설정을 보존했다. 동일 에셋 팩 임포트와 로컬 모델 복원이 필요하며 새 클론의 즉시 Play 가능 상태라고 주장하지 않는다. 원본 사진/API 비밀 응답·.env는 올리지 않는다.

완성 MP4·주요 이미지·HTML·검사 보고서는 PR에 포함한다. 대량 원본 프레임과 Delivery.zip/Blender 원본은 로컬 검토 페이지에서 받는다. PR 사본의 해당 다운로드 링크는 로컬 전용이다.
