## 남은 결함과 검증 상태

- **실패 / 원인 미확정:** 엄 측벽과 산·상·온·옷·옹의 후속 리본 표현이 재촬영에서도 식별되지 않는다. 실제 Renderer 활성·Alpha 1·Erode 0·유효한 크기를 확인했다. 정적 메시 46정점/44삼각형의 색·노멀·인덱스·바운드는 정상이다. 셰이더/실제 재질의 교차 렌더 진단은 미실행이다.
- **보완 필요:** 토 속성 영상 24개의 시간순 표본 288개를 검토했다. 몸의 행동/표적 겹침, 몽의 대비/내부 흐름이 약하다. 만·망의 보고서는 수정 전 영상에 대한 관찰이다.
- **미검증:** 최신 변경 이후 120종 전체 Play 재검사, 전체 영상 재촬영, 실제 플레이어 입력·인식·장면 전환, 빌드/GPU 및 프레임률 성능.
- 실제 입력 검수 도구 `Vfx120PlayerInputAudit.cs`는 로컬 작성 중이며 검사 신뢰도 보강이 남아 이번 커밋에서 제외했다. 로컬 파일은 보존했다.

`particle_color_probe.txt`는 GPU 인스턴싱 변경 전 기록이다. `ribbon_probe.txt`는 후속 리본 진단이다. 두 파일을 같은 설정의 동시 결과로 해석하지 않는다.
