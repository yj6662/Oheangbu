# 술식 120개 신규 시각 설계 초안

이 폴더의 `visual_direction_draft.json`은 실제 구현자가 읽을 수 있는 신규 설계표다. **설계표 작성은 VFX 구현·검수 완료 증거가 아니다.**

- 어휘 원본: `Docs/오행부_작도어휘_v0_1.csv` 120행. 효과가 배정된 100자와 의도적 공백 20자를 구분했다. 원본 효과·CSV는 변경하지 않았다.
- 문법 근거: Spellcraft Bible 13·16장. 공백은 군·굼·굿·궁 / 눅·눔·눗·눙 / 묵·문·뭇·뭉 / 숙·순·숨·숭 / 욱·운·움·웃이다. 공백에는 전시용 시각 후보만 넣었고 게임 규칙이나 해금을 배정하지 않았다.
- 각 글자에 고유 제목, 주 실루엣, 운동, 문양, 보조색, 시전·이동·접점·소멸을 작성했다. 재질을 속성 색만 바꾸어 구별하는 방식은 검수 기준으로 인정하지 않는다.
- 오행색을 읽기 기준으로 유지하면서 비색, 적동, 석회색, 바랜 홍색, 회청, 옅은 황토 등의 보조색을 제한적으로 사용한다. 순간 강조 뒤에는 먹·재·젖은 면·금속 광택으로 가라앉으며 지속 네온을 사용하지 않는다.
- `recipe`에는 주 primitive, 부 primitive, 배치 layout, behavior, count, layers, scale, duration, 색상과 4단계 기본 구간을 넣었다. count는 전시 주형상 수이며 게임 탄수·틱수·소환수 수가 아니다. duration·scale 역시 검수 기본값이며 실제 전투 수명·반경을 덮어쓰지 않는다.
- `requiredVisualEvents`는 구현 어댑터가 실제 게임 이벤트에 연결할 동작 계약이다. 간의 전이, 녹의 명중점 회복존, 각의 만료 해제, 앗의 첫 피격 파쇄, 손의 시전 간 누적, 솟의 시전 내 점증 등을 서로 구분한다.
- 원본 KoreanTraditionalPattern_Effect의 VFX 프리팹은 복제하지 않는다. 감사한 텍스처의 알파 문양만 신규 메시·리본·면에 배치한다. RGB는 흰색이므로 반드시 A를 마스크로 읽는다. 구체 도상은 `asset_audit.json`의 실제 관찰과 연결했다.
- 곰·놈·몸·솜·옴의 외곽 형상은 잠정 시각 제안이다. 소환 행동·상한·지속·어그로·그로기 규칙은 확정하지 않는다.

실제 완료 검수에서는 100개 배정 술식의 게임 이벤트 연결과 20개 공백의 전시 격리를 따로 확인해야 한다. 전체 갤러리에서 색을 회색으로 치환해도 곡·곳·공, 농·몽, 손·솟, 각·앗 등의 차이가 읽혀야 한다. 문양 도상 검수와 실제 렌더 검수는 별개다.
