# 식물 본체 15 영상 원본 프레임 검수

결론: **각·검·공의 두 시점, 총 6개 시퀀스에서 원본 PNG 54장을 직접 열람했다. 확인 표본에서는 새 대규모 튀김·방향 반전·Life 이후 잔존이 발견되지 않았다.** 각의 교정된 뿌리 방향, 검의 잎 있는 수관, 공의 전진하는 대나무 수풀은 유지된다. 접촉 음영 부족 등 [정적 검수의 미술 잔여](KTP_BOTANICAL_REVIEW15.md)는 남는다.

## 자료와 판정 범위

촬영은 C2의 고정 Main Camera / External Inspection Camera에서 효과의 시간을 `Sample`한 **진단 재생**이다. 사용자 작도, 커밋, 인식, 실제 피해·엄폐·보호를 촬영한 플레이 영상이 아니다. 메타데이터 6개 모두 `PRESENTATION_REVIEW_ONLY`, `demonstrationCues=true`, `gameplayConnectionVerified=false`다. 공의 Path도 검수용 예시다.

- Main 촬영 UTC: 2026-09-09 08:48:46.197~08:49:03.118. External: 08:49:45.025~08:50:01.863. Runtime MVID는 모두 `fb3d4381-ac41-49ee-aef2-ed6b874f010e`다.
- 24fps, 1280×720. 원본은 시점당 각 84 / 검 113 / 공 87장, 총 568장이다. **568장 전부를 육안 검수한 것은 아니다.** 아래 명시한 54장만 실제 원본 파일로 열었다.
- 촬영 목표는 Life+0.1초까지이며, 24fps 이산 표본의 마지막 실제 시각은 각 3.458초 / 검 4.667초 / 공 3.583초다. 각각 Life 3.4 / 4.6 / 3.5초를 지난다.
- [Main 인코딩 기록](ClipsKTPIntegrated15/encoding_report.json), [External 인코딩 기록](ClipsKTPExternal15/encoding_report.json)은 각 선택 3개 모두 `VERIFIED_ENCODING_AND_TIMING_ONLY`, 선택 범위 완비다. 전체 120개 영상 검증이나 미술 PASS가 아니다. 이 보고서의 시각 판정은 MP4 전체 연속 재생이 아닌 원본 프레임 표본 열람에 근거한다.

## 시간 순서에서 보이는 결과

**각:** 처음에는 효과가 없고 0.25초에 작은 문양과 녹색 기운이 보인다. 영향 시각 0.55초를 끼는 13/14번 표본에서 완성 뿌리 덩어리가 한꺼번에 나타나지 않는다. 18번에는 낮은 잔뿌리, 34번에는 표적 몸통 높이의 뿌리 울타리가 보인다. 60번까지 위아래 방향과 중심 위치가 유지된다. 81번에는 검은 점상 소멸만 조금 남고, 83번에는 사라진다. 다만 하부의 굵은 지지부는 여전히 여러 가는 다리처럼 보이고, 강하게 감아 조이는 움직임보다는 솟은 가지 울타리로 읽힌다. 근거: [Main 18](KTPIntegratedFrames15/002_AC01/0018.png), [External 34](KTPExternalFrames15/002_AC01/0034.png), [External 81](KTPExternalFrames15/002_AC01/0081.png), [External 83](KTPExternalFrames15/002_AC01/0083.png).

**검:** 0.417/0.458초는 발동 기운 단계이며 1.5초에는 잎 있는 나무가 자리 잡는다. 3초 유지 표본까지 줄기와 수관의 큰 방향은 안정적이다. 예시 Release는 Life×0.77인 약 3.542초다. 직후인 86번(3.583초)에는 본체가 남아 있지만, 94번(3.917초)에는 점상으로 해체되고 110/112번에는 보이지 않는다. Release 직후 나무가 남는 것을 잔존 실패로 판단하지 않았다. 그늘을 제공한다는 의미는 수관 형태에 의존하며 땅에 드리운 그늘 표현은 약하다. 근거: [External 72](KTPExternalFrames15/010_AC80/0072.png), [External 86](KTPExternalFrames15/010_AC80/0086.png), [External 94](KTPExternalFrames15/010_AC80/0094.png), [External 112](KTPExternalFrames15/010_AC80/0112.png).

**공:** 0.375/0.417초에는 발동 기운만 보이며, 35번에서 대나무 열이 형성되어 있다. 58번은 Main에서 더 멀고 External에서 전방 우측으로 더 가까워져 두 시점의 전진 방향이 일치한다. 83번에는 같은 진행 방향 끝에서 점상으로 사라지며, 86번에는 본체·문양이 없다. 표본 사이에 뒤로 되돌아오거나 거대한 원판으로 바뀌는 현상은 없다. 다만 접촉 음영이 약해 심어진 수풀이 전진하는 느낌보다 잎 덩어리가 평행 이동하는 인상이 남는다. 근거: [Main 35](KTPIntegratedFrames15/018_ACF5/0035.png), [Main 58](KTPIntegratedFrames15/018_ACF5/0058.png), [External 58](KTPExternalFrames15/018_ACF5/0058.png), [External 83](KTPExternalFrames15/018_ACF5/0083.png), [External 86](KTPExternalFrames15/018_ACF5/0086.png).

6개 시퀀스 모두 첫 원본과 마지막 원본의 RGB 픽셀이 동일했다. 이 끝점 비교와 실제 열람한 마지막 프레임에서는 잔존이 없다. 중간의 모든 프레임에서 깜박임·미세 튀김이 없다는 전수 판정으로 확대하지 않는다. 점상 소멸은 마지막 구간에서 관찰되는 표현이며, 특히 공의 외부 근접 화면에서는 검은 점 무리가 비교적 또렷하다.

## 실제 Update 검사와 구분

별도 [botanical_play_audit.json](botanical_play_audit.json)은 08:46:31.700 UTC에 시작한 실제 C2 Update/Destroy 진단이다. `PASS_REAL_UPDATE_LIFETIME_ONLY`, 완료 3 / 실패 0 / 오류 0 / 셰이더 오류 0이며 `restored`, `sceneUnchanged`, `sourceUnchanged`, `cleanupObserved`가 모두 true다.

이는 세 식물 본체의 참조·가시성·수명 정리 검사다. 해당 기록 자체도 `art`, `gameplayCasting`, `targetFrameRates`를 `UNVERIFIED`로 남긴다. **실제 Update 검사 통과를 이 영상의 미술 합격이나 입력·인식·게임 규칙 합격으로 바꾸지 않는다.**

마감 판정: 이번 표본 검수에서 새 중대 회귀는 발견되지 않았다. 기존 형상을 보존한 채 접촉 음영과 각 하단 실루엣을 미술 잔여로 남긴다. 전 프레임 연속 시청, 실제 작도·시전, 피해·결박·엄폐·보호 규칙, 전 정점 접지와 목표 FPS는 미검증이다. 이 작업에서는 Unity·코드·원본 파일을 변경하지 않았다.
