# 옴 · 거북 영물 자료 조사

2026-09-11. 웹 및 이미지 검색을 수행하고 공식 소장품 설명과 이미지 링크를 조사했다. 아래 문화유산을 그대로 복제하지 않고, 특징을 새 게임 캐릭터로 종합했다. Meshy 입력은 박물관 원본 사진이 아니라 별도 생성한 Concept.png다.

## 출처

- [국립중앙박물관 — 청자 거북이모양 주자, 덕수5636](https://www.museum.go.kr/MUSEUM/contents/M0502000000.do?relicId=1431&schM=view&searchId=search). 고려 청자, 육각 등껍질과 귀부에서 볼 수 있는 얼굴·목 표현. [공식 이미지](https://www.museum.go.kr/relic_image/PS01001001/duk005/2017/0512090608004/duk005636-00-01.jpg). 사진 저작자 국립중앙박물관, 공공누리 출처표시. 사진은 모델 텍스처로 전사하지 않았다.
- [국가유산포털 — 경주 태종무열왕릉비](https://www.heritage.go.kr/heri/cul/culSelectDetail.do?ccbaCpno=1113700250000). 검색 결과로 소재와 문화유산 식별을 확인했다. 상세 페이지 직접 조회는 403으로 제한되었으며, 그 페이지 전체를 열람했다고 간주하지 않는다.
- [국립중앙박물관 — 청자 거북이모양 연적, 덕수5559](https://www.museum.go.kr/MUSEUM/contents/M0502000000.do?relicId=4251&schM=view&searchId=search). 고려 귀부와 연결되는 거북 형상의 또 다른 사례.

## 게임적 종합

넓고 낮은 지지 자세와 듬직하게 든 머리, 회청색 등갑, 육각 비늘 안의 절제된 구름·물결 장식을 채택했다. 살아 있는 큰 거북이 주인공이다. 석비·연꽃 받침·주전자 손잡이·문자·용의 뿔은 추가하지 않았다. 이는 역사적 영물의 정확한 복원이라는 주장이 아닌 독자적인 게임 디자인이다.

## 제작 경로

웹/이미지 검색 → ConceptPrompt.md의 독자 이미지 생성 → Concept.png를 Meshy 7 image-to-3D 입력으로 사용 → Blender에서 크기·원점·노멀·재질·지면 지지 정리 → FBX 왕복 및 Unity 진단 검수. 원본 사진을 그대로 메시나 텍스처로 쓰지 않는다.
