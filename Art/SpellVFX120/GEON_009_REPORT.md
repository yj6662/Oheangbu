# 건009 단독 수정 기록

2026-09-09. 한 술식씩 제작하며 미술 판정은 사용자가 맡는다.

## 변경

- 짧은 대회복을 몸 양옆의 수련 잎 두 장으로 구성했다. 말린 잎이 올라오고, 한 번의 회복 확정 신호 뒤 0.22초 동안 펼쳐진다. 중앙에 별도의 판을 두지 않았다. 이후 잎이 조금 접히며 아래로 내려가고 공간 디졸브로 소멸한다.
- 잎 메시는 새로 제작한 열린 원반형이며 가로 방향을 원호로 구부린다. 원호를 따라가는 길이를 유지하며 접힘을 표현한다. 전체 캐릭터나 물리 천 변형을 구현했다는 뜻은 아니다.
- SeyeonjeongPavilion의 T_NymphaeaTetragona_Leaf_BC/N 아틀라스에서 좌측 위 잎을 UV로 선택한다. UV 배율 (0.44, 0.44), 오프셋 (0.025, 0.53). 원본 텍스처 픽셀은 수정하지 않았다.
- 펼침에 따라 KTP Pattern_210의 연꽃 선문양을 잎 재질에 더한다. 발동에는 기존 KTP_Cast_LeafBloom, 확정 순간에는 KTP_Impact_LeafBurst를 사용한다. NativeScale 0.26, NativeImpactScale 0.65. 원본 KTP의 메시·재질·곡선을 재사용한다.
- SetBloomReceiver는 공급된 몸통 위치와 수평 방향을 읽는다. SignalBloom은 한 번만 수신하며 중복 수신으로 애니메이션과 확정 효과를 다시 시작하지 않는다. 회복 신호가 없으면 펼침과 확정 효과도 발생하지 않는다. Health·버프·이동·피해를 계산하지 않는다.
- 새 Meshy 생성·크레딧 사용은 없다. 다른 119개 프로필은 변경하지 않았다. 원본 건 프로필은 WoodDetailOriginals/009_AC74.asset.txt에 보존했다. 최초 빌드 검사 중단 뒤 beforeJson을 재생성하지 않았으므로 수정 전 근거는 이 원본 YAML이다.

App MVID: d10aebab-c35f-4ded-9d86-b1cb3a5f99b4. 네 촬영과 실제 Play 검사는 같은 런타임 DLL을 사용했다. 영상은 1280×720·24fps, 시연 회복은 0.28초에 한 번 발생한다. 실제 Play도 관측자가 같은 시점에 표현 콜백을 공급한다. 공통 Play 감사가 전달하는 impact clock 0.6초 때문에 감사의 루트 수명은 1.5초이며, 카탈로그 영상의 기본 수명 1.45초와 구분한다. 새 건의 펼침·KTP 확정 효과는 이 공통 impact clock 대신 전용 Bloom 신호를 따른다.

현재 영상의 회색 캡슐은 크기 비교용이며 실제 플레이어가 아니다. 수정 전21은 D3D12, 현재31은 복구용 D3D11이다. 초기 셰이더 예약어와 재질 속성 블록 초기화 오류를 수정한 뒤 위 최종 검사를 실행했다. 자동 미술 판정은 수행하지 않았다.
