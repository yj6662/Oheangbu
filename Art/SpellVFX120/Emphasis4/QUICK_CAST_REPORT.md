# 가·나·거·너 — 빠른 발동과 문양 방어막 v4

2026-09-10. 구현·기술 검사 완료, 사용자 비주얼 검토 대기.

[비교 영상](http://127.0.0.1:8771/QUICK_CAST_REVIEW.html)에서는 이전 확대판 v3와 이번 v4를 같은 C2 카메라에서 비교한다. 가 → 나 → 거 → 너 순서로 촬영했다. 이전 v3 원본 영상·프로필 및 공급자 KTP 에셋은 보존했다.

## 변경

| 항목 | 이전 확대판 v3 | v4 |

가·나의 비행 시작점은 이미 `ReceivedOrigin`을 사용하므로, 발동 문양을 그 위치로 옮겼다. 발사와 피해 판정을 기다리게 하는 연출 지연은 추가하지 않았다. 카메라에 가까워지므로 화면 크기 감소율은 월드 크기 감소율보다 작다. 화면 구도별 최종 크기·농도 판단은 사용자에게 맡긴다.

너의 기존 Travel 전체와 별도 불투명 막은 새 모드에서 생성하지 않는다. 확인된 받아치기 접점에서만 기존 Contact의 ImpactFire/ImpactCinders/ImpactSmoke를 작은 크기로 복제한다. 투사체 제거 자체는 기존 전투 처리가 담당한다. 투사체 메시 표면을 실제로 태우는 디졸브 셰이더를 추가한 것은 아니다.

나는 불을 운반하는 화염탄이므로 기존 화염 비행을 유지했다. 거는 발동만 변경했고 대나무 방벽과 접촉 효과는 유지했다. 다른 ㄴ 술식 전체에 일괄 적용하지 않았다. 추가 제작 시에도 실제 불은 연소·화염탄·접점 소각처럼 기능에 필요한 경우에 선택해서 사용한다.
