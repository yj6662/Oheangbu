# 가·나 우측 하단 발사 / 거·너 문양 방어막 v5

2026-09-10. 네 술식만 수정하며 v4 프로필·영상과 KTP 공급자 원본을 보존한다. 최종 비주얼 판단은 사용자 검토 대상이다.

[이전/수정 비교 페이지](http://127.0.0.1:8771/OFFSET_GUARD_REVIEW.html)

## 공격

가·나는 실제 작도 투영 카메라를 기준으로 화면 가로⅔, 세로⅓(아래 원점 기준), 카메라 깊이1.6m에서 발사한다. 프로필의 `CameraOffsetLaunch`, `LaunchViewport`, `LaunchDepth`로 관리한다. `BrushStrokeFeedAdapter`가 `Vfx120LaunchPoint.Resolve`로 계산한 점을 전달하며, 문양과 투사체가 같은 점에서 시작한다. 기존 표적·착탄 예약·피해 수치는 유지한다. 이 변경은 비행 궤적을 보여주기 위한 표현 변경이며 원시 작도 좌표를 옮기지 않는다.

명중 효과 역할 배율은2→3.5, 기존 대비1.75배다. 문양 밝기는2.2→3.5이며 별도 `KtpContactBrightness`로 발동 밝기와 분리했다. 표적 안에 가려지는 현상을 줄이기 위해 표시 위치만 카메라 쪽으로0.4m 이동한다. 실제 피해 위치·대상은 변경하지 않는다. 고정0.4m는 현재 인간형 표적을 위한 값이며 모든 대형 적 표면에 정확하게 맞춘 충돌점 계산은 아니다.

## 방어

거·너의 `NativeCastPrefab`을 비워 별도 발동 효과를 없앴다. 기존 대나무 본체/테두리와 지속 화막을 생성하지 않고 Bottom04(목), Bottom09(화)의 투명한 Pattern만 세워 방어막을 구성한다. 거는 배율1.8, 너는1.1로 각각의 기존 NativeScale에 맞춘다. 문양의 초기 펼침과 방어 종료 페이드는 방어막 자체의 표현이다.

실제 방어 접촉은 기존 단일 `CombatLoopWiring.SpawnContact` 경로에서 전용 소스를 선택한다. `GuardContactPrefab`이 연결된 유효 거·너에만 적용한다.

- 거: 대나무 조각24개와 잎 조각14개. 짧게 흩어지고 중력에 따라 떨어지며 축소 소멸한다.
- 너: KTP 화염·불티·연기 재질을 재사용한 짧은 연소 입자와, 약0.14초 뒤의 재 조각28개. 문양 폭발은 포함하지 않는다.
- 기존 별도 `BurnIntercept` 경로는 새 전용 접촉이 있으면 실행하지 않아 이중 소각을 막는다.
- 반성공은 기존 HalfScale을 유지하고 성공 보상을 추가하지 않는다. 실패·만료·방어 교체는 기존 유효 문자/버전 처리를 유지한다.

투사체 자체의 제거는 기존 전투 코드가 담당한다. 불꽃 뒤 재가 흩어지는 입자 표현을 추가했으며, 입사 투사체의 원본 메시를 재로 변환하는 디졸브 시스템은 아니다. 방어 문양은 월드 오브젝트이며 화면 오버레이가 아니다.

## 제출물과 검증 범위

`가_v5`, `나_v5`, `거_v5`, `너_v5`에 각 이전/수정 × 플레이/외부 구도의 영상, 프레임, 발동/접촉 이미지, 설정과 실제 런타임 검사 JSON을 기록한다. `BaselineV4_*.asset`은 이전판 재생용 복사본이다. 새 에셋은 `QuickCast`를 포함하는 기존 KtpEmphasis 폴더의 `TransparentShield_0`, `WoodSplinterContact`, `FireToAshContact`, `DebrisUnlit`, `DebrisShard`다.

촬영은 C2에서 임시 표적과 시험용 입사 신호를 사용한다. 피해·방어 판정·입자 업데이트는 실제 런타임 경로다. 손글씨 입력부터 실제 적 AI 전투까지 촬영한 영상은 아니다. 외부 구도에서도 출발점은 플레이 카메라 기준으로 계산한다. 영상은1080p·24fps·각6초이며 프레임 성능 검사가 아니다.

전체 카메라 피치·이동·벽 근접·대형 적 표면·다중 시전 성능 및 최종 미술 합격은 미검증이다. C2 씬, 공용 플레이어, 전역 노출/블룸, 다른 술식은 이번 변경 대상이 아니다.

최종 수치 결과는 `offset_guard_scope.json`, 각 `report.json`, `v5_contact_audit.json`, `v5_ktp_contact_play_audit.json`으로 확인한다.
