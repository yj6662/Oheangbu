# 수룡 112 — 기존 Meshy 모델 무료 구제 실험 01

판정: **정적 구조 실험은 완료, 최종 아트는 반려.** 낮게 휘는 사족 몸과 긴 꼬리로 바꿀 수는 있었지만, 실제 다섯 시점 렌더에서 몸통이 늘어난 판처럼 보이고 목·꼬리 연결 단차가 뚜렷하다. 이 상태로 리깅이나 Unity 적용을 진행할 품질은 아니다. 추가 유료 생성 요청과 이번 실험의 소비 크레딧은 모두 0이다.

## 원형 조사와 재사용 범위

Source와 Retry02의 실제 GLB를 각각 Blender에 가져와 중성 재질로 확인했다. 이름이나 기존 반려 사유만으로 모델 구조를 판단하지 않았다.

| 원형 | 실제 삼각형 | 원본 정점 | UV 경계 중복을 병합한 정점 | 연결 성분 | 실제 관찰 |
|---|---:|---:|---:|---:|---|
| Source/112_C634/preview | 12,528 | 17,785 | 6,250 | 1 | 직립 몸통, 뿔·수염·긴 주둥이, 목의 비늘과 발톱을 재사용할 수 있음 |
| Retry02/112_C634/preview | 12,549 | 16,571 | 6,276 | 1 | 축이 달라 진단 복제본만 방향 보정. 제대로 세우면 전완과 감긴 꼬리를 가진 직립형이며 낮은 사족 몸은 아님 |

두 원형은 부품별로 분리된 메시가 아니므로 국부 절단이 필요했다. Source를 사용했고 Retry02는 조사용으로만 보존했다. 실제 원형 렌더에서 큰 막 날개는 확인하지 못했다. 따라서 확인하지 않은 날개를 제거했다고 주장하지 않는다. 수정본에는 날개가 없다.

실제 재사용한 부분은 Source의 머리·뿔·수염, 목 비늘 표면, 발톱이 있는 **한쪽 발**이다. 머리 절단 및 경계 막음 후 4,280 tris, 목 비늘 구간 974 tris, 발 원형 1,140 tris였다. 이 수치는 새로 막은 경계 면을 포함하므로 순수 원본 삼각형 수로 해석하면 안 된다. 한 발을 네 위치에 복제했으며 네 개의 서로 다른 Meshy 다리를 재사용한 것은 아니다.

목 비늘은 낮은 S자 중심선을 따라 늘이고 재배치했다. 긴 꼬리 전체, 짧은 상부 다리 연결부와 목 연결 체적은 Blender에서 새로 조형했다. 최종 결과는 **Meshy 부품을 재사용한 Blender 합성 수정본**이며 전체가 Meshy에서 생성된 새 수룡이 아니다.

## 실제 수정과 측정

원형 복제 → 머리·목 표면·발 국부 분리 → 사족 위치와 S자 몸통 배치 → 새 연결 체적/꼬리 구성 → voxel 결합 → 삼각형 축소 → 작은 분리 조각 정리 순서로 작업했다. 원형과 중간 부품은 작업본에 숨겨 보존했다. 최종 메시에는 적용 대기 모디파이어가 없다.

| 항목 | 실제 결과 | 판정 |
|---|---|---|
| 최종 정점 / 삼각형 | 10,924 / **21,872 tris** | 측정 완료 |
| 크기 X / Y / Z | 1.3204 / 4.5606 / 0.8359 m | 측정 완료 |
| 연결 성분 | 1 | 통과 |
| 열린 경계 / 비다양체 경계 / 면적 0 면 | 0 / 0 / 0 | 통과 |
| 유한 좌표 | 전체 유한 | 통과 |
| 작은 분리 조각 제거 | 60개, 184 정점 | 수행 |
| 낮은 사족 몸·긴 꼬리·날개 없는 정적 실루엣 | 다섯 시점에서 확인 | 구조에 한해 통과 |
| 최종 한국 수룡 아트 | 아래 세 가지 큰 문제 잔존 | **실패·반려** |
| UV/PBR, 리깅, 애니메이션 | 새 토폴로지용 제작 안 함 | 미검증 |
| FBX 빈 장면 왕복, Unity 임포트·게임 동작·물리·성능 | 수행 안 함 | 미검증 |

초기 결합 단계는 942,080 tris, 1차 축소는 22,000 tris였으며 작은 조각 정리 후 최종 21,872 tris다. 이는 요청 폴리곤 수나 Meshy 원본 수치를 그대로 표기한 값이 아니라 Blender 최종 메시에서 계산한 수치다. 삼각형 수와 닫힌 메시 조건의 통과는 미술·관절 변형 품질의 통과를 의미하지 않는다.

## 렌더 판정

Cycles 중성 조명·회색 단일 재질, 1280×720, 16:9로 정면·후면·양측·사선을 렌더하고 다섯 원본 이미지를 직접 열었다. 이미지 안에 글자나 라벨은 없다.

1. 양측에서 목 비늘을 늘린 몸통이 매끈한 긴 판/껍질처럼 보인다. 원래 비늘의 간격과 굴곡이 자연스러운 긴 몸 해부로 이어지지 않는다.
2. 목의 구형 연결과 꼬리 시작부의 직각 단차가 눈에 띈다. 수치상 한 메시로 연결되어 있어도 형태의 연속성은 실패다.
3. 앞·뒤 다리가 같은 발의 복제로 보이며 새 상부 다리와 원형 발목의 굵기 차이가 크다. 머리의 동아시아 용 특징은 남지만 몸통·다리와 디테일 밀도가 맞지 않는다. 새 꼬리도 비늘 디테일이 없는 매끈한 체적이다.

따라서 구제 가능 부위는 **머리와 발톱 등 국부 디자인 원형**으로 제한한다. 현재 합성 실루엣을 채택하거나 세부 리깅에 시간을 투입하는 것은 권장하지 않는다. 이번 제한된 1회 실험에서 추가 조형은 중단했다.
