# 송090 단독 수정 기록

2026-09-09. 한 술식씩 제작하며 비주얼 판정은 사용자가 맡는다.

## 변경

- 큰 반원 배열을 최대 6개 목표로 향하는 개별 은침과 서리매듭으로 교체했다. 상078의 24cm 침(12tris)과 서리끈(36tris)을 공유한다. 목표당 침 1개·끈 3개로, 표현 메시 상한은 합계 720tris다. KTP 파티클과 시연용 투사체는 이 수치에서 제외한다.
- `SetInterceptionTargets`는 효과 로컬 좌표·발사/도착 시각·지면 높이를 최대 6개까지 복사한다. `ConfirmInterception`으로 각 목표의 요격 위치와 효과 기준 확인 시각을 전달한다. Begin 이후 설정하며, 이미 확인한 목표를 중복 확인해도 시간을 다시 시작하지 않는다.
- 없는 목표·유효하지 않은 목표는 표시하지 않고, 요격 미확정 목표에는 서리매듭을 만들지 않는다. 각 매듭은 확인 뒤 닫힘·낙하·풀림을 수행한다. 실제 투사체 탐색·충돌·동결·피해에는 쓰지 않는다.
- KTP 발동 문양은 한 번 재생한다. KTP 타격 문양도 최초 확인 위치에서 한 번 재생하고, 나머지 목표는 개별 서리끈으로 표현한다. 모든 목표에 큰 KTP 타격을 중복 생성하지 않는다.
- 프로필의 BodyMesh·AccentMesh·Count(12→6)·PartScale·RibbonCount(2→0)·NativeImpactScale(1→0.45)을 변경했다. KTP 원본 프리팹과 재질 참조, 수명 2.7초는 유지했다. 다른 119개 프로필 해시는 동일하다. 원본은 MetalDetailOriginals/090_C1A1.asset.txt에 보존했다.
