# 겅012 단독 수정 기록

2026-09-09. 한 술식씩 제작하며 비주얼 판정은 사용자가 맡는다.

## 변경

- 곁가지 잔탄을 작은 목 씨앗 두 개로 제작했다. 반쪽 껍질 메시를 두 개씩 짝지어 사용하며, 확정 명중 뒤 각 껍질을 벌리고 짧게 내려보낸다.
- 보유 대나무 재질 M_Bamboo_0_Bark의 나무결·노멀을 재사용하고 누런 씨껍질 색을 더했다. 새로운 Meshy 요청이나 크레딧 사용은 없다.
- 접촉 흔적은 KTP Pattern_192의 중앙 영역을 UV로 선택한다. 알파 문턱을 0.5~0.85로 적용해 옅은 바탕 격자를 줄였다. 원본 텍스처 픽셀은 변경하지 않았다. 실제 문양 가독성은 사용자 검토 대기다.
- 발동은 KTP_Cast_LeafBloom을 NativeScale 0.18로 사용한다. 접점마다 큰 공통 폭발을 추가하지 않고 각 씨앗의 작은 문양 면을 표시한다.
- SetCompanionProjectile은 공급된 주탄의 위치·회전을 읽는다. 비행 후반에 양옆 간격이 조금 벌어지며 주탄의 색·변환·게임 상태를 변경하지 않는다.
- ConfirmCompanionHit은 지정한 씨앗의 확정 접점·법선·시각을 받는다. 발사 설정 없는 신호와 같은 씨앗의 중복 명중은 거절한다. 한 씨앗의 명중으로 다른 씨앗을 터뜨리지 않는다.
- 실제 모든 술식에 동반 발사하는 기능, 투사체 충돌·추가 피해·버프 적용·해제는 미연결이다. 이번 결과는 카탈로그 표현과 이를 구동하는 수신 API다.
- 원본 프로필은 WoodDetailOriginals/012_AC85.asset.txt에 보존했다. 다른 119개 프로필 해시는 동일하다.
