# 오 — 물마루 20 정적 비교 검수

판정: **현재 20은 최종 미술 채택 반려.** 19의 반복 봉우리와 얇은 격자 막을 줄인 개선은 확인했지만, 20은 물결보다 문양을 인쇄한 천막·방패에 가까워졌다. 구조 실험본으로 보존하며, 현재 상태의 영상 촬영·미술 통과 처리는 권하지 않는다.

## 실제 열람 범위

- 새 원본 10장: `KTPIntegratedStills20/109_C624_0..4.png`, `KTPExternalStills20/109_C624_0..4.png` 전부 직접 열람.
- 재열람한 19 비교 원본 4장: Main phase 1·2, External phase 2·3.
- 두 시점 모두 1280×720. 20 메타데이터 촬영 시각은 Main `2026-09-09T10:05:24.3156877Z`, External `2026-09-09T10:05:28.4232427Z`.
- 각 phase의 표본 시간은 약 0.240 / 0.753 / 1.438 / 2.191 / 3.080초. Life는 약 3.423초이므로 phase 4는 소멸 이후 표본이 아니다.
- [Main 메타데이터](KTPIntegratedStills20/109_C624_capture.json), [External 메타데이터](KTPExternalStills20/109_C624_capture.json)는 `PRESENTATION_REVIEW_ONLY`, `gameplayConnectionVerified:false`, 보기용 Path와 예시 cue 사용을 명시한다.

## 짧은 후속 실험에 대한 판단

재질에서 내부 면이 만드는 짙은 띠를 줄이고 Pattern_204를 윗마루의 좁은 영역에 제한하는 1회 실험은 현재 그림에서 보이는 문제에 대응한다. 색을 더 밝게 하거나 전체를 더 크게 만드는 방향은 권하지 않는다. 이 수정 후에도 매끈한 반원 차양·쐐기 실루엣이 지배하면 20 형상은 최종 채택하지 않는 편이 낫다.

이번 검수는 새 정적 원본 10장과 비교 원본 4장에 대한 미술 판단이다. 실제 시간 흐름의 말림·포말 운동, 모든 프레임의 안정성, Life 이후 잔존, 실제 입력·충돌·피해 및 런타임 성능은 **미검증**이다. 코드·Unity·원본 이미지는 수정하지 않았다.

## 구현 측 후속 처리

검수 후 구현 담당이 최종 반려를 채택했다. [Build 실측](water_roll20_build.json)은 2,305정점 / 4,512tris, 열린 경계·비다양체·퇴화 삼각형 0이다. 이 수치는 미술 실패를 상쇄하지 않는다. [10:07:52 UTC Restore](water_roll20_restore.json)로 오의 BodyMesh·BodyMaterial·PartScale만 19로 복원했고, 원본 파일·그 외 프로필 불변을 확인했다. 추가 21 실험이나 20 영상은 실행하지 않았다. 후보는 증거로 보존하며 실험용 활성 코드와 셰이더 분기는 제거했다.

활성 코드 제거·Unity refresh 후 `WaterRestore20Main`에 5개 시점을 다시 촬영했다. [복원 점검](water_roll20_restoration_check.json)에서 원래 오19 프로필과 모든 필드가 일치했고, PNG 바이트는 0·3·4 세 시점에서 19와 동일했다. 1·2는 바이트가 달라 전체 픽셀 동일성을 주장하지 않는다. 구현 담당은 [복원 p1](WaterRestore20Main/109_C624_1.png)을 직접 열어 20의 짙은 반원 차양이 사라지고 기존 물마루가 돌아왔음을 확인했다.
