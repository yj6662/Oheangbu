# 거007 단독 수정 기록

2026-09-09. 한 술식씩 제작하며 비주얼 판정은 사용자가 맡는다.

## 변경

- 구019와 공유하던 NativeField 방벽을 거007에서 분리했다. 대살 7개와 두 가로 지지대, 위쪽의 열린 문양 테두리를 만들었다. 중앙을 채우는 면은 만들지 않았다. 0~0.2초에 펼쳐지고, 패링 성공 뒤 접촉 부근이 휘었다 0.48초 안에 복원된다.
- 대살은 보유 Seyeonjeong 대나무에서 앞서 추출한 M_Bamboo_0_Bark의 색·노멀 텍스처를 재사용한다. 기존 대나무 메시 자체의 복제는 아니며, 새로운 곡선 대살에 UV를 부여했다. 테두리는 KTP Pattern_33의 실제 알파 문양을 사용한다. 이 원본은 잎과 줄기가 엮인 당초 띠이며 죽엽 문양이라고 단정하지 않는다.
- KTP LeafBloom 발동을 유지하고 LeafBurst를 접촉 연출로 연결했다. 현재 거의 NativeScale은 0.32, 접촉 추가 배율은 0.42다. 원본 재질·텍스처·KTP 프리팹은 변경하지 않는다.
- 메시 통계: 대살·지지대 1,146정점/2,256tris, 테두리 130정점/128tris. 합계 **1,276정점/2,384tris**, 본체 렌더러 2개다. KTP 파티클은 별도다. runtime 복사 메시만 변형하고 원본 메시를 쓰지 않는다. 수명 끝에 두 복사 메시를 직접 해제한다.
- 기존 GuardDuration·ParryWindow를 읽어 수명·진한 구간을 정한다. 잔존 구간에는 대살과 문양 농도가 내려가며 종료 직전에 소멸한다. Release/Break 표현 신호는 소멸을 앞당길 수 있지만 판정 수명을 변경하지 않는다.
- BrushStrokeFeedAdapter에서 거의 전방은 플레이 카메라의 수평 방향으로 정하고, 가장 최근 패링 연출만 수신 대상으로 등록한다. 다른 패링 연출이 선택되면 이전 거의 등록을 해제한다. 카탈로그 시연은 등록하지 않는다.
- CombatLoopWiring의 확정된 Wood·Success 결과를 `TrySignalBambooParry`에 전달한다. 유효한 거가 수신하면 기존 임시 성공 버스트는 중복 생성하지 않는다. 반성공 및 거가 없는 경우의 버스트, 판정·먹 환급·그로기·HUD 처리는 유지한다. 접촉 좌표는 연출 표면에 투영·제한하며 실제 충돌점을 수정하지 않는다. 반복 성공은 최초 휘어짐/문양을 다시 시작하지 않는다.
- 원본 프로필은 WoodDetailOriginals/007_AC70.asset.txt에 보존했다. 바뀐 프로필 필드와 나머지 119개 프로필 해시가 유지됐다는 결과는 ge28_scope_check.json에 기록했다. 추가 Meshy 크레딧은 사용하지 않았다.
