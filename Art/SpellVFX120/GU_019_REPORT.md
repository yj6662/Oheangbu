# 구019 단독 수정 기록

2026-09-09. 한 술식씩 제작하며 비주얼 판정은 사용자가 맡는다.

## 변경

- 구의 현재 의도는 **패링 판정·보상이 없는 잔존 광역 결계**다. 전방 방벽인 거와 달리, 반경 1.85m의 여섯 둘레 자리에 열린 대살 지지부를 배치했다. 각 지지부 사이와 결계 안쪽을 채우는 메시를 만들지 않았다. 이 반경은 카탈로그 표현값이며 실제 피해 경감 영역을 뜻하지 않는다.
- 각 지지부는 대살 두 개와 가로대 두 개로 구성한다. 본체는 새로 만든 곡선 메시이며 보유 대나무의 색·노멀 텍스처와 수피 재질을 재사용한다. 전체 크기를 늘려 성장시키지 않고, 지면 아래에서 차례로 올라온다. 생성 시 지지부별 지면 높이를 한 번 읽고 이후 물리 계산 없이 보관한 위치를 사용한다.
- 기둥 사이 문양 면에는 KTP Pattern_126의 맞물린 직선 무늬를 사용했다. 전통 창호 실물을 복원했다는 뜻은 아니다. 기존 KTP_Shield_JadeCanopy의 큰 수직 패널·Aura 계층은 이 시안에서 제외했다.
- 발치 표식은 Bottom04-01의 Pattern 하위 객체만 재사용한 여섯 파티클이다. 원래 재질·사용자 데이터·방출/색/크기 시간 곡선은 가져오고, 메시를 새 평면으로 바꾸고 개별 위치·배율·시작 크기·이동·회전을 조정했다. 원본 KTP 프리팹과 재질에는 쓰지 않는다. 발동에는 기존 LeafBloom을 유지했다.
- `SignalWoodWardHit(index)`는 이미 정해진 표현용 지지부 번호만 받는다. 해당 지지부가 짧게 안으로 기울었다 0.6초 안에 복원되며, 다른 지지부의 피격 시간을 공유하지 않는다. 적을 탐색하거나 새 충돌·피해·패링 보상을 만들지 않는다. 기존 거 패링 연결에도 등록하지 않는다.
- 종료 0.85초 전부터 문양 면이 먼저 마르고, 마지막 0.4초에 대살이 소멸한다. 수명은 기존 Vfx120Effect의 수명 처리를 따른다. 구의 실제 게임 능력과 피격 신호 연결은 미완료이며 카탈로그에는 시연 신호만 공급한다.
- 원본은 WoodDetailOriginals/019_AD6C.asset.txt에 보존했다. 변경 필드는 gu29_scope_check.json에 기록했고, 나머지 119개 프로필 해시는 같다. 새 Meshy 요청이나 추가 크레딧 사용은 없다.
