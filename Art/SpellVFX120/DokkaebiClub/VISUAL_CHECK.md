# 도깨비 시안 확인

- 생성 콘셉트와 Meshy thumbnail, Blender 렌더에서 머리 뿔 없음, 오른손의 몽둥이, 큰 원형 눈·문양·넓은 어깨 확인.
- 원형의 몽둥이가 두 발보다 약23cm 아래까지 내려왔음. 모델 전체를 회전한 시험판은 외부 시점에서 발 들뜸이 보여 채택하지 않음.
- 최종은 몸을 세우고 몽둥이 하부 길이를 줄였다. 낮은 높이에서 연결된 메시 영역을 추출해 양발과 몽둥이를 구분했고, 손잡이 파지 영역은 보정하지 않았다.
- 최종 원본 좌표의 세 최저점 높이: 0m, 0.0000678m, 0m. support_components.json에 보정 전후 기록.
- 정적 모델 검수이며 손가락 리깅, 휘두르기 중 파지 유지, 플레이 전투는 미검증. 최종 미술 평가는 사용자 검토.
