# 고013 단독 수정 기록

2026-09-09. 한 술식씩 제작하고 비주얼 판정은 사용자가 맡는다.

## 변경

- 일제 죽창을 새로운 대나무 가시 메시로 제작했다. 돌출된 마디, 사선 절단부, 움푹한 내부와 밝은 속살을 두고, 고정된 굵기·높이·기울기가 다른 17개를 영역에 배치했다.
- 기존 대나무 재질 M_Bamboo_0_Bark의 색·노멀 텍스처를 사용한다. 새로운 BambooSpike 셰이더는 절단부를 구분하고 끝부터 세로 섬유 형태로 소멸시킨다. 원본 재질·텍스처는 보존했다.
- KTP Pattern_192의 중앙 식물 문양을 다섯 바닥 면에 배치했다. UV 선택과 알파 문턱으로 옅은 격자를 줄이는 방식이다. 원본 이미지 변경은 없으며 최종 가독성은 사용자 검토 대기다.
- KTP_Cast_LeafBloom과 KTP_Impact_LeafBurst를 재사용한다. 발동은 지정 영역 중심으로 옮기고, NativeScale 0.32·NativeImpactScale 0.6을 적용했다.
- 기존 CombatLoopWiring → BrushStrokeFeedAdapter가 전달하는 Circle 계획의 중심·반경·Delay를 읽는다. 새 가시는 Delay 직전 0.13초 동안 지면 아래에서 솟아 Delay에 완전히 드러난다. 모든 가시가 같은 시각을 사용하며 표시 중 크기를 늘리거나 줄이지 않는다.
- 바닥 높이는 생성 시 가시와 문양 위치에서만 기존 GroundHeight로 표본한다. 가시를 별도 충돌체로 만들지 않으며 인식·피해·시전 시계와 영역 판정 코드는 변경하지 않았다.
- 유효한 원형 계획이 없으면 새 가시와 구형 가시 본체를 모두 생성하지 않는다. 기존 KTP 발동 장식은 별개다. 실제 플레이어 시전·피해 회귀는 이번에 실행하지 않았다.
- 다른 119개 프로필은 변경하지 않았다. 원본은 WoodDetailOriginals/013_ACE0.asset.txt에 보존했다. 새 Meshy 요청이나 크레딧 사용은 없다.
