# KTP 원본 공통 연출 적용

2026-09-10. 비주얼은 사용자 검토 대기.

## 변경

- 모든 속성의 배정된 100개 프로필에 원본 KTP 재생 모드를 적용했다. 미배정 20개는 수정하지 않았다. 각 프로필의 본체 메시·재질·NativeBody·Botanical·Meshy 참조와 비행 시간·수명은 전후 동일하다.
- 기존 속성별 매핑에 따라 Fly의 완전한 Charge/Explosion 계층, Bottom 전체 계층을 사용한다. 공급자 원본을 수정하지 않고 배치용 프리팹에서 참조한다. 색은 속성 팔레트로 바꾸면서 명암·알파를 유지한다.
- 원본 모드에서는 입자 상한을 재배분하지 않으며, 임의 암화·페이드·정지 자세를 적용하지 않는다. 일회성 연출은 원본 주기 이후 남은 입자가 끝나도록 두고, 지속 효과는 종료 신호에서 방출을 멈춘다.
- 본체가 먼저 사라져도 원본 꼬리 연출은 같은 씬에 잠시 남아 자연 종료한다. 게임 판정이나 본체 수명은 늘리지 않는다.
- 기존 받아치기·플레이어 피격 연결을 유지했다. 받아치기는 속성색을 적용하며 기존 성공/반성공 판정·보상을 유지한다. 플레이어 피격은 기존 원본색을 유지한다.
- 실제 예약 피해 처리에서 양수 피해가 살아 있는 적에게 적용되는 경우 원본 명중 효과를 생성한다. 접점 정보가 없는 현재 데이터에서는 대상 위치 위 0.8m를 사용한다. 실제 충돌 표면 좌표로 주장하지 않는다.
- 불탄·화막·화 오라·화 잔탄·대나무탄·목 동반탄의 중복 접촉 레이어를 억제하고 확정 접촉 연출을 원본으로 연결했다. 부착 불씨·지속 연소·회복 위치 등 술식 의미를 가진 본체 표시는 유지한다.

## 전달물

- [5속성 원본 검토 페이지](http://127.0.0.1:8771/ORIGINAL_KTP_REVIEW.html): 960×540, 24fps 역할별 영상 20개. 발동·명중·소환진·방어를 분리 촬영했다. 기본/외부 C2 입력 시전 비교 영상은 이번 전달물이 아니다.
- `ORIGINAL_KTP_PROGRESS.json`: 한 술식씩 수행한 100개 변경 기록과 본체 전후 비교, 원본 출처.
- `OriginalKtpBackups`: 프로필별 수정 전 사본.
- `OriginalReview/*/report.json`: 원본/복제본의 계층·재질·수명·입자 상한과 촬영 중 입자 수.

## 검증과 한계

- 원본 계층·재질·입자 상한·duration·loop 설정 비교와 20개 역할의 재생/종료를 검사했다. 영상 20개는 인코딩 후 전체 디코드했다. 비주얼 합격을 의미하지 않는다.
- `original_play_audit.json`: 격리된 실제 Play에서 5속성×4역할, 짧은 술식 루트 뒤 꼬리 연출, 적 명중·0 피해·치명타·죽은 대상 처리를 확인한다.
- `ktp_contact_play_audit.json`: 기존 받아치기·플레이어 피격 107개 확인 항목을 재검사한다.
- 100개 전부의 실제 입력 시전·적 전투 회귀는 미검증이다. 이미 게임에 연결된 피해 경로만 확장했으며 나머지 술식의 피해·회복·소환 AI·환경 상호작용을 구현한 것은 아니다.
- 원본 입자 상한과 실제 활성 입자 수는 다르다. 전체 전투의 CPU/GPU 비용, 다중 동시 시전 FPS는 미검증이며 150fps 등의 성능 보장을 하지 않는다.
- 기존 ㄱ/ㄴ 검토 페이지는 이전 제작본 기록이다. 이번 공통 연출의 비주얼은 새 원본 검토 페이지를 사용한다. 사용자 작업 씬은 KTP Preview로 복귀한다.
