# 손등 위 파지 수정

요청한 손등 위·자루를 덮는 방향을 Unity 표현 리그에 적용했다. 기존 부착 방향에서 손등만 돌리면 전완과 손 진행 방향이 어긋났다. 실제 비교에서 이전 손목 축 비틀림 172.51°, 굽힘 84.94°를 확인했다. 새 중앙 자세는 축 비틀림 약 0°, 굽힘 8.29°다.

- 기존 폴리시 프로필과 FBX·Blender 메시를 보존했다. 이 변경은 Recovery 프로필의 붓 부착 회전·손가락 로컬 회전·작은 부착점 보정과 Unity IK에 적용했다. 모델 재생성은 하지 않았다.
- C02 휴식 자세의 검지·소지 시작점으로 손 진행 방향과 손등 법선을 교정했다. 손등은 카메라 위를 향하고, 전완 축 회전을 먼저 처리해 손목 단면에 회전을 몰아넣지 않는다.
- 팔꿈치 위치는 손 진행 방향과 함께 계산한다. 화면 끝에서 붓끝을 억지로 맞추는 대신 깊이·방향 후보를 함께 조사하고 손목 굽힘을 벌점에 포함했다. 최대 어깨 추가 이동 5cm 제한 및 원래 팔·붓 길이를 유지한다.
- 엄지·검지·중지·소지 굽힘과 부착점을 국부 보정했다. 원본 finger offset은 FingerFit/profile_before.json 및 기존 프로필에 보존했다. 적용값은 PlayerGesture_Overhand_Final.asset에 별도 기록했다.

## 결과

87개 진단 검사 통과: 9개 화면점의 손등 방향, 손목 굽힘, 축 비틀림, 실제 변형 붓끝 오차 및 기존 표현 검사. 수치의 전체 목록은 summary.json 참조.

접촉 검사는 **실패**: 현재 포즈 정점 검사에서 최대 피부 관통 약 0.886mm로 0.5mm 기준을 넘는다. 초기 방향 반전 직후의 약 6.2mm에서 줄었지만 RIG_PASS나 완전한 손 리깅 완료로 처리하지 않는다. 자세가 바뀌어 기존 고밀도 삼각형 표면 샘플링 결과는 새 파지의 근거가 아니다. 현재 검사 역시 정점 접촉 검사이며, 전체 면·모든 동작의 소매 관통·연속 실제 입력과 외형 승인은 미검증이다.

정지 프레임은 실제 Unity 렌더다. Before는 동일 장소에서 이전 부착·손가락·roll을 일시 복원한 비교 장면이며, 원자료 scope에 임시 재정의를 적었다. 원시 획, 피해·시전 입력, 몸/붓 길이는 변경하지 않았다. 식생·지형·조명 설정은 변경하지 않았다. 새 방향 탐색의 연속 작도 CPU 비용은 재측정하지 않았다.

빌드는 갱신하지 않았다. 기존 배포 후보에는 이번 수정이 포함되지 않는다. Unity는 Edit Mode로 복귀했고 테스트 저장 슬롯 선택을 해제했다.
