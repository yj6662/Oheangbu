# 붓의 앞뒤 수정

붓털은 엄지·검지 쪽, 끝고리는 새끼손가락 쪽으로 수정했다. 이전 Overhand 결과는 앞뒤가 반대로 설정된 반려 결과다.

## 변경

- 손에 부착하는 붓의 불필요한 180도 회전을 제거하고 올바른 파지 위치·손가락 오프셋을 복구했다.
- 손등이 위로 드러나도록 팔뚝 회전과 손목 자세를 함께 조정했다. 붓의 앞뒤와 손등 회전을 분리했다.
- 파지 기준 회전 18도에 손등 기울기 40도를 더한 DrawingBrushRoll 58을 저장했다. 근접 손목이 오른쪽 아래에서 읽히도록 후보 자세에 구도 비용을 추가했다.
- 검지–새끼손가락 방향과 붓털 방향의 내적으로 앞뒤 검사를 추가했다. 붓을 거꾸로 돌리는 진단 옵션도 차단했다.
- 이번 수정은 기존 메시·골격의 파지 설정과 런타임 IK 수정이다. 새 Blender/FBX 모델을 만들지 않았다.

## 결과

| 항목 | 판정 | 근거 |
|---|---|---|
| 엄지 쪽으로 향하는 붓털 | 통과 | 9개 지점 최소 내적 0.9608, 기준 > 0.5 |
| 합성 입력의 수치 검사 | 통과 | 96개, 실패 0개 |
| 실제 변형 붓끝 | 통과 | 최대 0.282px, 기준 2px |
| 손목 꺾임 | 통과 | 최대 40.03도, 기존 검사 기준 |
| 현재 파지 정점 접촉 | 통과 | 표본 정점 관통 0.000mm |
| 중앙·왼쪽 아래 외형 | 사용자 검토 | 실제 Unity 1920×1080 정지 캡처 |
| 오른쪽 위 극단의 손 가시성 | 실패 | 붓끝은 도달하지만 손은 화면 밖에 있음 |
| 모든 자세의 소매·면 내부 관통 | 미검증 | 접촉 검사는 현재 자세의 정점 표본에 한정 |
| 실제 연속 입력·보행 중 파지 전환 | 미검증 | 이번 검사는 합성 입력의 동기식 자세 평가 |
| 새 빌드 | 미제작 | 기존 빌드 변경 없음 |

첫 캡처에서는 팔이 카메라를 향해 겹치면서 소매 잘린 경계가 크게 드러났다. 그 결과는 채택하지 않고 손등 각도와 구도를 수정했다. 원본 실패 캡처는 관련 txt가 가리키는 폴더에 보존했다.

캡처는 진단 명령에서 roll 58을 임시 적용한 것으로, 그 뒤 동일 값이 프로필에 저장되었다. 캡처 보고서의 당시 디스크 해시와 현재 저장본 해시는 다를 수 있다. 최종 수치 QA와 contact는 저장된 roll 58로 재실행했다. 수정된 프로필 사본과 해시는 함께 제공한다.

사용자 저장과 분리한 시험 슬롯에서 검사했고 Play를 종료한 뒤 시험 슬롯 설정을 해제했다. 촬영은 한 장씩 진행하며 각 촬영 전 커밋 사용률 85% 제한을 적용했다.
