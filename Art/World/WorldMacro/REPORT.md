# 5강토 V4 — 짙은 지면·옅은 강토색과 이동 흐름

2026-09-11 · TEST · 결정 #207 · **기하56항목·귀환4연결 통과 / 콜라이더 HIGH0·편안함 WARN2478 / 짧은 이동8구간 도달**

땅과 산을 더 어둡게 하고 강토별 오행색을 옅게 더했다. 산 높이를 유지하면서 급사면을 피하도록 길을 옮기고, 교량 접근과 거점 도착부의 장애물을 보완했다. [V3 보존본](Versions/v3_before_realm_tint/REVIEW.html)과 별도로 비교하며, C2와 기존 프롤로그는 유지한다.

## 지면과 색

매크로 전용 `WorldMacroTerrain.shader`와 `MacroGround.mat`을 사용한다. ToneCeiling은0.62→0.25, InkDensity는1.16→1.75, GroundPathTones는(0.23,0.57)→(0.07,0.18)이다. 강토색 강도0.38과256×384 지역 마스크에 기존 오행 팔레트를 적용하고, 약560m 전이 구간에 토질·경사·불규칙한 얼룩을 섞는다. 발광은 추가하지 않았다. 하늘·조명·노출을 함께 어둡게 조정한 결과는 아니다.

색조 비교2쌍은 **같은 V4 지형·카메라**에서 V3 지면값과 강토색 OFF를 복원한 화면을 현재판과 비교한다. 강토색 비교2쌍은 새 어두운 지면을 유지하고 강토색만 끄고 켠다. 지도 음영은 높이 자료의 시각화이며 실제 지면 색을 재현하는 렌더가 아니다.

## 길에서 확인하고 고친 부분

- 실제 PlayerRig와 같은 높이2m·반경0.5m·경사 한계45°·단차0.3m 기준으로 지면과 교량 콜라이더를 검사했다. 수학적 높이만으로 통행을 판정하지 않았다.
- 경로 탐색에 실제 표면·횡경사 확인을 반영하고 급한 모서리와 막힌 연결을 우회시켰다. 거점의 대체 건물은 도착 공터 옆으로 옮겼고 교량 끝에 지면과 연결되는 접근부를 보완했다.
- 산계 저작선36개, 분지·외곽·수계는 유지했다. 80m 전역 높이 표본의 V3→V4 변화는0이다. 경로36개·거점31개, 지형587,034tris·전체 생성 메시897,428tris다.

HIGH와 WARN은 **표본·문제 코드별 기록 수**로 고유 장애물 개수가 아니다. 길이 바뀌어 전후 표본 수도 다르다. 초기 경사 초과·상체 겹침·교량 턱 기록은 새 표본 검사에서 해소됐지만, 편안한 이동 기준 경고는 횡경사2,216건·종경사262건 남았다. 특히 서쪽→북쪽 고개, 남쪽 도하→역참, 청림 고개→역참에서 경로 폭 전체의 편안함을 더 확인해야 한다.

Editor에서 CharacterController.Move를 수동 시간 간격으로 호출한 **20m 구간4곳의 양방향8검사**는 모두 구간 끝에 도달하고 마지막 발밑 지지·접지가 유지됐다. 남쪽 교량 접근부·남문 중심·잔여 급경사·주막 지선 대조 구간을 확인했다. 남문 중심 검사는 남쪽 접근 전체를 통과한 결과가 아니다. 실제 사용자 입력이나 전체 길 완주·가마 주행은 미검증이다. [콜라이더 기록](flow_audit.json) · [짧은 이동 기록](flow_move_probe.json).
