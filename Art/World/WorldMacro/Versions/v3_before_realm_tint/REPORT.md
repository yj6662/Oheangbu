# 5강토 V3 — 길 양옆 산지와 지면 농도

2026-09-11 · State: TEST · 결정 #206 · **V2→V3 비교 / 기하56항목·귀환4경로 통과 / 스크린샷14장·기존8파일 보존**

넓은 평야를 일정량 확보하던 지침을 정착·이동·조우에 필요한 적당한 평지를 남기는 방향으로 바꿨다. 기존 큰 산계를 따라 산자락과 구릉을 보완하고, 땅·산 재질을 조금 더 어둡게 조정했다. 이 보고서는 V2와 V3를 비교한다. 이전 V1→V2 산지·귀환길 결과는 [V2 보존 보고서](../v2_before_route_relief/REPORT.md)에 따로 남아 있다.

## 이번 변경

- 산계 저작선을26→36개로 보완하고, 넓게 땅을 평탄화하던 분지7개의 영향 범위를 줄였다. 분지 수는 같지만 기존 분지 값을 그대로 보존한 변경은 아니다.
- 황경·현강·철옹의 정착 공간, 청림 외림·심부와 적로의 활동 평지는 남기면서 주변 산자락이 더 가까이 읽히도록 조정했다. 실제 외곽75.14km²와 수계 저작은 유지했다.
- 기존36개 경로 중31개가 새 지형에 맞춰 평면 선형을 바꿨다. 산세와 경로의 조정이 함께 포함되어 전후 차이를 산 높이 하나만의 효과로 해석하지 않는다.
- 모든 강토의 황경 귀환 연결은 유지했다. 길은 가도 또는 도보 대안이며 실제 가마·진행 게이트·전투·상세 도시를 구현한 단계는 아니다.
- 수정한 룩은 매크로 씬 소유 `MacroGround.mat`의 세 값이다. 하늘·조명·노출·거리 대기 설정을 함께 어둡게 만들지 않았다.

넓은 지역 내부를 의무적으로 만들던 문구는 [SPEC-WORLD-MACRO](../../../Docs/Specs/SPEC-WORLD-MACRO.md), Production Bible의 국부 지침과 결정 #206에서 갱신했다. 길 양옆을 일정한 산벽으로 채우는 방식이 아니라 높낮이와 갈라짐이 다른 산자락을 목표로 한다. 자연스러운 밀도와 반복감은 최종 미술 검토 대상이다.

## 길 양옆의 지형 표본

두 버전의 실제 경로를 수평거리160m 간격으로 각각 표본화했다. V2는310점, V3는402점이다. 길 자체가 바뀌어 **동일 위치의 개선률이 아니라 각 버전 실제 길의 집계 비율**이다. 표본 수로 나눈 값이며 길이 가중치가 아니고 공유 끝점은 경로별로 중복될 수 있다.

| 상대 지형 조건 | V2 실제 길 | V3 실제 길 | 변화 |
|---|---:|---:|---:|
| 왼쪽 조건 만족 | 89.35% | 95.77% | +6.42%p |
| 오른쪽 조건 만족 | 88.06% | 93.28% | +5.22%p |
| 양쪽 모두 | 78.39% | 89.05% | +10.66%p |
| 한쪽 이상 | 99.03% | 100.00% | +0.97%p |
| 양쪽 모두 미달 | 0.97% | 0.00% | -0.97%p |

계산은 눈높이1.8m에서 옆35~145° 방향을10° 간격으로 나누고120~1200m 거리의 지형을 확인한다. 높이 차10m·고도각2° 이상인 지형이12개 방향 중3개 이상이면 해당 측의 조건을 만족한다. 기준은 전후에 동일하다. **이는 낮은 진단 하한이며 ‘거의 항상 산이 보인다’는 시각적 합격 정의가 아니다.**

80m 격자의 잠재 지형 실루엣이므로 앞산의 가림, 건물·숲·조명·그림자와 실제 렌더 깊이는 고려하지 않았다. 좁은 도로 절개·갓길·작은 언덕을 세밀하게 판정할 수 없으며, 도시나 도하점에서 한쪽이 열렸다고 결함을 뜻하지 않는다. 실제 눈높이 이미지를 함께 검토한다.

고정 V2 위치310점의 지형 비교도 원문에 보존했다. 이 중234점은 바뀐 신도로 밖이므로 주지표로 사용하지 않는다. [route_relief.json](route_relief.json)의 `baseline`과 `currentRouteAudit`가 위 표의 근거이고, 최상위 `current`는 옛 위치의 보조 비교다. 구간별 좌·우 조건 미달 범위는 표본 중간점으로 추정한 길이이며 페이지의 펼침 표에서 확인할 수 있다.

## 땅·산 재질의 전후

| MacroGround 값 | 이전 | 수정 |
|---|---:|---:|
| `_ToneCeiling` | 0.72 | 0.62 |
| `_InkDensity` | 1.06 | 1.16 |
| `_GroundPathTones` | 0.26 / 0.64 | 0.23 / 0.57 |

산의 밝은 면 상한과 지면 톤을 조금 낮추고 먹 농도를 올렸다. 다른 재질과 전역 노출·하늘·조명·거리 씻김은 같은 조건을 사용한다. 조감에서는 기존과 같이 매크로 재질 사본의 거리 씻김을 일시적으로0.10으로 낮춰 산세를 읽고, 지상은 기본0.58을 사용한 뒤 복원한다.

V2→V3 지형 스크린샷은 지역·경로의 변화도 포함하며 동일 카메라 비교가 아니다. 특히 청림 고개 지상 화면은 V3의 새 가도를 읽도록 위치와 방향을 다시 잡았다. 그 화면을 색조만의 전후 증거로 사용하지 않는다. 별도의 황경·적로 색조 비교는 **같은 V3 지형과 완전히 같은 카메라에서 위 세 값만 복원**한 이전 화면을 사용한다. 두 종류 비교를 혼동하지 않도록 페이지에서 나눠 보여준다.

## 황경 귀환 거리 재계산

이번에는 V2와 V3의 같은 강토 중심을 출발점으로 사용했다. 무방향 경로 그래프에서3D 거리 합계가 가장 짧은 경로를 고른 뒤 그 동일 경로의 시간을 환산한다. 최단시간 경로와 실제 완주 기록은 아니다.

| 출발 | V2 거리 | V3 거리 | V3 가도 / 도보길 | 전부 도보4.5m/s | 가도14·도보4.5m/s |
|---|---:|---:|---:|---:|---:|

산세와 경로가 바뀌면서 네 거리 모두 늘었다. 적로는 기존 가도 대신 북쪽 안부 도보 대안이 현재 거리 최단경로로 선택된다. 황경으로 돌아올 수 있다는 연결은 유지하지만 통행 해제나 가마 운행을 구현한 의미는 아니다. 전체 경로 ID·출발점·시간은 [return_routes.json](return_routes.json)에 남겼다. V1 청림 주막 대리 출발 비교는 V2 보존 기록에만 해당하며 이번 표에는 적용하지 않는다.

## 촬영과 보존

새 지형의 기본12장(조감6·지상6)과 동일 V3 색조 비교용 이전 이미지2장, 총14장을 순차 촬영했다. 모두1920×1080이며 이번 촬영 응답의 최고 시스템 커밋은84.3%였다. 지상6시점·전체 조감과 지역 조감5시점을 실제 이미지로 확인했다. 청림 고개에서 지형만 보이던 방향은 실제 가도를 읽는 구도로 재촬영했다. 영상은 제작하지 않았다. 시스템 커밋85% 이상에서는 새 촬영을 시작하지 않는 기준을 유지했다.

C2·프롤로그·룩·공용 PlayerRig·SpellBook의 최종8파일 SHA-256 동일성을 재확인해8/8 통과했다. `motion_probe.json`은 V1의 검사 기록이며 V3에서 다시 실행한 것으로 보고하지 않는다. 실제 가마·AI·전투·보상·저장·세계 전체 완주와 런타임 성능은 이번 지형 수정에서 미검증이다.
