# 5강토 지형 보완 — 가지능선과 황경 귀환길

2026-09-11 · State: TEST · **산지 보강·귀환 연결 / 기하56항목·귀환 연결4항목 통과 / 새 스크린샷12장**

큰 산계에 가지능선을 더하고, 각 강토에서 황경으로 되돌아가는 길을 기존 가도와 도보 연결로 보완했다. 지형의 불규칙한 외곽과 분지·수계 저작은 유지했다. 최종 기하56항목과 네 강토의 황경 연결 계산은 통과했다. 실제 가마·플레이어 완주 검증과 최종 미술 승인을 뜻하지 않는다.

## 변경 전 자료와 범위

이전 전체 지형 검토본은 [V1 검토 페이지](../v1_before_mountain_returns/REVIEW.html), [V1 보고서](../v1_before_mountain_returns/REPORT.md)에 보존했다. 이전 지도·지형 표본·12장 스크린샷·측정·Seed 원문도 같은 디렉터리에 남겼다. 이번 보고서의 수치는 새 `sheet.json`, `terrain_grid.json`, `measurements.json`, `return_routes.json` 기준이다.

- 독립 씬 `W_WorldMacro_Blockout`의 거친 지형과 이동망을 수정했다. 상세 도시·숲·주막·광산·교량은 대체 형상 단계다.
- 가도에만 가마14m/s, 도보길에는4.5m/s를 적용하는 검토 가정을 유지한다. 실제 가마 시스템이나 월드 스트리밍을 만들지 않았다.
- 새 길은 지리 연결 예약이다. 북·동쪽의 황경 접근 경로가 생겨도 기존 남문 관문전이나 게임의 통행 해제 규칙을 변경하지 않는다.
- 원래 청림→청룡→국 재방문→상경 가도→황경 남문 흐름을 보존하며, 바이블의 고정 시간·좌표는 공간 설계의 강제 기준으로 사용하지 않는다.
- 영상은 제작하지 않는다. 조감과 플레이 눈높이의1920×1080 정지 이미지만 갱신한다.

## 산지 변화

| 항목 | 이전 → 현재 | 해석 |
|---|---:|---|
| 산계 저작선 | 12 → 26개 | 가지능선14개 추가. 실제 산봉우리 개수 아님 |
| 분지 / 수계 | 7 / 6, 저작 값 동일 | 기존 평지와 물길 관계 보존 |
| 불규칙한 저작 외곽 | 75.14km², 동일 | 8×12km 할당 범위96km²와 구분 |
| 이전보다25m 이상 높아진 영역 | 약15.86km² | 80m 격자 표본의 셀 면적 환산 |
| 이전보다75m 이상 높아진 영역 | 약10.96km² | 같은 표본 방법 |
| 표본 최대 / 평균 높이 증가 | 433.11 / 28.79m | 측량 면적·실제 플레이 가능 면적 아님 |
| 거점 / 경로 | 28 / 28 → 31 / 36 | 새 고개3곳과 귀환 도보 구간8개 |

높이 변화는 동일한80m 지형 표본을 비교한 값이며 렌더 지형의16m 격자 전체를 면적 적분한 결과는 아니다. 외곽·분지·수계의 저작 데이터가 그대로인지도 비교했다. 산이 추가되었다는 이유만으로 지역 전체를 좁은 통로로 만들지는 않았으며, 실제 분지의 개방감과 산줄기의 자연스러움은 사용자 검토 대상이다.

새 고개는 황경 북산 귀환 고개, 청림 서쪽 산기슭 귀환 고개, 적로 북쪽 귀환 안부다. 지도에서 `귀환길 추가분` 레이어가 새 여덟 구간을 자주색으로 표시한다. 기존 갈색 가도·녹색 도보 길과 함께 읽으며, 표의 강토 버튼을 누르면 실제 최단거리로 선택된 길을 강조한다.

## 황경까지의 연결과 거리

무방향 저작 경로 그래프에서 **3D 거리 합계가 가장 짧은 경로**를 선택했다. 이후 그 동일 경로에 속도를 적용한다. 최단시간 경로를 따로 탐색하거나 실제 캐릭터로 전 구간을 완주한 값이 아니다. 가도·도보 구간은 양방향 지리 연결로 계산하며 진행 게이트는 포함하지 않는다.

| 출발 | 이전 거리 | 현재 거리 | 현재 가도 / 도보길 | 전체 도보4.5m/s | 가도14m/s·도보4.5m/s |
|---|---:|---:|---:|---:|---:|
| 청림 외림 | 금표 주막 출발3.96km | 3.61km | 0 / 3.61km | 13.4분 | 13.4분 |
| 적로 전장 | 8.22km | 4.39km | 3.72 / 0.67km | 16.3분 | 6.9분 |
| 철옹 관성 | 3.19km | 3.19km | 3.19 / 0km | 11.8분 | 3.8분 |
| 현강 옛 도읍 | 10.01km | 5.96km | 2.55 / 3.41km | 22.1분 | 15.7분 |

- **청림:** 이전에는 청림 외림 중심이 그래프에 연결되지 않아 금표 주막을 비교 출발점으로 삼았다. 현재는 청림 외림→금표 주막→서쪽 산기슭 고개→황경이다. 시작점이 다르므로 두 거리 차이를 단축량으로 제시하지 않는다.
- **적로:** 기존 남쪽 계류 교량행 가도와 새 교량→남문 연결이 선택되어 약3.83km 줄었다. 기존 가도 정렬도 조정되어 새 안부 도보길 하나만으로 줄어든 결과가 아니다. 안부를 지나는 대안은 존재하지만 이번 거리 최단경로로 선택되지 않았다.
- **철옹:** 기존 동쪽 고개→황경 서쪽 교량 경로가 계속 선택된다. 이미 짧은 연결이 있으므로 불필요한 길을 더 만들지 않았다.
- **현강:** 옛 도읍 남쪽 계류 교량→북쪽 교량→송악 남쪽 고개→황경 북산 귀환 고개→황경으로 약4.05km 줄었다.

경로 ID·거점 순서·초 단위 환산값은 [return_routes.json](return_routes.json)에 있다. 가마14m/s는 검토용 가정이며 가감속·회전·전투·정차 시간을 포함하지 않는다.

현재 저작 지형은88청크·587,034tris다. 배경 연장과 대체 형상을 포함한 씬 전체는894,377tris로 집계했다. 이는 특정 카메라의 가시 삼각형 수나 GPU 비용 측정이 아니다. 기술 검사 당시 시스템 커밋은81.54%였다.

현재 가도18구간의 합계 길이는22.91km, 도보18구간의 합계는18.27km다. 여러 경로 합계이므로 하나의 여정 거리로 해석하지 않는다. 이전 가도 합계의 변화에는 기존 선형 조정도 포함된다.

경사·곡률은 별도 제한을 남긴다. 기본 최대/95% 경사는 교량 예약점 반경150m 표본을 제외하며 그 구간의 경사는 별도 `maxBridgeApproachGradeDeg`로 보고한다.

- 일반 가도 최대 표본 경사21.57°(`Road_WestPass_NorthPass`), 최소 곡률 반경7.66m(`Road_NorthPass_Bridge`). 실제14m/s 가마 주행 합격 수치로 해석하지 않는다.
- 교량 접근 최대31.58°(`Road_NorthBridge_OldCreek`). 상세 상판·램프와 이동체 검증이 필요하다.
- 새 북쪽 귀환길 최대7.97°, 청림 산기슭 귀환길 최대21.98°, 적로 안부 대안 최대31.29°. 안부는 실제 보행 검사 전의 거친 지형 길이다.
- 폐광 연결 최대38.76°(`Trail_Mine_Inn`). 시작 구간의 세부 지형·계단·캐릭터 충돌은 후속 상세화 범위다.

## 촬영과 보존

새 지형의 조감6장·플레이 눈높이6장을 한 장씩 재촬영했다. 전체 조감과 지상6시점, 지역 조감5시점을 실제 이미지로 확인했으며 새로 생긴 중대한 카메라 가림 문제는 발견하지 않았다. 총12장은 모두1920×1080이며 촬영 응답의 최고 시스템 커밋은 이번 보완에서82.6%였다. 이전 촬영 최고83.24%와 구분한다. 영상은 만들지 않았다.

조감은 매크로 재질 사본의 거리 씻김을 일시적으로0.10으로 낮춰 산세를 읽기 쉽게 촬영한다. 지상 시점은 기본0.58이며 촬영 후 복원한다. C2 원본의 영구 룩을 바꾸는 조작이 아니다. 화면 안에는 설명문을 넣지 않으며 위치와 촬영 종류는 페이지에 적는다. 시스템 커밋85% 이상에서는 새 촬영을 중단한다.

최종 `preservation.json`을19:32에 다시 확인하여 C2·프롤로그·룩 설정·공용 PlayerRig·SpellBook 등8개 파일의 SHA-256 동일성을 통과했다. `motion_probe.json`은 V1의 실제 카메라 이동2구간 기록이며 새 지형에서 재실행한 검사로 보고하지 않는다.

## 남은 한계와 확인 방법

- 저밀도 산의 면 경계, 지역 조감 외곽의 배경 끝, 수면의 단순한 끝단, 원뿔 숲과 단순 건물 같은 대체 형상은 상세 제작 전 한계다.
- 실제 AI·전투·보상·저장·지형 완주와 가마 물리·게임 런타임 성능은 이번 지형 보완에서 미검증이다.
- 리뷰의7개 레이어·36개 경로선·4개 귀환 경로 선택 데이터·로컬 링크·SVG XML·JavaScript 문법과12장1920×1080 크기는 정적 검사에서 통과했다. 최종 지도 PNG의 한글 라벨·불규칙한 외곽·추가 귀환길도 확인했다. 브라우저 도구의 로컬 파일 URL 정책 때문에 실제 드래그·레이어·버튼 상호작용 검수는 미검증이다.
- Unity 검토 카메라: Play Mode에서1자유 비행,2지면 눈높이,3선택 경로 이동, [ / ]경로 선택, 오른쪽 마우스 드래그 시선 회전, WASD 이동. 이것은 실제 플레이 모드나 가마 기능이 아니다.
