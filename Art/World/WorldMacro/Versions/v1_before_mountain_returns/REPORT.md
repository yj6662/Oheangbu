# 5강토 전체 지리·3D 지형 초안 검토

2026-09-11 · State: TEST · 결정 #205 · **전체 지형 검토본 / 기하47항목·검토 카메라2구간 통과 / 스크린샷12장**

전체 산계·수계·분지를 먼저 만들고 정착지와 길을 연결한 독립 지형 초안이다. 최종 지형 검사47항목과 짧은 검토 카메라 이동2구간을 통과했다. 아래에서 초기 실패와 수정 후 결과를 구분하며, 실제 가마·전체 도보 완주·최종 미술 검증까지 완료했다고 해석하지 않는다.

## 결과와 이번 범위

- 약8×12km는 데이터 할당 범위다. 불규칙한 저작 외곽의 실제 평면 면적은 초기 측정 **75.14km²**이며, 이 면적 전체를 플레이 콘텐츠로 채운다는 의미가 아니다.
- 황경 분지, 동쪽 청림 계곡·산림, 남쪽 적로 구릉, 서쪽 철옹 고개, 북쪽 현강 옛 도읍의 지리적 관계를 별도 `W_WorldMacro_Blockout` 씬에서 검토한다.
- `WorldMacroSheetSO`가 외곽·능선·분지·수계·강토·거점·가도·도보망을 소유한다. Unity의 같은 저작 자료와 높이 표본으로 지도와 단면을 생성했다.
- 도시·숲·광산·주막·교량은 입지와 크기를 읽기 위한 대체 형상이다. 실제 가마, 전투·NPC·보상, 상세 도시, 월드 스트리밍을 새로 구현한 단계가 아니다.
- 영상은 제작하지 않는다. 조감도와 플레이 눈높이의 **1920×1080 정지 이미지**만 사용한다. 눈높이 검토 카메라는 실제 플레이 입력·캐릭터 충돌 검증과 구분한다.

## 지리 참고와 게임적 각색

한양의 산세에 따른 도성 입지와 개성의 산지 분지·옛 도읍 관계를 참고했다. 자료의 실제 지형 관계를 바탕으로 가도·도하점·도시의 자리를 게임에 맞게 각색했으며, 실제 지형 측량이나 DEM을 그대로 복제한 모델은 아니다.

- 참고 자료: [국가유산포털 한양도성](https://www.heritage.go.kr/heri/html/HtmlPage.do?pageNo=5_1_1_0&pg=%2Funesco%2FHeritage%2FHeritage_99_12.jsp), [UNESCO 개성역사유적지구](https://whc.unesco.org/en/list/1278).
- 구체적인 경계·방위·수계·도시 위치와 고도는 게임용 TEST 저작이다. 바이블의 공간 규약은 방향을 제시하는 지침이며, 시간·수량·좌표를 맞추려고 지형을 변형하지 않는다.
- 청림 탐험→청룡→국 재방문→상경 가도→황경 남문이라는 큰 흐름은 예약이다. 물리적으로 길이 연결되었다는 사실이 이야기 진행이나 실제 통행 기능의 완성을 뜻하지 않는다.
- 기존 프롤로그의 짧은 산맥 우회·첫 주막120–180초·고정 좌표는 새 전체 지형의 제약으로 승계하지 않는다. 큰 산맥의 우회는 여러 장소를 잇는 긴 여정에서 다룬다.

## 지도와 이동 측정의 읽는 법

- [검토 페이지](REVIEW.html)는 지형 음영·수계·강토·가도/도보·거점·주능선 저작선을 켜고 끌 수 있다. 지형 음영은80m 간격의 Unity 높이 표본을 사용하며 실제 Unity 렌더 스크린샷은 아니다.
- [전체 지도 PNG](world_map.png)와 [SVG](world_map.svg)는 같은 좌표와 외곽을 사용한다. 지도 기호의 선 폭은 가독성을 위한 것이며 실제 가도·하천 폭과 다르다.
- [단면도](sections.svg)는 황경–청림, 황경–현강, 적로–철옹 사이의 직선 표본이다. 길을 따라 움직이는 단면이 아니며 수직축을 확대했다. 원자료는 [section_samples.json](section_samples.json)에 있다.
- 이동 시간은 실제 경로3D 길이에 가도14m/s, 도보4.5m/s를 적용한 일정 속도 환산이다. 가감속·회전·정차·지면 충돌을 포함하지 않으며 실제 자동가마 구현이나 주행 실측을 뜻하지 않는다.
- 최대/95% 경사는 인접 경로 표본의 고도 차, 최소 곡률 반경은 경로 표본의 기하로 계산한다. **최대/95% 경사는 교량 예약점 반경150m 표본을 제외한다.** 제외된 구간의 최대 경사는 `maxBridgeApproachGradeDeg`와 검토 페이지의 **교량 접근 최대** 열에 따로 표시한다. 따라서 일반 경사 값만 보고 전체 가도가 완만하다고 판단하지 않는다. 자세한 실제 수치는 [measurements.json](measurements.json)을 따른다.
- 최종 물길 교차 검사는 예약점에 가깝다는 사실만으로 통과시키지 않고 실제 `Bridge_Deck_TEST` 형상의 범위를 검사한다. 최종 검사에서 수중 누락 표본0을 확인했다. 교량으로의 실제 가마 진입·차량 회전은 미검증이다.

## 스크린샷과 시각 검토

최종 [captures.json](captures.json)은12장을 기록한다. 전체 조감1장·강토별 조감5장, 주막·황경 남문·청림 고개·현강 옛 도읍·교량·적로 평야의 눈높이6장이다. 실제 파일12개가 모두1920×1080이고, 그림 안에는 설명 라벨을 넣지 않았다. 위치와 구도는 검토 페이지와 manifest에서 확인한다.

메모리 사용률85% 이상에서는 신규 촬영을 시작하지 않는 제한을 유지했다. 재촬영을 포함한19개 촬영 응답에서 최고 시스템 커밋은**83.24%**였다. 이는 촬영 응답 시점의 기록이며 전체 작업 중 최고 메모리 값은 아니다. 영상은 요청대로 생성하지 않았다.

조감 촬영에서는 지형을 읽을 수 있도록 **매크로 씬의 재질 사본만 일시적으로 거리 씻김0.10**으로 낮추며, 지상 눈높이는 기본0.58을 사용한다. 촬영 후 설정은 복원한다. 두 시점의 농도 차이는 검토 카메라의 표시 보정이며 C2 원본이나 영구 룩 변경이 아니다.

초기 이미지에서 발견한 문제:

- 전체 조감은 지형이 화면에 작게 잡히고 원경 대기가 강하게 씻겨 산과 분지를 판단하기 어려웠다.
- 청림 고개 눈높이에서는 평탄한 대지의 끝이 급경사 벽으로 떨어져 인공적으로 읽히는 부분이 있었다.
- 저작 외곽만 잘라 표시한 조감은 땅이 떠 있는 조각처럼 보였다. 바깥 지형 연장을 같은 전역 높이로 구성하는 보완을 진행한다.
- 지도상 밀집 거점의 라벨 겹침과80m alpha 마스크의 흰 경계 톱니는 지도 생성기에서 수정했다. 거점과 지형의 실제 위치는 바꾸지 않았다.

최종 전체 조감은 화면 안에서 배경 연장까지 읽히도록 조정했고, 황경 남문·적로 평야 시점은 가까운 대체 형상이 카메라를 가리지 않도록 다시 촬영했다. 최종 청림 고개에서 열린 분지와 낮은 산세를 확인했다. 산맥이 지도를 둘러싼 테두리처럼 보이는지, 가도가 미세하게 반복 굴곡지는지, 지역 내부가 충분히 넓게 읽히는지는 사용자 검토 대상이다.

최종 지역 조감에서 남긴 초안의 한계는 청림 화면 우측의 배경 범위 끝, 현강 저밀도 산 메시의 면 경계, 적로·현강 수면 리본의 각진 끝단이다. 이음·수계의 수치 검사가 통과하더라도 이러한 표시 한계는 남아 있으며 미술적 완료로 간주하지 않는다. 숲과 건물의 단순한 대체 형상도 이번 전체 지형 검토 범위에 따른 것이다.

- 초기 `preservation.json`에서 C2, 기존 프롤로그, CodexWorld 설정, C2 NoBloom, 프롤로그 Post·Content, 공용 PlayerRig, SpellBook8파일이 모두 동일했다. 최초 기준은 `baseline.json`이다.

## Unity에서 직접 둘러보기

`W_WorldMacro_Blockout` 씬을 열고 Play Mode에서 검토 카메라를 사용한다. 기존 플레이어 게임 모드가 아니며 전투·저장·가마 물리에는 연결하지 않았다.

| 입력 | 검토 동작 |
|---|---|
| 1 | 자유 비행 |
| 2 | 지면 눈높이 도보 카메라,4.5m/s |
| 3 | 선택한 경로 자동 이동,가도14m/s·도보4.5m/s |
| [ / ] | 이전 / 다음 검토 경로 선택 |
| 오른쪽 마우스 누른 채 이동 | 시선 회전 |
| W / A / S / D | 자유 이동·도보 이동 |
| Q / E, 왼쪽 Shift | 자유 비행의 하강 / 상승, 속도 증가 |

Play Mode의 두 짧은 이동 시험이 전체 경로·모든 조작 키의 실제 입력 검증을 대신하지 않는다.
