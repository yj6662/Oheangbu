# 마법가마 — 조립·제한 주행 기록

2026-09-12 · TEST · **시제품 전달 · 사용자 외관·조작 검토 대기**.

몸체·지붕·바퀴를 각각 이미지 → Meshy 7 → Blender로 제작하고 매크로 씬에 차량 시제품을 연결했다. 세 원형의 생성과 FBX 왕복 검사를 마쳤으며, Unity에서는 약6.40초의 제한된 물리 주행을 확인했다. 전체 경로 주행이나 실제 키보드 조작의 완료를 뜻하지 않는다. 차체 기울기 진단을 포함한8항목을 확인했고 중복 연결부를 정리한 최종 Unity 조립은35,489tris·4재질이다. 최신 외관·탑승1920×1080 정지 이미지2장을 제공한다. 영상은 제작하지 않는다.

## 생성 원형과 Blender 결과

built-in imagegen을 사용했으며 [PROMPTS.md](Concepts/PROMPTS.md)는 실제 도구 원문과 구분한 **제작 조건 요약**이다.

| 파츠 | 생성 모델 | Meshy 요청 폴리곤 수 | 생성 GLB 실제 tris | Blender 감면 상한 | 최종 FBX 실제 tris | 배치 수 | 실제 소비 |
|---|---|---:|---:|---:|---:|---:|---:|
| Cabin | meshy-7 | 18,000 | 15,462 | 18,000 | 15,462 | 1 | 30 |
| Roof | meshy-7 | 8,000 | 8,025 | 8,000 | 7,935 | 1 | 30 |
| Wheel | meshy-7 | 5,000 | 5,155 | 3,000 | 2,975 | 4 | 30 |

세 요청은 모두 `SUCCEEDED`, 실제 소비는 **90크레딧**이다. 90은 제작자가 정한 이번 실행의 내부 상한이며 사용자 지정 예산이나 과거 캐릭터 예산이 아니다. 파츠마다 한 번 생성했고 유료 재시도·추가 생성은 하지 않았다. [Meshy 원장](Meshy/ledger.json)에 요청 ID·입력 해시·실제 비용을 보존했다.

생성 원본에서 Roof와 Wheel은 요청 수를 초과했다. Blender 수정 후 FBX는 각각7,935·2,975tris다. 바퀴4개를 포함한 **FBX 조립 합계는35,297tris·재질3개**다. 차축2개·지지대4개(192tris·재질1개)를 추가한 **최종 Unity 배치는35,489tris·재질4개**다. Prefab override의 연결부 중복을 정리한 뒤2026-09-11T19:54:13Z 설치 원장에서 재확인했다. 이 세 원형에는 별도 LOD를 제작하지 않았다.

원본 GLB·UV·생성 텍스처를 보존하고 Unity +Z 전방·+Y 위, 바퀴 X축 중심으로 정리했다. 바퀴 지름은 약1.2m, 실제 두께는0.26m다. 이미지 제작 조건의0.18m와 실제 제작값을 구분한다. 지붕은2.3×3.4m, 캐빈은약1.655×1.550×3.0m다. 원형 보존·유효 정점·UV·재질·축·크기는 [Blender 전달 기록](Blender/DELIVERY.md)과 각 파츠 JSON의 빈 장면 FBX 재임포트 결과를 따른다.

현재 Unity 재질은 diffuse·normal을 사용한다. packed MR 파일은 보존했지만 `WorldMacroTexturedSurface`에서 사용하지 않는다. 파일 보존을 PBR 전체 적용으로 보고하지 않는다.

## 사용자 조작

`W_WorldMacro_Blockout` Play에서 가마 옆 캡슐로 시작한다. 입력 연결은 코드에 있으며 실제 키 입력의 조작감은 사용자 검토 대상이다.

| 조작 | 기능 |
|---|---|
| 2 / 8 | 캡슐 보행 / 가마 검토 지점 이동 |
| E | 가까이 정차한 가마에 탑승, 정차 후 안전한 위치로 하차 |
| W / S · A / D | 전후 구동 · 조향 |
| Space | 제동 |
| V | 탑승 시점 전환 |
| 마우스 오른쪽 버튼 누르기 | 시선 회전 |

검토 단축키8은 게임 내 빠른 이동 규칙이 아니다.

주요 건축물은 [별도 검토 페이지](../Landmarks/REVIEW.html)에 있다. 궁궐·요새·사찰은 기존 조선 건축 파생 모델의 외관·진입 첫 배치이며 상세 실내·보스·전투 콘텐츠가 없다. 동굴은 지면을 변경하지 않고 만든 입구·약30m 공간의 블록아웃이며 자연 암반 미술 완성본이 아니다. 기존 경로에서 배치 범위까지 약721.63m 떨어져 연결 동선도 미완료다.

실제 크기 보행 캡슐은 높이1.75m·지름0.56m·눈높이1.62m이며 Edit 상태에서 가마 Entry에 저장했다. 보행 검수는 사용자가 진행한다. 기존 매크로 룩·지리, C2·공용 PlayerRig를 보존한다. 수면은 사용자 판단에 따라 추가 수정을 보류했다. 건축물 첫 배치 이후 차량 시제품을 진행한 순서이며 완성 콘텐츠로 등록한 단계가 아니다.

촬영은 한 장씩 진행하고 시스템 커밋85% 이상에서는 새 촬영을 중단한다. 최종 차량 촬영의 커밋 사용률은 약69%였다. Unity를 저장 후 일시 종료해 Blender를 실행했고 Unity 재시작을 완료했다. 한시 API worker0 설정은 복원했으며, 현재 프로젝트 로컬 임포트 동시성은1·대기0·유휴 종료10,000ms다(이전3·2·60,000ms). 근거: [임포트 설정](editor_import_settings.json)·[모델 작업 중 Unity 일시 종료](../editor_model_pause.json). 영상은 없다.
