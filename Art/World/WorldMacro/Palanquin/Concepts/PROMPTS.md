# 마법가마 파츠 이미지 — 제작 조건 요약

2026-09-12 · 도구: **built-in imagegen**.

이 문서는 이미지 생성에 사용한 **제작 조건의 요약**이며, 실제 도구에 전달한 전체 프롬프트의 원문이 아니다. 전체 호출 프롬프트와 도구 반환 원본 경로는 이 요약 작성자의 문맥에 없어 전사하지 않았다. 필요하면 실행 담당자가 원문을 별도로 보충한다.

사용자 제공 데스크톱의 **‘마차’ 참조**를 출발점으로, 오행부의 낮은 채도와 조선식 목조·금속 장식을 해석했다. 참조의 정확한 파일명·확장자는 이 기록에서 확정하지 않는다. 아래 세 PNG는 생성 결과를 프로젝트에 복사해 보존한 파일이며 Meshy 입력으로 사용했다.

위 치수·바퀴살 수·착석 공간은 **이미지 제작 의도**다. 생성 이미지나 Meshy 생성 성공만으로 실제3D 치수·부품 분리·강체 회전·착석·충돌·주행 조건이 통과했다고 보지 않는다. Blender 수정과 Unity 결과를 따로 검수한다.

Meshy 입력 파일 해시·모델명·작업 ID·실제 비용은 [생성 원장](../Meshy/ledger.json)을 따른다. `meshy-7` 세 파츠의 생성은 완료되었고 실제 소비는 **30+30+30=90크레딧**이다. 90은 제작자가 정한 이번 실행의 내부 상한이며 사용자 지정 예산이 아니다. 유료 재시도·추가 생성은 하지 않는다.
