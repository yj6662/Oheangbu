# 주요 건축물 외관·배치 초안

2026-09-12 · TEST · 궁궐·요새·동굴·사찰 4개 설치. 궁궐·요새·사찰은 기존 조선 건축 파생 모델의 외관·진입 첫 배치이고, 동굴은 입구·짧은 공간의 블록아웃이다. 상세 실내·도시 전체·보스 AI·전투·보상·진행 게이트는 구현 범위가 아니다. 실제 보행은 사용자가 직접 검수한다.

## 이번 배치

- **궁궐:** Bongsudang 파생 모델, 양쪽 부속채, 담장·열린 문·마당.
- **요새:** 성벽·열린 성문·모서리 감시대·지휘 건물. 성벽 위 동선과 공성 콘텐츠는 후속.
- **동굴:** 지면을 변경하지 않고 입구와 약30m 공간의 블록아웃을 설치했다. 기존 지형 위에 바닥·접근부를 맞추며 뒤쪽은 막혀 있다. 자연 바위 형상이 완성된 건축 미술이나 완성 던전이 아니다.
- **사찰:** Byeolchu 파생 모델을 활용한 마당·낮은 담장·문·삼층 석탑의 각색. 상세 법당과 서사 기능은 후속.

원본 폴더는 `HwaseongHaenggung`, `HwaseongForteressGate`, `BillemotdonggulLavaTubePack`이다. 공급자 원본을 보존한 파생 모델·재질과 단순 충돌체를 사용한다. 기존 매크로 지형·룩, C2·공용 PlayerRig와 수면을 함께 재제작하지 않는다.

## 사용자 보행

Unity `W_WorldMacro_Blockout` 씬의 Play에서 확인한다. 캡슐 높이 **1.75m**, 지름 **0.56m**, 발 기준 눈높이 **1.62m**다.

| 조작 | 기능 |
|---|---|
| WASD / 마우스 오른쪽 버튼 누르기 | 이동 / 시선 회전 |
| 1 / 2 / 3 | 자유 카메라 / 캡슐 보행 / 경로 관찰 카메라 |
| 4 / 5 / 6 / 7 | 궁궐 / 요새 / 동굴 / 사찰 입구로 검토 위치 이동 |

위 단축키는 제작 검토용이며 새로운 게임 내 빠른 이동 기능이 아니다. 에이전트의 전 구간 보행·자동 주행 검사는 수행하지 않았다. 이전 높이2m·지름1m 공용 캡슐의 매크로 검사 결과를 새 캡슐의 통행 합격으로 승계하지 않는다.

추가 출입 공간의 정적 검사 기록은 [clearance_audit.json](clearance_audit.json)에서 확인한다. 설치 갱신보다 오래된 기록은 현재 배치의 통과 판정으로 재사용하지 않으며, 페이지에 이전 기록임을 표시한다. 정적 표본 검사만으로 실제 사용자 통행을 통과 처리하지 않는다.

최근 설치 원장의 `riverClearance`는 저작 하천 폭과 배치 범위의 반지름을 제외한 여유 거리다. `terrainRelief`는 배치 영역25개 지면 표본의 고도차, `caveRampMaxGrade`는 동굴 접근 중심선의 최대 경사다. 새 필드가 없는 예전 원장의 기복0은 측정된 평탄도로 간주하지 않는다.

이는 실제 수면 가장자리의 전수 접촉·보행 검사가 아니다. 동굴·사찰의 배치·재질을 조정한 최신 값이며, 이후 갱신은 각 setup JSON을 따른다. 동굴은 기존 경로의 배치 반지름 바깥 여유가 약721.63m로 기록되어 있다. 입구 단축키를 이용한 외관·주변 보행 검토 단계이며 기존 길에서 이어지는 연결 동선을 완성·검수한 것으로 보고하지 않는다.

## 시각 자료와 다음 순서

[REVIEW.html](REVIEW.html)은 4개 건축물의 `_eye`·`_aerial` PNG 8장을 표시한다. 각 이미지는1920×1080이며 설명은 이미지 밖에 둔다. 촬영 위치·눈높이·조감 프레이밍 범위·메모리 상태는 같은 이름의 JSON을 따른다. 촬영이 없거나 현재 배치 위치·Renderer 수와 맞지 않는 이전 파일은 페이지에서 대기로 표시하며, 파일이 존재한다는 이유만으로 미술 품질을 통과했다고 보지 않는다. 영상은 제작하지 않는다.

촬영·모델 작업은 순차 진행하며 시스템 커밋85% 이상에서 신규 촬영을 중단한다. Unity 저장 후 일시 종료해 Blender를 실행했고 재시작을 완료했다. 한시 API worker0 설정은 복원했으며, 현재 프로젝트 로컬 임포트 동시성1·대기0·유휴 종료10,000ms를 사용한다. [현재 설정 기록](../Palanquin/editor_import_settings.json)을 따른다.

수면은 자연스러움에 대한 사용자 판단에 따라 **현 상태 보존·추가 수정 보류**다. 주요 건축물 이후 [마법가마 제작](../Palanquin/REVIEW.html)을 파츠별 이미지 → Meshy → Blender → Unity 시제품 순서로 진행한다. 차량 생성·Blender 조립과 제한된 API 주행 기록은 해당 페이지를 따른다. 차량 최종 연결부·촬영 갱신을 완료했으나, 전체 경로 주행이나 실제 키보드 조작의 완료를 뜻하지 않는다.
