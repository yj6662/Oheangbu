# 5강토 환경·차량 최종 전달 상태

5강토 환경 비교 이미지 24종과 마석 자동차 이미지 6종을 확보했다. 환경은 배치·출처 보존 검사와 한 지점의 성능 기록까지 제공하며, 전체 맵 120fps 달성이나 실제 보행·차량 완주를 확정하지 않는다.

## 검토 자료

- [5강토 환경 전후 비교](REVIEW.html): 5지역 조감·지상과 경계 2지점, 총 12쌍·24장. 모두 1920×1080이며 접지 보정 이후 촬영했다.
- [촬영 계획](capture_plan.json), [저작·원본 보존 기록](authoring_audit.json), [선택 LOD 접지 보정 기록](grounding_geometry.json). 접지 보정은 캐시 메시의 밑면·접지 표본에 대한 기록이며 월드 전 구간 접촉 검사를 대신하지 않는다.
- [마석 자동차 검토](../MagicStoneCar/REVIEW.html): 정적 구도 5장과 실제 토크에 의한 출발 문양 진단 1장. 임시 정지벽 API 진단과 일반 자유 주행을 구분한다.
- 환경 배치 데이터: 1,225셀, 원형 설정 48개, 군락 11개, 확정 생활 소품 112개. 모델·텍스처는 기존 공급자 에셋의 별도 사본을 사용한다. 퀘스트·보상은 연결하지 않았다.

조감은 전후 모두 촬영용 담채 .10과 원경 식생 확장을 사용하고 끝난 뒤 런타임 설정을 복원했다. 지상 비교는 카메라 구도이며 실제 캡슐 이동 검사로 표시하지 않는다.

## 최종 동일 구도 성능 기록

최종 카메라 기준은 위치 약 (1988.0876, 134.7153, 711.3671), yaw 181.68°, 화각 60°다. 세 파일의 위치 차이는 최대 0.000107m, 피치 차이는 0.000481°로 허용 0.02m·0.05° 이내다. 각 120프레임, Unity Editor Play의 1080p 오프스크린 타깃에서 정지 상태로 측정했다.

[비교 기준·원본 해시·측정치 JSON](performance_summary.json). 새 환경의 정지 캐시와 강제 재생성 기록 모두 이번 표본의 CPU·프레임 P95가 120fps 예산 약 8.33ms 이내다. 강제 재생성 프레임 P95는 8.2924ms로 여유가 작으며, 최고 프레임 시간은 수집하지 않았다. **한 지점의 P95 결과이며 모든 프레임·전체 맵 120fps 보장이 아니다.**

`entry_before`·`entry_after`는 이전 탐색 구도인 위치 (1985.6913,134.7152,708.7893), yaw 105.3875°에서 측정했다. 최종 세 기록과 직접 비교해 9.8187→4.3570ms의 개선율을 계산하지 않는다. 원본 파일은 보존한다.

## 해석의 한계

- 최종 세 기록의 활성 환경 충돌체는 모두 0개다. 나무·바위 충돌체가 다수 활성화되는 상황의 비용은 이번 측정에 포함되지 않았다.
- 강제 재생성은 정지 카메라에서 드로우 패킷만 다시 만든 조건이다. 이동, 신규 셀 생성, 순간 이동, 다른 지역의 최대 밀도 또는 완주 부하를 대신하지 않는다.
- 8,069 드로우 인스턴스는 메시 파트·LOD 제출 기준이다. 고유 식물 개체 수가 아니다. 83,323 상주 기록도 한 화면에 그린 개체 수와 다르다.
- 전체 Unity 할당 메모리와 프레임당 GC 할당은 구분한다. 프레임당 GC는 별도 수집하지 않았다.
- 실제 키 입력·장거리 차량 주행·교량/경사·승차감·최종 밀도·색상·한국적인 인상은 사용자 검토 또는 후속 검증 대상이다.

## 차량 확정 수치

차량 실제 설치는 LOD0/1/2 **39,825 / 21,485 / 11,036 tris**, 재질 9개, Meshy 4파트 실제 소비 120크레딧이다. [카메라 14개 API 검사](../MagicStoneCar/camera_checks.json), [구동 상태 9개 검사](../MagicStoneCar/drive_state_checks.json), [짧은 물리 9개 검사](../MagicStoneCar/physics_probe.json)는 각각 범위를 명시했다. 운전석 기본 피치 12° 유지도 실제 API 검사에 포함한다. 세부 범위·편집 파일·원본 보존은 [차량 보고서](../MagicStoneCar/REPORT.md)에 있다.

물 표현 작업은 보류했다. 보행 기준 캡슐은 높이 1.75m·지름 0.56m·눈높이 1.62m이며 자동 보행 완주와 영상은 제작하지 않았다.
