# 빌드 후 편집기 복구 기록

첫 후보는 생성됐지만 과거 씬을 열던 전처리 예외1건과 시작 시 NavMesh 초기화 순서 문제를 발견했다. 첫 후보를 보존하고 해당 문제를 수정했다.

수정 후 편집기 새로고침/자원 해제가 지연됐으며 시스템 커밋88.6%로 재빌드가 거부됐다. 저장한 씬과 로그를 확인한 뒤 응답 없는 Unity 프로세스14116만 종료하고 재시작했다. 다른 앱은 종료하지 않았다. 복구 사본은 Assets/_Recovery에 남았으며 빌드는 저장된 W_WorldMacro_Playtest 씬으로 실행했다.

최종 후보20260913T154956Z: 시작 커밋56.5%, 빌드 오류0. 적3체가 NavMeshSurface 활성화 뒤 연결되며 숨김 실행/저장/재시작 검사와 세 순찰 경로가 통과했다. 숨김 창은 렌더링이 생략될 수 있으므로 루프 타이밍은 게임FPS로 해석하지 않는다.
