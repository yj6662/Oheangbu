산 안의 폐광,
처음의 금표 주막

일정한 팔각 통로를 산속의 넓고 불규칙한 동굴로 바꾸고, 주막에는 초기 C2 테스트 씬의 ㄱ자 초가 원형을 다시 적용했습니다.

환경 아트 · 구조 검사 결과
최종 Unity 환경의 1920×1080 정지 화면입니다. 연속 흙 접근면 적용 후 게임 연결 구조 검사 18개와 주막 계단 지지 표본 23개가 통과했습니다. 자연스러운 룩은 사용자 검토로 판단하며, 실제 입력 완주·AI 전투·사용자 저장 재실행·이동 성능은 미검증입니다.
산속 입구넓은 실내산과의 관계주막검사·자료

길이 산을 만나고, 산 안에서 넓어지는 폐광

옛 동굴 축의 앞쪽은 골짜기였습니다. 통로를 실제 산이 높아지는 쪽으로 꺾고, 산 밖에 노출된 앞부분은 야외 접근로로 정리했습니다. 입구 이후에는 넓은 방과 좁아지는 목이 번갈아 이어집니다.

전후 사진은 해당 상태를 대표하는 구도입니다. 카메라 위치가 같은 정밀 비교로 취급하지 않습니다. 새 화면은 환경 확인용 Editor 캡처이며, 캐릭터 스킨은 촬영 동안만 제외합니다.

팔각형 반복 대신 넓고 굴곡진 방

큰 시작 방에서 폭파 흔적을 조사하고, 좁아지는 연결부를 지나 중간 방에서 첫 근접 적을 만나도록 기존 콘텐츠 위치를 함께 옮겼습니다. 등불과 작업 흔적은 필요한 곳에 모으고, 광맥은 실제 벽 표면에 놓았습니다.

콘텐츠와 데이터 연결

  • 조사·석경·적·주막의 기존 ID와 외부 주경로의 나머지 좌표를 유지했습니다.
  • 절삭된 실내 바닥 경계로 지하 지도를 갱신했습니다. 깊은 방의 내부 분류, 노출 접근부와 산 위의 외부 분류 검사가 통과했습니다.
  • 기존 저장 슬롯은 유지하며 지형 버전만 갱신했습니다. 이전 위치의 안전 보정 경로를 연결했고, 실제 사용자 저장 재실행은 미검증입니다.

동굴을 별도 건물처럼 올리지 않고

산 전체를 재생성하지 않고 입구 주변만 바꿨습니다. 기존 산의 높이장에서 동굴의 빈 공간을 빼 하나의 연속 표면을 만들었습니다. 기존 산세가 방의 지붕을 덮고, 바깥 지표면이 동굴 벽으로 이어집니다.

앞마당은 중심 통행면을 따라 놓고 측면 4~12m 구간을 실제 지형 바닥과 혼합했습니다. 메시를 중심선 12m 이내의 지면 확인 구간으로 잘라, 솟은 좁은 띠와 넓은 사각 받침면을 대체했습니다. 최종 흙 접근면은 3,200 tris이며 같은 메시로 렌더링·충돌을 처리합니다.

최종 화면에서 떠 보였던 입구 장식 바위 9개는 원본을 보존하고 활성 배치에서 제외했습니다. 경계 상자의 지면 검사만으로 접지를 통과했다고 판단하지 않았으며, 원래의 연속 암벽이 읽히도록 정리했습니다. 배우·이동·지도는 변경하지 않았습니다. 조치 원장

Blender 편집 원본은 최초 약 175m 설계를 보존합니다. 최종 Unity에서 앞쪽 외피를 잘라 남긴 약 123m 범위와 삼각형 수가 서로 다릅니다.

초기 테스트 씬의 주막으로

원래 C2의 ThatchedInn 전체 프리팹을 다시 사용했습니다. ㄱ자 초가, 돌 계단, 목재와 낮은 채도의 재질, 처마 등롱을 유지하고 앞마당은 흙 바닥으로 정리했습니다.

확인한 것과 남은 것

구조 검사와 실제 플레이를 구분합니다. 최종 스크린샷의 자연스러운 공간감과 룩은 사용자 검토로 판단합니다.

외부 산비탈과 암벽 사이의 거친 재질 경계, 원거리 식생의 접지는 사용자 검토 후 추가 정리가 필요합니다. 이번 결과를 최종 미술 합격으로 처리하지 않았습니다.
