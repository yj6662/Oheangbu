# 폐광·초기 주막 개선 — 제작·검사 보고서

작성: 2026-09-15. 팔각형의 일정한 폐광을 산속의 넓고 불규칙한 동굴로 교체하고, 금표 주막에는 초기 C2 테스트 씬의 ㄱ자 초가를 복원했다. 최종 접근 지면을 적용한 뒤 게임 연결의 구조 검사 18개와 주막 계단 지지 표본 23개가 통과했다. 아래에서 초기 제작 수치와 최종 Unity 적용 수치, Editor 검사와 실제 플레이를 구분한다.

## 제작 방향과 현재 적용

팔각형의 일정한 통로를 없애고, 낮은 접근부에서 산 안쪽의 큰 방으로 이어지는 굴곡진 동굴을 만들었다. 기존 지형을 조사한 결과, 옛 통로의 정면은 산을 파고드는 방향이 아니라 골짜기를 따라가는 방향이었다. 이에 안쪽 경로를 기존 동굴 좌표의 -X, 실제 산이 높아지는 쪽으로 꺾었다.

초기 동굴 원본의 X 범위는 약 175m였다. 이후 산 밖에 드러난 앞부분을 제거하고 입구를 local X=-43의 산비탈로 옮겼다. **현재 실내 외피는 X 약 -166.4~-43, 약 123m 범위**이며, 앞부분은 야외 접근로로 전환했다. 이는 축 방향 범위이지 실제 보행 거리 실측은 아니다. 편집용 Blender 원본은 초기 전체 설계를 보존하므로 최종 Unity의 입구 위치·삼각형 수와 같다고 취급하면 안 된다.

안쪽에는 넓은 시작 방과 중간 방, 그 사이 좁아지는 목을 두었다. 초기 오프라인 단면 표본에서 큰 방의 폭은 약 34.7~36.7m, 지붕 높이는 약 16.2~16.7m였고, 가운데 목은 폭 약 18.5m·높이 약 9.9m였다. 이 수치는 생성 원본의 표본이다. 최종 Unity의 시작점·조사점·중간 방·입구 표본에서는 머리 위 여유가 각각 약 14.96m·13.97m·13.83m·11.63m였다. local X=-43은 주 실내 바닥과 실내 지도의 경계이며, 그 바깥 앞마당도 일부는 암석 돌출부가 위를 덮는다. 야외 분류를 천장이 전혀 없는 공간이라는 뜻으로 사용하지 않는다.

벽·천장은 불규칙한 구조 메시로 연결하고, 보유 암석 표면·작업 목재·바구니·등불을 재사용했다. 광맥은 실제 동굴 벽 접점에 배치했다. 기존 정기적인 지지대 배열은 보존용으로 비활성화하고 작업 흔적을 국부적으로 구성했다. 폭파 흔적의 원인을 플레이어에게 확정해서 설명하지 않는다.

최종 화면에서 입구 쪽 장식 바위가 떠 보이는 문제가 남아, local X>-60에 중심이 있는 장식 바위 9개를 활성 배치에서 제외했다. 바위 경계 상자의 지면 깊이는 통과했지만 화면에서 자연스럽게 접지된다는 증거가 되지 않았으므로, 이를 접지 통과로 보고하지 않는다. 원본 `Mine_Detail_0.asset`을 보존하고 `Mine_InteriorDetails_PortalCleared.asset` 파생본을 렌더링·충돌에 함께 연결했다. 해당 배치는 60,360→51,306 tris로 9,054 tris 줄었고, 입구의 연속 암벽과 내부 작업 소품은 유지했다. 배우·Motor·지도는 이 조치로 변경하지 않았다.

전역 지형 재생성은 실행하지 않았다. 입구는 기존 지형의 높이장에서 동굴의 빈 공간을 뺀 하나의 연속 표면으로 다시 만들었다. `Tools/Art/build_cave_portal.py`의 1m 간격 체적 생성과 `NaturalCaveSolidPortal.cs`의 통합을 사용한다. 산에 암석 띠를 덧대던 중간 패치는 비활성화했으며, 바깥에 사각 측벽을 추가하지 않았다.

새 국부 지형 범위는 동굴 local X[-96,-8], Z[-42,48]이다. 범위 밖의 `Terrain_052`, `Terrain_060`은 원본 지리를 유지한다. 공급자 원본과 기존 지형 에셋도 보존했다. 입구 생성 원본은 163,028 tris였고, 실제로 떨어져 있는 것으로 확인한 암석 조각 24 tris를 제거해 최종 암석·지표면은 163,004 tris이다. 새 폐광 루트 전체는 실내·입구·소품·등불·연속 흙 접근면을 포함해 21개 렌더러·318,673 tris이다.

접근부에는 하나의 연속 흙 표면을 만들었다. 중심 통행면은 완만하게 잇고, 중심선에서 4~12m인 측면 구간을 절삭된 지형 바닥과 혼합한다. 최종 메시 범위는 중심선에서 12m 이내이며 실제 아래 지면을 확인한 부분으로 잘랐다. 원래 사용했던 좁고 솟은 띠, 넓은 앞마당 면, 바깥 받침면은 비활성 보관했다. 새 표면은 렌더링과 충돌에 같은 메시를 사용하며, 기존 외부 경로 꼬리는 원래 좌표로 복원했다. 이는 모든 자연 지면을 그대로 따라가는 방식이 아니라, 중심 통행면과 주변의 자연 지면을 부드럽게 연결하는 방식이다.

## 주막

초기 `C2_CodexWorld` 테스트 씬의 `ThatchedInn.prefab`을 찾아 전체 형태를 다시 사용했다. 원형은 `House_1/house.fbx` 기반의 ㄱ자 초가이며, 현재의 긴 직사각형 벽 조합을 대체한다. 원본 11개 재질 그룹, 돌 계단과 처마 등롱을 유지했다. 이전 `House_2` 주막과 합쳐진 렌더링 배치·충돌체는 비활성 보관했다.

지형과 만나는 바닥을 낮추고, 넓은 목재 앞마당을 흙 마당으로 바꾸었다. 계단의 시각 형태는 유지하면서 이동을 위한 연속 경사 충돌을 별도로 구성했다. 경사 구간은 약 23.20도이며 끝에 길이 0.9m의 수평 참을 연결했다. `inn_final_validation.txt`의 18.64도는 수평 참을 포함한 전체 양 끝점의 평균 기울기이므로 실제 경사면 각도와 구분한다. 최종 계단·참의 캡슐 지지 23/23, 휴식·벌목꾼·약초꾼 접근 지지가 통과했다. 주막 휴식·체크포인트 ID와 대화·보상·휴식 규칙은 유지한다.

## 게임 연결과 저장

- 새 시작 위치는 깊은 방, 폭파 조사와 시작 석경은 그 곁으로 이동했다. 첫 근접 짐승은 중간 방으로 옮겼다. 바깥의 나머지 적과 기존 콘텐츠 ID는 유지한다.
- 지하 경로를 새 시작점에서 입구까지 연결하고 기존 외부 주경로의 나머지 좌표를 그대로 이어 붙였다. 최종 검사에서 외부 경로 일치가 통과했다.
- 기존 로컬 NavMesh만 더 넓은 범위로 다시 만들고 별도 `NaturalCave/Navigation.asset`에 저장했다. 최종 연속 접근면 적용 뒤 다시 베이크했다. 적은 기존 규칙대로 저장 시 NavMeshAgent가 비활성이고, Play 시작 시 로드된 NavMesh에 연결된다.
- 최종 절단된 동굴 바닥 경계로 내부 지도와 동선을 갱신했다. 깊은 시작점·조사점은 실내, 노출된 옛 앞 통로 local(-26,-1)와 산 위 지표면은 야외로 분류되는지 검사했다. 전체 지도 삽화·좌표 변환·탐험 저장은 유지한다.
- 저장 슬롯 `world-macro-playtest-v2`를 유지한다. 지형 버전만 `macro-natural-cave-20260915`로 변경했다. 기존 복원 코드가 이전 지형의 저장 위치를 등록된 폐광 또는 주막 체크포인트로 보정하며 통보·완료 ID·인벤토리·발견 기록을 유지한다. 지지가 없는 드롭은 안전한 체크포인트로 옮긴다. **실제 사용자 저장의 재실행 이행은 미검증**이다. 사용자 저장 파일을 삭제하거나 초기화하지 않았다.

최종 캡처는 환경을 보는 Editor 정지 화면이다. Play에서 갱신되는 캐릭터의 스키닝이 Editor 화면을 오염시키지 않도록 캡처 동안 캐릭터 SkinnedRenderer를 임시로 제외하고 원래 상태로 복원한다. 이를 캐릭터 외형이나 동작 검증으로 취급하지 않는다. NPC·적의 임시 외형도 실제 플레이 최종 아트 승인과 구분한다.

`runtime_smoke.txt`는 `_natural-cave-delivery-20260915` 시험 접미사를 쓴 독립 슬롯에서 최종 상태의 Play를 다시 시작한 결과다. 저장 상태 `new`, 오류 없음, 안전한 바닥 `true`를 확인했다. 실제 캡슐은 새 깊은 시작점에서 계획 위치보다 약 5cm 아래로 접지해 멈췄고, 적 3개 모두 활성화되어 NavMesh에 연결됐다. 플레이어 스킨 경계도 캐릭터 주변 크기를 유지했다. 검사를 마친 뒤 Play를 중단하고 시험 슬롯을 정리했다. 실제 사용자의 저장 슬롯을 이 시험으로 대체하지 않았다.

Play 중에는 Unity 정적 배치가 공유 메시를 합치므로 `runtime_smoke.txt`에 나오는 메시별 숫자를 삼각형 합계로 더하지 않는다. 아래 렌더 원장은 Edit 상태의 독립 메시를 기준으로 한다. 이 시작 검사는 실제 키보드 이동·전투·기존 사용자 저장 재실행·성능 측정을 포함하지 않는다.

외부 산비탈과 암벽이 만나는 재질 경계의 거친 부분, 원거리 식생의 접지는 사용자 검토 후 추가 정리가 필요하다. 이번 결과를 최종 미술 합격으로 처리하지 않는다.
