# 관청 시작과 오행부 차량 호출 — 2026-09-15

사용자의 최신 방향은 폐광에서 갑자기 시작하는 대신 주변 마을 관청에서 조사 의뢰를 받고 출발하는 것이다. 고정 주차 장소까지 돌아가는 불편을 피하기 위해 오행부 메뉴로 기존 마석 자동차 한 대를 부르는 기능을 연결한다.

- 새 게임: 마을 관청 앞 → 아전과 F 대화 → 오행부의 자동차 호출 → 금표 주막 쪽 큰길 → 동쪽 산길 → 폐광 폭파 흔적 조사.
- 기존 저장: 위치·체크포인트·완료·통보·드롭 보존. 관청으로 강제 이동하거나 의뢰를 다시 받도록 잠그지 않는다.
- 도로는 호출 위치를 고르는 조건이다. 큰길 밖 주행을 강제로 막거나 자동 하차시키는 규칙은 확정하지 않았고 구현하지 않았다.
- 차량은 기존 인스턴스를 이동한다. 주차한 곳에 복제본을 남기지 않으며 주행 프로필·좌석·바퀴를 재생성하지 않는다.
- 의뢰는 현장 조사 목적만 설명한다. 폭파 배후는 밝히지 않는다. 기록첩은 제거하며 대화·조사는 기존 완료 ID로만 유지한다.
- 관청 건물은 보유 SM_Naeposa의 소형 한옥을 관청 외관 시안으로 재사용한다. 집사청 원본 약 49만 삼각형 대신 약 9천 삼각형 소스를 선택했다. 마당과 실제 충돌을 덧붙였으며 기존 지형 전체는 재생성하지 않았다.
- 아전은 기존 NPC 대체 외형이다. 새로운 의상·얼굴·음성의 완성본이 아니다.
- 금빛 5소켓 오행부의 3D 메뉴 외형과 새로운 차량 소환 시각 연출은 다음 제작 범위다. 이번 기능은 현 메뉴에서의 호출 연결이다.
- 새 빌드·영상·자동 보행 완주를 만들지 않는다. 검사는 실제 연결 API 진단과 순차 정지 화면으로 구분한다.
