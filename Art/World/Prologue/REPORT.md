## 구현한 플레이 흐름

폐광의 임시 성황당에서 시작해 폭파 흔적을 F로 조사한다. 무속성 근접 공격과 화 속성 원거리 공격을 하는 임시 짐승 두 체가 서로 다른 위치에 있다. 기존 작도·락온·갈무리·회피 조작과 플레이어 캡슐을 사용한다. 특정 글자 성공이나 적 처치를 진행 잠금으로 삼지 않는다.

산자락을 돌아가는 주경로는 약 586.9m다. 4.5m/s 기준 순수 보행 계산은 약 130.4초다. 지선은 통보 24와 별도 폭파 물증을 포함하며 본선에 재합류한다. 절벽 위 옛 작업 발판은 국 획득 뒤 돌아올 장소의 예고다. 얕은 물길은 기존 PolyOne 물 재질의 별도 사본으로 만들었다. 등반·점프·수영 기능은 추가하지 않았다.

금표 주막에서 HP·먹 회복과 체크포인트 등록이 동작하고 벌목꾼·약초꾼의 짧은 대화를 읽을 수 있다. 정담·왕소는 후속 역참/객주 예약에 남겼다. 상점·강화 경제를 추가로 정하지 않았다.

저장은 별도 버전/슬롯, 원자적 파일 교체와 이전 파일 백업을 사용한다. 조사·일회 보상·체크포인트·보유 통보·미회수 드롭·HP·먹·안전 위치를 저장한다. 휴식은 일반 적을 되살리고 조사/보상을 유지한다. 사망은 보유 통보 전부를 남기며 재사망은 이전 드롭을 대체한다. 적과 NPC, 일부 조사 소품은 임시 외형이다.

## 미완료·미검증

- **전체 완주 영상 미확보.** 시스템 커밋 85% 제한으로 촬영을 중단했다. 첫 시도는 유효 프레임을 얻지 못했고 두 번째는 151프레임까지 기록했다. 완주 자체는 두 차례 입력 로그로 확인했지만 전체 영상으로 대체하지 않는다.
- **렌더 호출 CPU 표본 확보, 전체 성능 합격은 미검증.** `render_comparison.json`: C2 대표 시점의 동기식 Camera.Render CPU 평균 약 2.445ms/24표본. 새 씬의 첫 시도는 커밋 약 85.19%에서 중단했다. 메모리 정리 후 `render_prologue.json`에서 새 씬 약 1.872ms/24표본, 커밋 83.65%를 확보했다. 서로 다른 대표 구도의 에디터 렌더 호출이므로 GPU 프레임타임·빌드 FPS·성능 향상의 증거로 확대 해석하지 않는다. UnityStats 값은 에디터 전역 표본이며 카메라별 통계로 보장하지 않는다. 보행 로그의 프레임 간격도 성능 합격값으로 사용하지 않는다.
- 독립 실행 파일 빌드 및 **프로그램 자체 재실행**은 미검증. Play 종료/재진입과 디스크 재로드만 검사했다.
- 30·60·120fps 및 작도 감속의 전체 행렬, 모든 시작 어휘·패링·전투 승리/보상까지의 입력 검사는 미완료. 아/어 검사는 위의 일부 실패를 포함한다.
- 주막 계단 전체, 모든 경사/절벽 경계, 지선 두 번째 물증과 국 예고 지점의 개별 실제 입력 검수는 미검증.
- 출구에서 주막 일부를 먼저 보여준 뒤 가리는 구도, 주요 시점별 단서 우선순위, 얕은 물길 가독성은 추가 시각 검수가 필요하다. 새 산자락이 너무 강하게 시야를 가리는지 사용자의 검토가 필요하다.
- 황경까지의 다음 구간은 연결·방향·고도 관계를 TEST로 예약한 상태다. 미래 구역의 실제 지형/콘텐츠/구역 전환은 구현하지 않았다. AreaLoader 진입 POI 선택은 추가했으나 전체 구역 전환 실전 검사는 미검증이다.

## 수정 중 확인한 원인과 유지보수

기존 C2의 바위 배치를 새 지형 위에 그대로 쓰면 들뜸/길 막힘이 발생했다. 별도 씬의 바위 170개를 새 지형에 맞춰 접지하고 경로를 막는 8개 형상을 제외했다. 공급자 메시를 변경하지 않았다.

Mesh의 `CopySerialized` 갱신이 예전 렌더 버퍼를 유지해 물리 표면과 화면이 다르게 보이는 문제를 실제 비교에서 확인했다. 정점·인덱스·노멀을 명시적으로 다시 업로드하도록 수정했다. 길 표시·지형·콜라이더는 같은 경로/높이 자료를 사용한다.

일반 Build 명령은 제작 씬이 이미 있으면 거절한다. 후속 콘텐츠는 이 씬에서 개별 편집한다. 전체 재생성을 기본 작업 흐름으로 사용하지 않는다. `Refine` 역시 초기 제작용 도구이며 새 수작업 배치를 자동으로 재접지할 목적의 상시 명령이 아니다.

유료 생성 요청 0. 기존 술식/소환수 제작을 재개하지 않았다. 추가 상시 HUD는 없으며 접근 시 상호작용 안내와 짧은 대화만 표시한다.
