# C02 몸·동작·얼굴 후속 실험

최선의 통합 실험본은 **A2 몸 웨이트 + B2 동작 + C3 눈꺼풀**이다. 겨드랑이의 급격한 웨이트 경계, 일부 발 접지, Unity Humanoid에서 Idle이 떠오르는 문제를 개선했다. 좌우 눈을 덮는 두 채널 및 세 강도 프리셋도 구현했다. **게임용 캐릭터 전체 품질은 UNVERIFIED**다. 원본 C02·FitRigV3·C2·공용 PlayerRig를 교체하지 않았다. 이번 추가 유료 요청은 **0회, 0크레딧**이며 과거 AutoPlayerV1의 123크레딧과 별개다.

## 실제로 개선한 부분

**A — 몸/의복, 2/4회.** 왼쪽 겨드랑이 아래에서 Hips와 LeftArm 영향이 갑자기 바뀌는 경계를 확인했다. 첫 후보의 4개 웨이트 재투영은 다른 경계의 늘어남을 키워 폐기했다. 두 번째 후보는 연결된 작은 영역을 정리하고 다섯 번째 웨이트를 유지했다. 245개 위치/803개 렌더 정점을 수정했으며, 그중 722개가 최대 5개 영향을 갖는다. 기하·UV·원본 클립·기준 골격은 바꾸지 않았다.

동일한 원본 Walk·Run·Idle·Attack과 5개 진단의 **578개 정수 프레임**을 검사했다. 5mm 이상 기준 에지의 4배 늘어남 경고는 모든 동작에서 0개가 됐다. Run 최악값 4.079→3.934, Idle 4.406→3.949. Attack 최악값은 3.850→3.918로 조금 증가했으므로 모든 수치가 좋아졌다고 주장하지 않는다. 2배 경고 개수는 아홉 동작 모두 감소했고, 같은 카메라의 회색/원재질 확대에서 겨드랑이의 큰 꼬임 감소를 확인했다. 이 경고 기준은 품질 합격선이 아니다. 원본과 A2의 4종 비교 영상을 각각 252프레임으로 새로 렌더했다.

**B — 동작, 2/3회.** B1은 원본을 보존하고 복사한 4개 동작에 발 IK와 공격 후 중심 복귀를 적용했다. 선택한 신발 밑면 표본의 Idle 오른발 부유가 약 3.3–4.7cm에서 4.4–5.0mm로 줄었다. 같은 지지창에서 오른발 수평 이동 범위는 Idle 4.35→0.27cm, Walk 최댓값 1.76→0.88cm, Run 최댓값 0.74→0.19cm로 줄었다. 이는 선택 표본에 대한 결과이며 모든 옷·몸의 접촉 검사가 아니다.

원본/수정본을 같은 지면에서 보여주는 **331프레임, 30fps 비교 영상**에 Run 원속도 6주기와 Idle→Run→Idle→Attack→Idle 전환을 넣었다. Run의 발 이동에 맞는 속도는 약 5.36m/s, 실제 게임 설정은 4.5m/s다. 게임 이동 값을 변경하지 않았으며 실제 게임 속도와의 접지 일치는 미검증이다.

B1의 Unity Humanoid Idle에서 약 16cm 부유가 발견됐다. 원본 Idle만 Hips에 **1.1764704배 스케일**을 사용했고, Generic은 이를 재현했지만 Humanoid는 동일 자세를 재현하지 못했다. 루트 Y 가져오기 설정 변경도 해결하지 못했다. B2는 새 Idle에서 Hips scale을 1로 정상화하고 골반 애니메이션과 발 회전 IK를 다시 맞췄다. **캐릭터 루트와 바닥 높이는 유지했다.** Blender 121프레임의 최저점은 4.996mm 이상이며 Unity 직접 표본 Idle0는 160.730mm에서 **4.074mm**로 개선됐다. 실제 Play 상태와 그림자는 [Unity 보고서](Unity/UNITY_REPORT.md)에서 별도로 확인한다.

B2는 Idle과 연속 시퀀스를 추가하고 B1 Walk·Run·Attack을 사용한다. 앞의 B1 비교 영상은 이전 체크포인트이며 B2 최종 Unity 영상과 구분한다. 기존 원본과 B1 동작은 그대로 보존했다.

실제 Unity Play의 Idle 첫 두 프레임에서도 최저점 **4.074/4.094mm**, 루트·바닥 Y=0을 확인했다. 직접 표본과 일치하므로 16cm 부유가 Play에서 재발한 것은 아니다. 그림자가 떨어져 보이는 현상은 남아 있으며, 측정된 shadowBias 0.05/normalBias 0.4의 영향으로 추정하지만 별도 대조 실험은 하지 않았다.

**C — 얼굴 기초, 3/3회.** 원본 눈은 독립 안구가 아닌 통합 표면과 텍스처였다. C1의 오른 눈꺼풀은 앞머리를 피부로 샘플링해 34.27mm 늘어나는 오류가 있어 폐기했다. C2의 별도 안구는 과노출과 닫힘 실패로 폐기했다. C3는 실제 눈 주변 피부 연결 영역만 사용해 오른쪽 최대 이동을 7.53mm로 줄였다. 원래 얼굴/머리/몸은 유지하고, 눈꺼풀 두 메시를 기존 Head 본에 연결했다.

**D — 표정 범위, 1/3회.** 새 감정 채널 대신 기존 BlinkLeft/Right를 함께 35/65/100%로 제어하는 `GentleSquint`, `FocusedSquint`, `EyesClosed`를 남겼다. 272프레임의 기존 Idle·Run·Attack 위에서 단일 Head 스키닝 오차가 최대 0.000725mm였다. 눈썹·턱·입을 움직이는 감정 표현으로 보고하지 않는다.

## 실제 통계와 내보내기

| 대상 | 렌더 삼각형 | Blender 정점 | 새 본 |
|---|---:|---:|---:|
| 기존 몸/의복 | 51,760 | 87,148 | 0 |
| 좌우 눈꺼풀 합계 | 1,024 | 594 | 0 |
| 합계 | **52,784 / 상한 60,000** | 87,742 | **0** |

총 변형 본 24개, 렌더 메시 3개, 재질 2개, 얼굴 BlendShape 2개다. 두 재질은 동일한 기존 C02 원본 PNG를 사용한다. 내보내기 중 지연 로드 이미지가 이전 변환 파일을 잘못 읽는 경로 순서 오류를 재현하고, 원본 PNG 바이트를 공용화해 수정했다. 새 디자인이나 텍스처를 생성하지 않았다.

최종 FBX를 별도 빈 Blender 장면에 다시 임포트했다. 원본/보정 동작과 Blink 0/25/50/75/100/중립의 **31개 조건, 93개 메시 표본**에서 최대 최근접 정점 오차 0.001406mm, 같은 삼각형·24본·2키와 722개 5웨이트 정점 보존을 확인했다. 일대일 정점 대응을 가정하지 않는 최근접 비교이며, 미술·관통 합격 검사는 아니다.

Unity는 자체 Humanoid Avatar, **17개 30fps take**, 2개 얼굴 채널을 임포트했다. 원본 take에 FBX가 기록한 상수 얼굴 곡선이 있어 **실험용 복사 클립에서 해당 두 곡선만 제거**하고 별도 표정 제어기가 0–1 값을 Unity의 0–100으로 전달하도록 했다. 원본 take는 남아 있다.

Unity 6000.3.9f1은 `minBoneWeight=0` 요청을 0.001로 저장했다. 원본의 다섯 번째 웨이트가 0.001 이상인 정점은 정확히 297개로, Unity의 5웨이트 정점 개수와 일치한다. 나머지 425개의 작은 영향은 잘린다. 최대 5개 임포트와 임시 Unlimited 스키닝을 적용했으며 원본의 모든 작은 웨이트가 그대로 유지된다고 보고하지 않는다. 실제 B2의 16표본에서 FourBones와 Unlimited의 최대 차이는 **13.1344mm**다. B1 압축·OptimizeGameObjects 비교 분기는 최대 **17.3945mm**의 자세 차이가 있어 최선본에서는 둘 다 OFF로 유지했다. B2 최적화 전체 프레임이나 게임 성능 합격을 주장하지 않는다. 실험 종료 시 전역 품질 설정을 복구한다. 실제 재생·최종 임포트 확인 범위는 [Unity 보고서](Unity/UNITY_REPORT.md)에 기록한다.

손가락 본이 없어 손가락 굽힘·붓 접촉은 수행하지 않았다. 기존 무기 없는 Attack을 붓 파지 완료로 표시하지 않는다. 정본 교체를 막는 것은 남은 의복/지면 변형, 눈꺼풀 접촉, 실제 안구·입·손가락 구조 부족이다. 별도 보조 물리와 공용 PlayerRig 적용은 이번 결과에 포함되지 않는다.

모든 영상은 실제 렌더 프레임으로 인코딩했다. 규격/전체 디코딩 통과와 실제 모델 품질을 분리했다. 잘린 예비 영상과 모델이 화면 밖에 있던 초기 Unity 캡처는 실패 진단 자료로 분리했으며 최종 결과로 사용하지 않는다.
