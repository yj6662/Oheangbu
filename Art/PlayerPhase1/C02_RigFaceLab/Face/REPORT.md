# C02 얼굴 독립 실험

현재 전달 가능한 얼굴 구조는 **C3의 좌우 눈깜박임 두 채널과 D1의 해당 채널 프리셋 3종**이다. 기존 얼굴·눈의 그림은 보존하고 별도 피부 면이 눈을 덮도록 구현했다. 채널 전달·프리셋 제어·전신 동작 위 스키닝은 기술 PASS다. 실제 안구 회전·턱·입 움직임은 구현되지 않았다. 눈꺼풀 접촉 전체와 Unity의 왼쪽 눈 최대 닫힘 시각 확인은 미완료이므로 `face_blink` 전체 품질은 **UNVERIFIED**이며, 얼굴 미술 품질이나 통합 캐릭터를 PASS로 판정하지 않는다.

## 보존과 실제 비용

- 원본: `AutoPlayerV1/Candidates/C02/Candidate_C02_Repaired.blend`. 원본을 덮어쓰지 않았다.
- 기존 `C02_Mesh_0`의 87,148정점, 51,760삼각형 및 몸·의복·얼굴의 원본 정점과 웨이트를 보존했다. UV를 편집하지 않았다.
- C3 추가: `FaceLid_Left`, `FaceLid_Right` 각 297정점·512삼각형. **총 52,784삼각형, 24본, 3렌더 메시**. 새 본은 0개이며 양쪽 눈꺼풀은 기존 `Head`에 100% 연결된다.
- 사용 텍스처는 기존 C02의 `Material_1`에 연결된 베이스 컬러 한 장, `Textures/texture_0.png`(2048×2048)이다. 다른 UV의 고아 이미지나 다른 캐릭터의 텍스처를 혼용하지 않았다.
- 외부 유료 생성·리깅·모션 요청 **0회 / 추가 0크레딧**. 기본 얼굴 후보는 C1~C3, 3회 한도를 모두 사용했다.

## 구조 진단과 후보 결과

| 후보 | 실제 변경·관찰 | 판정 |
|---|---|---|

| C2 | 국부 안구 두 개와 시선 채널을 추가했으나 흰자가 과도하게 노출되고 눈을 감아도 남아 원래 인상이 달라졌다. | 눈깜박임·시선 FAIL, 미채택 |
| C3 | 랜드마크가 있는 실제 얼굴 피부 연결 영역 448삼각형으로 샘플을 제한. 왼쪽 최대 7.075mm, 오른쪽 7.530mm 이동. 중립·반쯤·닫힘과 정면·측면·3/4를 확인했다. | 제한된 눈 덮기 기능만 검수 대상 |

원본의 눈·눈썹·수염·입은 통합 메시와 텍스처에 연결되어 있다. 독립 안구와 확립된 입안 구조가 없다. C3의 시선은 원본의 고정된 눈 그림이며 실제 gaze 기능이 아니다. 턱·입술은 `NOT_ATTEMPTED`: 닫힌 입 구조를 확인했지만 이번 3회 후보를 눈깜박임·안구 시험에 사용했다. 국부 입 구조 복원이 원천적으로 불가능하다는 뜻은 아니다.

D1의 프리셋은 `GentleSquint`(좌우 0.35), `FocusedSquint`(좌우 0.65), `EyesClosed`(좌우 1)다. 눈썹·입술·시선·턱을 움직이는 집중·미소·통증 표현으로 이름을 바꾸어 보고하지 않는다. 프리셋 3장과 연속 영상의 21·122·142·202·238프레임을 직접 열어 원본 동작에 눈가림과 중립 복귀가 함께 적용되는 모습을 확인했다. 머리 위치를 따라가는 고정 정면 외부 검수 카메라이며 실제 플레이 카메라나 부드러운 클립 전환을 재현한 영상은 아니다. 이 독립 영상의 몸은 원래 C02이며, 부모 작업에서 보완한 B1 전신과 구분한다.

FBX 비교는 임포트 정점 각각에 대한 원본 최근접 정점 비교이며, 재정렬된 정점의 일대일 ID 대응을 보장하는 검사는 아니다. 동시 0/0.5/1의 Blender 검사를 좌우 개별 채널의 Unity 5단계 검사와 구분한다. `C3/validation.json`의 초기 전체 메시 거리 검사는 앞머리를 피부로 오인하므로 피부 깊이 판정에 사용하지 않으며, `skin_component_validation.json`으로 대체했다.

잔여 한계: 오른쪽 50% 상태에서 5개 표본 정점이 피부 뒤로 최대 **0.287mm** 들어간다. 표본 정점 깊이·눈동자 9개 광선만 검사했으므로 모든 눈꺼풀/안구 접촉이 통과한 것은 아니다. 원본 얼굴의 거친 면과 눈꺼풀의 피부 패치 인상도 남는다. 근접 미술 완성, 생리적으로 정확한 안구·눈꺼풀 운동, 시선·턱·미소를 통과했다고 기록하지 않는다.

## 전달 파일과 통합

- 기본 얼굴 편집본: `C3/Face_C3.blend`
- 동일 얼굴 구조와 프리셋 편집본: `D1/Face_D1.blend`, 데이터 시험 FBX `D1/Face_D1.fbx`.
- 채널 시험 FBX: `C3/Face_C3.fbx` — 몸 애니메이션 없는 초기 데이터 시험본이다.
- 빈 장면 왕복 확인본: `C3/Face_C3_FBX_Roundtrip.blend`
- 채널: `FaceLid_Left/BlinkLeft`, `FaceLid_Right/BlinkRight`, Blender **0~1 → Unity 0~100**.
- 추가 메시만 병합하는 도구: `Tools/Blender/C02_RigFaceLab/face_merge.py`. 원본 몸과 부모 작업의 몸/의복 웨이트를 건드리지 않고 같은 `Head` 골격에 연결한다.
- 전신·최종 Unity 통합은 상위 실험의 `Final/` 및 `Unity/` 자료를 따른다. 초기 빈 Humanoid Controller로 얼굴이 화면 밖에 나간 Unity 영상은 시각 검증 실패본이며 채택하지 않는다.

Unity 담당이 최종 통합 모델의 실제 `LAB_B1_Idle` 위에서 두 채널 5단계·중립 복귀와 Animator 덮어쓰기 0을 확인했다. `Unity/Integrated_Blink_Close`의 150프레임을 얼굴 담당도 직접 확인했다. 머리 회전과 앞머리로 일부 시각 확인이 제한되어 양쪽 접촉/미술 전체를 통과로 처리하지 않는다. 몸·얼굴 동시 런타임의 최종 판정과 수정 재질 영상은 `Unity/`의 최종 보고를 따른다.

텍스처 전달 중 발견한 별도 오류도 재현했다(`texture_source_audit.json`, `TextureProbe/result.json`). Baseline·B1·C3는 원본 PNG 바이트와 이미지 픽셀이 완전히 동일하다. 통합 과정에서 아직 로드하지 않은 C3 이미지의 경로를 과거 렌더 변환 PNG 경로로 먼저 바꾸면 그 이전 파일을 읽어 색이 달라졌다. 경로 변경 전에 원본을 읽거나 원본 바이트를 복사하고, 몸·눈꺼풀에 같은 원본 이미지 datablock을 연결하는 내보내기 수정으로 해결할 수 있다. 부모가 이 전달 오류를 수정하며 얼굴 후보 횟수에는 추가하지 않는다.

기본 얼굴 후보 3/3, 프리셋 후보 1/3을 사용했다. C3와 D1은 제한된 실험 전달 체크포인트이며 정본 플레이어는 교체하지 않는다.
