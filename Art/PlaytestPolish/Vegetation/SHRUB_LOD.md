# 관목 중거리 LOD 보완

실제 원형 삼각형 수는 Hwaseong `SM_Bush` 40,788개, Yongmeori `SM_YMC_Bush_01_Small` 44,516개다. 서브메시마다 전체 메시 수를 중복 합산하지 않고 선택한 서브메시의 indexCount/3을 합했다. 두 공급자 prefab에는 LODGroup이 없으며 현재 파생 LOD0/1은 같은 원형이다.

`WorldMacroVegetationPolish.Run("optimizelod")`는 기존 네 지역 프로토타입의 LOD0/1·배치 ID·크기·밀도를 그대로 두고 LOD2에 실제 원형을 촬영한 4방향 카드(2삼각형)를 추가한다. 지역별 틴트 재질과 원형별 공용 아틀라스를 사용한다. 바탕 텍스처의 의존성 해시가 아틀라스 이름에 들어가므로 과거 누락된 흰색 맵을 재사용하지 않는다. YMC 재질은 `refreshplants`가 먼저 완료되어야 한다.

원형별 256px × 4뷰 아틀라스를 한 원형씩 처리하고 85% 메모리 중단선을 사용한다. 공급자 원본과 기존 메시·재질은 수정하지 않는다. 작업 전 시트는 `Baseline/ShrubLod/Dressing_BeforeShrubCards.asset`로 보존한다. 실제 실행 기록은 `shrub_lod.json`에 원본 해시, 전후 tris, 기존 수준 보존 여부와 카드 경로를 남긴다.

고밀도 관목의 런타임 전환은 렌더러 담당 변경에서 원형0 → 원형1 → 카드2로 처리하며 중심값 16m/24m, 겹침 ±4m/±5m를 사용한다. 기존 가까운 원형을 단순화하지 않는다. 공급자에 실제 하위 LOD가 없다는 이유로 LOD1을 저밀도라고 보고하지 않는다.

현재 작성 단계에서 통과한 검사는 오프라인 C# 컴파일과 원본 파일의 삼각형/LOD 구조 읽기다. Unity 카드 제작, 실제 가시성·색 차이·전환·GPU 성능은 루트 실행 결과를 확인하기 전까지 미검증이다.
