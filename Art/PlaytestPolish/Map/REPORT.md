# 지도 표현·미니맵 수정 보고서

2026-09-14. 실제 Play 씬에 적용했으며 빌드와 영상은 만들지 않았다.

전체 지도는 기존 지리 삽화와 닳은 한지, 가로·세로 한 번씩 접히는 종이 연출을 유지한다. 지역명은 실제 한국어 텍스트다. 도로·하천·시설·현재 위치는 기존 지도 데이터와 월드 좌표를 계속 사용한다. 삽화의 산·숲 기호는 지형을 설명하는 미술 표현이며 실제 개별 산봉우리·수목의 위치를 측량한 표시는 아니다.

미니맵은 전체 삽화를 크게 확대하던 방식을 수정했다. 실제 `WorldMacroTerrain.Height`와 강토 영역에서 지역별 지형 타일을 생성하고, 얇은 10m/40m 등고선과 낮은 명암으로 능선·골짜기를 표시한다. 기존 삽화는 최대 약 4.5%의 종이 명암으로만 남긴다. 새 지형 세부는 기존 탐험 셀에서만 보이며, 도로·시설의 발견 조건과 저장 형식을 바꾸지 않았다. 하천은 기존 확정 벡터를 재사용한다.

| 지역 | 타일 크기 | 표면 해상도 |
|---|---:|---:|
| 황경 | 2002×2048 | 2.18m/texel |
| 청림 | 1198×2048 | 2.99m/texel |
| 적로 | 2048×1346 | 3.48m/texel |
| 철옹 | 1232×2048 | 3.32m/texel |
| 현강 | 2048×1592 | 3.23m/texel |

타일은 같은 월드 원점의 24m 높이 격자, 총 161,299개 고유 샘플에서 보간했다. 위 표의 픽셀 해상도가 독립적인 지형 측량 간격을 의미하지 않는다. 실행 중에는 높이를 다시 계산하지 않고 구운 타일을 표시한다. 이전 타일과 지도 데이터는 `BeforeMini`에 보존했다. 재현 명령은 Editor의 `WorldMapIllustrationPolish.Run("mini")`이며, 일반 지도 굽기 이후 실행한다. 수치 원장은 [mini_terrain_bake.json](mini_terrain_bake.json)이다.

| 검사 | 결과 | 근거와 범위 |
|---|---|---|
| 실제 Play 화면 촬영 | 통과 | 청림 지상 지도 모드와 폐광 실내 도면 모드에서 각각 1920×1080 정지 이미지 8장 |
| 종이 열기·닫기·동작 줄이기 | 통과 | 실제 unscaled 시간의 연출. 설정 1.10초/0.65초, 관찰 약 1.115초/0.68초. 캡처 대기가 관찰시간에 포함됨 |
| 입력 정지·닫기 후 정리 | 통과 | 메뉴·Pause 깊이와 지도 표시 상태 복원. 진단용 uGUI 이벤트를 사용했으며 실제 키·마우스 입력 증거는 아님 |
| 저장·설정·플레이어 위치 보존 | 통과 | 별도 테스트 저장의 원본 바이트·타임스탬프, 메모리 진행, 설정 복원. 검사 자체는 이동을 요청하지 않음 |
| 미니맵 이미지 읽기 | 확인 | 청림 캡처에서 현재 방향과 알려진 길이 선명하며 커다란 숲 기호가 앞을 가리지 않음. 등고선은 의도적으로 옅고 발견 셀 외부는 숨김 |
| 폐광 내부 표시 | 확인 | 지상 타일 대신 실내 통로 도면을 사용 |
| 자원 증가 | 제한된 통과 | 청림 검토 구간 Material 2086→2086, RenderTexture 40→40, 할당 메모리 +733,435B. 장시간 누수·GPU 성능을 증명하는 수치는 아님 |
| 전 지역 타일 전환·실제 도보 발견·장시간 비용 | 미검증 | 각 경계의 실시간 이동, 실제 키 입력, 모든 확대 배율, GPU 프레임타임은 별도 플레이 검토 필요 |
| 전통적인 인상·최종 선 농도 | 사용자 검토 | 미니맵 세부는 길·플레이어보다 낮은 대비로 두었다. 발견 셀의 형태는 여전히 일부 보임 |
